$$\begin{gather}
F_{0} = P \\
c\delta_{ст} = P
\end{gather}$$

$$\begin{gather}
F = -c(\delta_{ст} + x) \\
m \frac{d^{2}x}{dt^{2}} = -c(\delta_{ст} + x) + P
m \frac{d^{2}x}{dt^{2}} = \cancel{ -c\delta_{ст} } - cx + \cancel{ P }
\end{gather}$$

$$\begin{gather}
\frac{d^{2}x}{dt^{2}} = -\underbrace{\frac{c}{m}}_{k^{2}}x \\
\frac{d^{2}x}{dt^{2}} + k^{2}x = 0
\end{gather}$$

$k$ - собственная частота колебания системы

$$\begin{gather}
T = \frac{2\pi}{k} \\
T = 2\pi \sqrt{ \frac{m}{c} } = 2\pi \sqrt{ \frac{P}{gc} } = 2\pi \sqrt{ \frac{\delta_{ст}}{g} }
\end{gather}$$

> [!important] ВАЖНО
> $$T = 2\pi \sqrt{ \frac{\delta_{ст}}{g} }$$
> $$\begin{gather}
k = \sqrt{ \frac{g}{\delta_{ст}} }
\end{gather}$$

Мы знаем, что:

$$\begin{gather}
x = C_{1}\sin kt + C_{2}\cos kt \\
\dot{x} = v = C_{1}k\cos kt - C_{2}k\sin kt \\
\end{gather}$$

$$\begin{gather}
t = t_{0} = 0 \\
x = x_{0} = -\delta_{ст} \\
v = v_{0} = 0 \\
\end{gather}$$

$$\begin{gather}
-\delta_{ст} = C_{2} \implies C_{2} = - \delta_{ст} \\
0 = C_{1}k \implies C_{1} = 0
\end{gather}$$

Получен закон колебаний:

$$\begin{gather}
x = -\delta_{ст}\cos kt
\end{gather}$$
