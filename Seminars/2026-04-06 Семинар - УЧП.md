## Формула Пуассона

$$\begin{gather}
n = 2 \\
\begin{cases}
u_{tt} + a^{2}\Delta u = f(x,y,t), \ (x,y)\in \mathbb{R}, t > 0 \\
u|_{t=0} = \phi(x,y), \ u_{t}|_{t=0} = \psi(x,y)
\end{cases}
\end{gather}$$

$$\begin{gather}
u(x,y,t) = \frac{1}{2\pi a} \frac{ \partial  }{ \partial t } \left( \iint_{r < at} \frac{\phi(\xi,\eta)d\xi d \eta}{\sqrt{ a^{2}t^{2} - r^{2} }}\right) + \frac{1}{2\pi a} \iint_{r<at} \frac{\psi(\xi,\eta)d\xi d \eta}{\sqrt{ a^{2}t^{2} - r^{2} }} + \\
+ \frac{1}{2\pi a} \int_{0}^{t} d\tau \iint_{r<a(t-\tau)} \frac{f(\xi,\eta,\tau)d\xi d \eta}{\sqrt{ a^{2}(t-\tau)^{2} - r^{2} }} \\

r^{2} = |\xi-x|^{2} + |\eta-y|^{2}
\end{gather}$$
