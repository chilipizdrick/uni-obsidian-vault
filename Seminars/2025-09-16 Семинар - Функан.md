### Задача

Пусть есть 2 метрических пространства $X, \rho_{x}$, $Y, \rho_{y}$.
$$z_{1} = (x_{1},y_{1}), \ z_{2} = (x_{2},y_{2})$$

Как задать расстояние?

### 1 Способ

$$\begin{gather}
\rho(z_{1},z_{2}) = \rho_{x}(x_{1},x_{2}) + \rho_{y}(y_{1},y_{2}) \\
\end{gather}$$

$$\begin{gather}
\rho_{x}(x_{1},x_{3}) \leq \rho_{x}(x_{1},x_{2}) + \rho_{x}(x_{2},x_{3}) \\
\rho_{y}(y_{1},y_{3}) \leq \rho_{y}(y_{1},y_{2}) + \rho_{y}(y_{2},y_{3})
\end{gather}$$

$$\rho(x,y) = \left| \frac{1}{x} - \frac{1}{y} \right| - \text{не работает}$$

$$\begin{gather}
\rho(x,y) = |\sin x - \sin y| - \text{полуметрика}

$$\begin{gather}
\rho(x,y) = |x-y|^{2} \\
x-y = a \\
y-z = b \\
x-z = a+b \\
|a+b|^{2} \leq |a|^{2} + |b|^{2} \\
a^{2} + 2ab + b^{2} < a^{2} + b^{2} - \text{не выполняется}
\end{gather}$$

$$\begin{gather}
\rho(x,y) = e^{-|x-y|} - \text{не выполняется}
\end{gather}$$

$$\begin{gather}
\rho(x,y) = f(|x-y|), \implies f: \mathbb{R}_{+} \to \mathbb{R}_{+} \\
f(0) = 0 \\
f(x) > 0 , \ x > 0 \\
\rho(x,z) \leq \rho(x,y) + \rho(y,z) \\
f(|x-z|) \leq f(|x-y|) + f(|y-z|) \\
f(|a+b|) \leq f(|a|) + f(|b|)
\end{gather}$$

$$\begin{gather}
\rho(x,y) = \frac{|x-y|}{1-|x-y|} \\
\frac{|a+b|}{1+|a+b|} \leq \frac{|a|}{1+|a|} + \frac{|b|}{1+|b|} \\
\end{gather}$$

$$\begin{gather}
\frac{|a+b|}{1+|a+b|} \leq \frac{|a|(1+|b|) + |b|(1+|a|)}{(1+|a|)(1+|b|)} \\
\frac{|a+b|}{1+|a+b|} \leq \frac{|a| + |b| + 2|ab|}{1 + |a| + |b| + |ab|} \\ \\

\frac{|a+b|}{1+|a+b|} \leq \frac{|a| + |b|}{1 + |a| + |b|} = \frac{|a|}{1 + |a| + |b|} + \frac{|b|}{1 + |a| + |b|} \leq \frac{|a|}{1+|a|} + \frac{|b|}{1+|b|}
\end{gather}$$
