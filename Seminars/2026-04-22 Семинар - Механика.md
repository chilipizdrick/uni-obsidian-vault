Работы силы

$$\begin{gather}
\begin{cases}
A_{P} = P(z_{0}-z) \\
A_{F} = -\frac{c(x^{2}-x_{0}^{2})}{2} \\
A_{M} = M^{e}\phi \\
A_{F_{тр}} = -F_{тр}S = -fNS
\end{cases}
\end{gather}$$

$$\begin{gather}
T - T_{0} = \sum A^{a}_{k} + \sum A_{k}^{r},
\end{gather}$$

где $T$ - кинетическая энергия, $A_{k}^{a}$ - активные работы (активные силы), $A_{k}^{r}$ - работы реакции (силы реакции).

$$\begin{gather}
\sum A_{k}^{r} = 0 - \text{система с идеальными связями}
\end{gather}$$

Т.е. не тратится никакой работы на реакцию между элементами (материальными точками) системы.

$$\begin{gather}
v_{0} = 0 \implies T_{0} = 0 \\
T = \sum A_{k}^{a} 
\end{gather}$$

1. Поступательное движение - при постумательном движении все точки тела движутся одинаково, поэтому $T_{пост.} = \frac{Mv_{C}^{2}}{2}$.
2. Вращательное движение - при вращательном движении кинетическая энергия выражается $T_{вр.} = \frac{J_{C}\omega^{2}}{2}$.
3. Плоскопараллельное движение - $T_{п/п} = \frac{J_{P}\omega^{2}}{2} = \frac{Mv_{C}^{2}}{2} + J_{P} + \frac{J_{C}\omega^{2}}{2}$.
$C$ - центр масс.

$$\begin{gather}
T - T_{0} = \sum A_{k}^{a} + \sum A_{k}^{r} \\
v_{0} = 0 \implies T_{0} = 0
\end{gather}$$

$$A_{N_{O}} = 0$$

В направлении действия силы $N_{C}$ нет никаких перемещений, следовательно

$$\begin{gather}
A_{N_{C}} = 0 \\
\end{gather}$$

Получается, что мы имеем дело с системой с идеальными связями.

$$\begin{gather}
\sum A_{k}^{r} = 0
\end{gather}$$

Тогда:

$$\begin{gather}
T = \sum A_{k}^{a}
\end{gather}$$

1. $T = T_{1} + T_{2} + T_{3}$

$$\begin{gather}
T_{1} = \frac{m_{1}v_{1}^{2}}{2} \\
T_{2} = \frac{J_{C} \omega_{2}^{2}}{2} = \frac{m_{2}\rho^{2}v_{1}^{2}}{2R^{2}} \\
T_{3} = \frac{m_{3}v_{C}^{2}}{2} + \frac{J_{C}\omega_{3}^{2}}{2} = \frac{m_{3}r^{2}v_{1}^{2}}{2R^{2}} + \frac{m_{3}r^{2}v_{1}^{2}}{4R^{2}} = \\
= \frac{3m_{3}r^{2}v_{1}^{2}}{4R^{2}}
\end{gather}$$

Промежуточные расчеты:
$$\begin{gather}
\omega_{2} = \frac{v_{1}}{R} = \frac{v_{C}}{r} \\
J_{O} = m_{2}\rho^{2} \\
x_{C} = \frac{rx_{1}}{R} , \ v_{C} = \frac{rv_{1}}{R}, \ \omega_{3} = \frac{v_{C}}{R} = \frac{rv_{1}}{R^{2}} \\
J_{C} = \frac{m_{3}R^{2}}{2}
\end{gather}$$

$$\begin{gather}
T = \underbrace{\left( \frac{m_{1}}{2} + \frac{m_{2}\rho^{2}}{2R^{2}} + \frac{3m_{3}r^{2}}{4R^{2}} \right)}_{L - \text{приведенная масса системы}}v_{1}^{2} = Lv_{1}^{2}
\end{gather}$$

$$\begin{gather}
\sum A_{k}^{a} = A_{P_{1}} + A_{P_{2}} + A_{P_{3}} + A_{F} \\
A_{P_{1}} = - P_{1}x_{1}; \ A_{P_{2}} = 0; \ A_{P_{3}} = 0 \\
A_{F} = Fx_{C}\cos\alpha = F\frac{rx_{1}}{R}\cos \alpha
\end{gather}$$

$$\begin{gather}
Lv_{1}^{2} = \underbrace{(F \frac{r}{R}\cos\alpha-P_{1})}_{J}x_{1}
\end{gather}$$

Выражение с двумя неизвестными:
$$\begin{gather}
Lv_{1}^{2} = Jx_{1}
\end{gather}$$

$$\begin{gather}
2Lv_{1}\dot{v}_{1} = J\dot{x}_{1}
\end{gather}$$
