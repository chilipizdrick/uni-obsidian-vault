### Задачи на формулу Даламбера

$$\begin{gather}
\begin{cases}
u_{tt} - a^{2}u_{xx} = f(x,t), \ x \in \mathbb{R}, t > 0 \\
u|_{t=0} = \phi(x), \ u_{t}|_{t=0} = \psi(x)
\end{cases}
\end{gather}$$

Решение может быть найдено следующим образом

$$\begin{gather}
u(x,t) = \frac{1}{2}\left( \phi(x + at) + \phi(x - at) \right) + \frac{1}{2a}\int_{x-at}^{x+at} \psi(\xi) \, d\xi + \\
+ \frac{1}{2a} \int_{0}^{t}d\tau \int_{x-a(t-\tau)}^{x+a(t-\tau)} d\xi \, f(\xi, \tau)
\end{gather}$$

### Задача 3

$$\begin{gather}
\begin{cases}
u_{tt} - u_{xx} = \sin(x) \\
u|_{t=0} = \sin x, u_{t}|_{t=0} = 0
\end{cases}
\end{gather}$$

$$\begin{gather}
u(x,t) = \frac{1}{2}\left( \sin(x-t) + \sin(x+t) \right) + \frac{1}{2}\int_{0}^{t} d\tau \int_{x-(t-\tau)}^{x+(t-\tau)}  d\xi \sin \xi = \\
= \frac{1}{2}\sin(x-t) + \frac{1}{2}\sin(x+t) + \frac{1}{2}\sin x - \frac{1}{2}\sin(x+t) + \\
+ \frac{1}{2}\sin(x) - \frac{1}{2}\sin(x-t) = \sin x
\end{gather}$$
