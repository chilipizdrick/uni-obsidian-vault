$$\begin{gather}
f(x) = \begin{cases}
1, x(t) \geq 0, x_{(t)a}\not\equiv 0, \\
0, x(t) \equiv 0, \\
-1, \exists t: x(t) < 0
\end{cases}
\end{gather}$$

$$\begin{gather}
f(x) = \int_{-1}^{1} x(t) \, dx \\
||x|| \leq 1 \\
\end{gather}$$

$$\begin{gather}
|f(x)| = \left|\int_{-1}^{1} x(t) \, dx \right| \leq \int_{-1}^{1} |x(t)| \, dx  \leq \int_{-1}^{1} ||x||_{C} \, dx  \leq 2||x||_{C} \leq 2
\end{gather}$$
 $$\begin{gather}
|f(x') - f(x'')| = |f(x'-x'')| \leq 2 |x'-x''| \\
\end{gather}$$
Т.е норма функционала $\leq 2$, несложно заметить, что она достигается (например для $f(t) = 1$).

Рассмотрим для $CL_{2}[a;b]$. Воспользуемся неравенством Коши-Буняковского:

$$\begin{gather}
|f(x)| = \left| \int_{-1}^{1} x(t) \, dt  \right| \leq \int_{-1}^{1} |x(t)|  \, dt \leq \sqrt{ \int_{-1}^{1} |x(t)|^{2} \, dt  } \sqrt{ \int_{-1}^{1} 1^{2} \, dt }
\end{gather}$$

Следующий функционал $f(x) = \int_{0}^{1}tx(t) \, dt$:

$$\begin{gather}
|f(x)| = \left| \int_{0}^{1} tx(t)  \, dt  \right|  \leq \int_{0}^{1} t|x(t)| \, dt \leq ||x||_{C} \int_{0}^{1} t \, dx \leq \frac{1}{2} \cdot ||x||_{C}  \leq \frac{1}{2}
\end{gather}$$

$$\begin{gather}
\int_{0}^{1} |x(t)| \, dt  - \int_{0}^{1} t|x(t)| \, dt = \int_{0}^{1} (1-t)|x(t)| \, dt > 0 \forall x \neq 0
\end{gather}$$
