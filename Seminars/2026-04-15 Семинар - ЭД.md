## Пр. №9. Собственные волны полного волновода. Общие свойства

![[2026-04-15 Семинар - ЭД 2026-04-15 12.44.25.excalidraw]]

$$\begin{gather}
\begin{cases}
\mathrm{rot} \, \dot{\vec{H}}_{m} = i\omega\epsilon_{a} \dot{\vec{E}}_{m} \\
\mathrm{rot} \, \dot{\vec{E}}_{m} = -i\omega \mu_{a} \dot{\vec{H}}_{m}
\end{cases} \\
\left.\dot{\vec{E}}_{m\tau}\right|_{S} = 0
\end{gather}$$

### 1. $E$-волны $(E_{z} \neq 0, H_{z} = 0)$

$$\begin{gather}
\dot{E}_{me}^{э} = \frac{1}{i\omega\epsilon_{a}}\left( \frac{dZ^{э}_{e}}{dz} \mathrm{grad}_{\perp} \, T_{l}^{э} + \vec{z}^{0} (\varkappa^{э}_{e})^{2} T_{l}^{э} Z_{l}^{э} \right)\\
\ \dot{\vec{H}}_{ml}^{э} = \left[ \mathrm{grad}_{\perp} \, T_{l}^{э}, \vec{z}^{0} \right] \\
Z_{l}^{э} = e^{\mp i\Gamma_{l}z} \\
\Gamma_{l}^{э} = \sqrt{ k^{2} - (\varkappa^{э}_{l})^{2} }
\end{gather}$$

### 2. $H$-волны $(H_{z} \neq 0, E_{z} = 0)$

$$\begin{gather}
\dot{\vec{E}}_{ml}^{м} = -\dot{\vec{H}}_{ml}^{э} = -\left[ \mathrm{grad}_{\perp} \, T_{l}^{м}, \vec{z}^{0} \right] Z_{l}^{м} \\
\dot{\vec{H}}_{ml}^{м} = \frac{\epsilon_{a}}{\mu_{a}}\dot{\vec{E}}_{ml}^{э} = \frac{1}{i\omega \mu_{a}}\left( \frac{dZ_{l}^{м}}{dz} \mathrm{grad}_{\perp} \, T_{l}^{м} + \vec{z}^{0} (\varkappa_{l}^{м})^{2} T_{l}^{м} Z_{l}^{м} \right) \\
Z_{l}^{м} = e^{\mp i \Gamma_{l}z}, \ \Gamma_{l}^{м} = \sqrt{ k^{2} - (\varkappa_{l}^{м})^{2} }
\end{gather}$$

$$\begin{gather}
\Delta_{\perp} T^{э} + (\varkappa^{э})^{2}T^{э} = 0 \\
\left.T^{э}\right|_{L_{\perp}} = 0
\end{gather}$$

Аналогично для магнитных волн.

Свойства:

1. В волноводе существует бесконечное множество волн электрического и магнитного типа. $E$- и $H$-волны формируют полную систему собственных фукнций. По этой системе можно представить любое ЭМ поле, находящееся в волноводе, в частности - возбуждаемое поле.
2. Зависимость собственных волн от продольной координаты $z$ определяется функциями $e^{\mp i\Gamma_{l} z}$, где $l$ - номер собственной волны. Собственные волны с зависимостью $e^{-i\Gamma_{l}z}$ будем называть собственными волнами положительного направления, а волны с зав. $e^{i\Gamma_{l}z}$ - отрицательного направления, где $l$ - номер собственной волны.

$$\begin{gather}
\dot{\vec{E}}_{ml}^{(+)} = \dot{\vec{\mathcal{E}}}_{ml}^{(+)}(x,y)e^{-i\Gamma_{l}z} \\
\dot{\vec{E}}_{ml}^{(-)} = \dot{\vec{\mathcal{E}}}_{ml}^{(-)}(x,y)e^{i\Gamma_{l}z} \\
\dot{\vec{H}}_{ml}^{(+)} = \dot{\vec{\mathcal{H}}}_{ml}^{(+)}(x,y)e^{-i\Gamma_{l}z} \\
\dot{\vec{H}}_{ml}^{(-)} = \dot{\vec{\mathcal{H}}}_{ml}^{(-)}(x,y)e^{i\Gamma_{l}z}
\end{gather}$$

3. Поперечные составляющие напряженности электрического и магнитного поля связаны между собой следующими соотношениями: 

$$\begin{gather}
\dot{\vec{E}}_{ml\perp} = W_{l}\left[ \dot{\vec{H}}_{ml\perp}, \pm \vec{z}^{0} \right] \\
\dot{\vec{H}}_{ml\perp} = \frac{1}{W_{l}}\left[ \pm \vec{z}^{0}, \dot{\vec{E}}_{ml\perp}\right] \\
\end{gather}$$

Волновое сопротивление собственной волны с номером $l$:

$$\begin{gather}
W_{l} = \begin{cases}
W_{l}^{э} = \frac{\Gamma_{l}}{\omega\epsilon_{a}} \ \text{для} \ E-\text{волн} \\
W_{l}^{м} = \frac{\omega \mu_{a}}{\Gamma_{l}} \ \text{для} \ H-\text{волн}
\end{cases}
\end{gather}$$

"+" - для С.В. положительного направления,
"-" - для С.В. отричательного направления.

4. Важными электродинамическими параметрами собственных волн являются: $\Gamma_{l}$ - постоянная распостранения, $\varkappa_{l}$ - поперечное волновое число, $\lambda_{кр. l}$ - критическая длина волны.

$$\begin{gather}
\lambda_{кр. l} = \frac{2\pi}{\varkappa_{l}} \\
\Gamma_{l} = \sqrt{ k^{2} - \varkappa_{l}^{2} } = k\sqrt{ 1 - \left( \frac{\lambda}{\lambda_{кр. l}} \right)^{2} }, \ \lambda = \frac{2\pi}{k}
\end{gather}$$

Постоянная распостранения представляет собой либо положительную величину (при $\lambda < \lambda_{кр. l}$), либо отрицательную мнимую величину (при $\lambda > \lambda_{кр.l}$)
