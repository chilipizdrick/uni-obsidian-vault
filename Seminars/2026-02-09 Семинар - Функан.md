Пятиминутка:

1. Множество меры 0 - множество, такое что $\forall \epsilon \exists$ набор интервалов, покрывающий данное множество, что сумма длин равна $\epsilon$.
2. Полная система элементов ЛНП - линейная оболочка образует плотное множество в этом пространстве.
3. $||A||$ - $\mathrm{sup}_{||x||\leq 1} ||Ax|||$
4. $||f||$ - $\mathrm{sup}_{||x|| \leq 1} |f(x)|$
5. Компактный оператор - образ любой ограниченной последовательности содержит сходящуюся подпоследовательность / образ любого ограниченного множество - предкомпактен.

Сопряженное пространство $X^{*}$ содержит линейные ограниченные функционалы, действующие на множестве $X$.

$c_{0}$ - пространство сходящихся к нулю последовательностей.
$$||x|| = \underset{j}{\mathrm{sup}} |x_{j}|$$

Плотное множество в $c_{0}$ - множество финитных последовательностей.
$x^{(N)} = (x_{1},x_{2}, \dots, x_{N}, 0,0,\dots) = \sum_{k=1}^{N}x_{k}e_{k}$.
$x = (x_{1},x_{2}, \dots, x_{N}, 0,0,\dots)$.

$$\begin{gather}
e_{k} = (0,0,\dots,0,\underset{k}{1},0,\dots)
\end{gather}$$

$$\begin{gather}
f(x^{(N)}) = f\left( \sum_{k=1}^{N}x_{k}e_{k} \right) = \\
= \sum_{k=1}^{N}x_{k}f(e_{k}) = \sum_{k=1}^{N}x_{k}f_{k}
\end{gather}$$

$$\begin{gather}
f(x^{(N)}) = \left| \sum_{k=1}^{N}x_{k}f_{x} \right| \leq \sum_{k=1}^{N} |x_{k}||f_{k}| \leq \sum_{k=1}^{N}|f_{k}| \cdot ||x^{(N)}|| \leq \\
\leq \sum_{k=1}^{\infty} |f_{k}| \cdot ||x^{(N)}||
\end{gather}$$

Т.е функционал ограничен, если ряд сходится, функционал не ограничен в общем случае.

Тогда линейные функционалы на $c_{0}$ задаются последовательностями $f_{k} := f(e_{k})$.

$c_{0}^{*} = l_{1}$

Продолжим фукнционал на все пространство $c_{0}$:

$$\begin{gather}
x^{(N)} \underset{N\to \infty}{\to} x \implies f(x^{(N)}) \to f(x) = \lim_{ N \to \infty } \sum_{k=1}^{N} x_{k}f_{k} = \sum_{k=1}^{\infty} x_{k}f_{k}
\end{gather}$$

Следующее пространство:

$$\begin{gather}
x \in l_{1} \\
\end{gather}$$

Функционал выглядит идентично, оценим норму:

$$\begin{gather}
||x^{(N)}|| = \sum_{k=1}^{N} |x_{k}|
\end{gather}$$

$$\begin{gather}
|f(x^{(N)})| = \left| \sum_{k=1}^{N} x_{k}f_{k} \right|  \leq \sum_{k=1}^{N} |x_{k}||f_{k}| \leq \underset{k\leq N}{\mathrm{max}} |f_{k}| \sum_{k=1}^{N} |x_{k}| = \\
= ||x^{(N)}|| \underset{k\leq N}{\mathrm{max}} |f_{k}| \leq \underset{k}{\mathrm{sup}} |f_{k}| \cdot ||x^{(N)}||
\end{gather}$$

Следовательно, если последовательность $f_{k}$ - ограничена, то и функционал ограничен.

Норма достигается для последовательности с одним не нулевым $k$-ым элементом.

То есть $l_{1}^{*} = l_{\infty}$.

Рассмотрим пространство $c$:

$$\begin{gather}
||x|| = \underset{j}{\mathrm{sup}} |x_{j}|, \ \sum_{k=1}^{\infty} |f_{k}| < \infty \\
\end{gather}$$

$$\begin{gather}
x_{k} \to x_{\infty}, \ x = x_{\infty}\underbrace{(1,1,\dots)}_{\hat{e}} + \overset{0}{x}, \ \overset{0}{x} \in c_{0} \\
x = x_{\infty}\hat{e} + \overset{0}{x} \\f(x) = x_{\infty}\underbrace{f(\hat{e})}_{\hat{f}} + f(\overset{0}{x}) = \\
= x_{\infty} \hat{f} + \sum_{k=1}^{\infty} f_{k}(x_{k} - x_{\infty}) = (*)
\end{gather}$$

$$\begin{gather}
\sum_{k=1}^{\infty} |f_{k}| < \infty \implies \text{можно представить суммой рядов}
\end{gather}$$

$$\begin{gather}
(*) = x_{\infty}\hat{f} + \sum_{k=1}^{\infty} f_{k} x_{k} - x_{\infty} \sum_{k=1}^{\infty} f_{k} = \\
= x_{\infty}f_{\infty} + \sum_{k=1}^{\infty} f_{k}x_{k} \\
f_{\infty} = \hat{f} - \sum_{k=1}^{\infty}f_{k}
\end{gather}$$


$$\begin{gather}
f(x) \leq |x_{\infty}| |f_{\infty}|  + \sum_{k=1}^{\infty} |f_{k}| | x_{k}| \leq \left( |f_{\infty}| + \sum_{k=1}^{\infty} |f_{k}| \right) \cdot ||x||
\end{gather}$$

Норма не достигается, но может быть приближена достигается при
$x^{(N)} = (\mathrm{sgn} f_{1}, \dots, \mathrm{sgn}f_{N}, \mathrm{sgn}f_{\infty},\mathrm{sgn}f_{\infty}, \dots)$

$$\begin{gather}
f(x^{(N)}) = |f_{\infty}| + \sum_{k=1}^{N} |f_{k}| + \left(\sum_{k=N+1} f_{k}\right) \mathrm{sgn}f_{\infty}
\end{gather}$$

В итоге: пространство сопряженное к $c_{0}^{*} = l_{1}, l_{1}^{*} = l_{\infty}$.
