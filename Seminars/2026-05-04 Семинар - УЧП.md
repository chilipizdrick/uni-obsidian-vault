Уравнение Гельмгольца:

$$\begin{gather}
u = u(x,y,t) \\
\Delta u + k^{2}y = 0, \ x^{2} + y^{2} < R^{2}, \ k = \mathrm{const} > 0 \\
u |_{x^{2}+y^{2}=R^{2}}, \ (u|_{\phi+2\pi} = u|_{\phi})
\end{gather}$$

$$\begin{gather}
g(\phi) = 1 + \sin \phi \cos \phi = 1 + \frac{1}{2}\sin 2\phi \\
\end{gather}$$

1. $x = r\cos \phi, \ y = r \sin \phi$,
$\Delta = \frac{1}{r} (ru_{r})_{r} + \frac{1}{r^{2}} u_{\phi \phi}$

$$\begin{gather}
\frac{1}{r} (ru_{r})_{r} + \frac{1}{r^{2}} u_{\phi \phi} + k^{2}u = 0 \\
u|_{r=R_{0}} = 1 + \frac{1}{2}\sin (2\phi), \ (u|_{\phi+ 2\pi} = u |_{\phi})
\end{gather}$$

$$\begin{gather}
\frac{1}{r}(rR')'\Phi + \frac{1}{r^{2}}R\Phi''a + k^{2}R\Phi = 0 \\
\frac{1}{rR}(rR')' + \frac{1}{r^{2}}\left( \frac{\Phi''}{\Phi} \right) + k^{2} = 0
\end{gather}$$

$$\begin{gather}
\frac{\Phi''}{\Phi} = -r^{2} \left( \frac{1}{rR} (rR')' + k^{2} \right) = -\lambda^{2} = \mathrm{const} \\
\Phi'' + \lambda^{2} \Phi = 0
\end{gather}$$

$$\begin{gather}
r(rR')' + (k^{2}r^{2} - \lambda^{2})R = 0 \\
\end{gather}$$

$$\begin{gather}
\begin{cases}
\Phi'' + \lambda^{2}\Phi = 0 \\
\Phi(\phi + 2\pi) = \Phi(\phi)
\end{cases} \\
\Phi_{n}(\phi) = e^{in\phi}, \ \lambda_{n} = n \in \mathbb{Z}
\end{gather}$$

$$\begin{gather}
x^{2}y'' + xy' + (x^{2} - n^{2})y = 0 \\
r^{2}R'' + rR' + (k^{2}r^{2} - n^{2})R = 0 \\
R_{n}(r) = A_{n}J_{n}(kr) + \cancel{ B_{n}Y_{n}(kr) }
\end{gather}$$

Функция Неймана отлетает, потому что она не регулярна в нуле.

$$\begin{gather}
u(r, \phi) = \sum_{n=-\infty}^{+\infty} A_{n}J_{n}(kr) e^{in\phi}
\end{gather}$$

Пусть $r = R_{0}$, тогда получается следующий ряд:

$$\begin{gather}
u(R_{0}, \phi) = \sum_{n=-\infty}^{+\infty} A_{n}J_{n}(kR_{0})e^{in\phi} = 1 + \frac{1}{2}\sin 2\phi \\
u(R_{0}, \phi) = \sum_{n=-\infty}^{+\infty} A_{n}J_{n}(kR_{0})e^{in\phi} = 1 + \frac{1}{4i}e^{i 2\phi} - \frac{1}{4i}e^{-i 2\phi}
\end{gather}$$

$$\begin{gather}
J_{n} = (-1)^{n}J_{-n}
\end{gather}$$

Тогда возьмем $|n|$ и учтем знаки в $A_{n}$:

$$\begin{gather}
u(R_{0}, \phi) = \sum_{n=-\infty}^{+\infty} A_{n}J_{|n|}(kR_{0})e^{in\phi} = 1 + \frac{1}{4i}e^{i 2\phi} - \frac{1}{4i}e^{-i 2\phi}
\end{gather}$$

$$\begin{gather}
A_{0} = \frac{1}{J_{0}(kR_{0})} \\ (A_{0}J_{0}(kR_{0}) = 1)
\end{gather}$$

$$\begin{gather}
A_{2} = \frac{\frac{1}{4i}}{J_{2}(kR_{0})} = \frac{1}{4iJ_{2}(kR_{0})}
\end{gather}$$

$$\begin{gather}
A_{-2} = -\frac{1}{4iJ_{2}(kR_{0})}
\end{gather}$$

$$\begin{gather}
u(r,\phi) = \frac{J_{0}(kr)}{J_{0}(kR_{0})} + \frac{J_{2}(kr)}{4i J_{2}(kR_{0})}e^{i 2\phi} - \frac{J_{2}(kr)}{4i J_{2}(kR_{0})}e^{-i 2\phi} = \\
= \frac{J_{0}(kr)}{J_{0}(kR_{0})} + \frac{J_{2}(kr)}{2J_{2}(kR_{0})}\sin 2\phi
\end{gather}$$

### Уравние Гельмгольца в циллиндрических координатах

$$\begin{gather}
\begin{cases}
u=u(x,y,z) \\
\Delta u + k^{2}u = 0 \\
(u|_{\phi + 2\pi} = u|_{\phi}) \\
u|_{r=R_{0}} = g(\phi ,z) \\
u|_{z=0} = u|_{z=H} = 0
\end{cases}
\end{gather}$$

$$\begin{gather}
\Delta u = \frac{1}{r}(ru_{r})_{r} + \frac{1}{r^{2}}u_{\phi \phi} + u_{zz}
\end{gather}$$

$$\begin{gather}
u = R(r)\Phi(\phi)Z(z) \\
\frac{r^{2}}{rR}(rR')' + \frac{\Phi''}{\Phi} + r^{2}\frac{Z''}{Z} + k^{2}R\Phi Z = 0 \\
\end{gather}$$

$$\begin{gather}
\begin{cases}
\frac{\Phi''}{\Phi} + \lambda^{2} \Phi = 0 \\
Z'' + \mu^{2}Z = 0 \\
r(rR')' + (k^{2}r^{2} - \mu^{2}r^{2} - \lambda^{2})R = 0, \ k^{2} - \mu^{2} = \alpha^{2} , \ \alpha \in \mathbb{C}
\end{cases}
\end{gather}$$

$$\begin{gather}
\Phi_{n}(\phi) = e^{in\phi}, \lambda_{n} = n \in \mathbb{Z} \\
Z'' + \mu^{2}Z = 0 \implies Z_{n}(z) = \sin \left( \frac{\pi mz}{H} \right), \ m = 1,2,3\dots
\end{gather}$$

$$\begin{gather}
r^{2}R_{m,n}'' + rR_{m,n}' (\alpha_{m}^{2}r^{2} - n^{2})R_{m,n} = 0, \ \alpha^{2}_{m} = k^{2} - \frac{\pi^{2}m^{2}}{H^{2}}
\end{gather}$$

$$\begin{gather}
R_{m,n}(r) = A_{m,n} J_{n}(\alpha_{m}r)
\end{gather}$$

$$\begin{gather}
u(r,\phi,z) = \sum_{n=-\infty}^{+\infty}\sum_{m=1}^{+\infty} A_{m,n}J_{|n|}(\alpha_{m}r)e^{in\phi} \sin \left( \frac{\pi mz}{H} \right)
\end{gather}$$
