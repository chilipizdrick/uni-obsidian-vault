## ТР 5

$$\begin{gather}
u(x,y,t) \\
\end{gather}$$

$$\begin{cases}

\frac{1}{a^{2}}u_{tt} - \Delta u = x^{2} + ty, \ x^{2} + y^{2} < r^{2}_{0}, \ t > 0 \\
u|_{x^{2}+y^{2} = r^{2}_{0}} = 0 \\
u|_{t=0} = J_{0}\left( \frac{\mu^{0}_{34}r}{r_{0}} \right), \ u_{t}|_{t} = 0 \\
\end{cases}$$

### 1. Переход к полярным координатам

$$\begin{gather}
\begin{cases}
x = r\cos \phi \\
y = r\sin \phi
\end{cases} \\
\Delta = \frac{1}{r} \frac{\partial }{\partial r}\left( r \frac{\partial}{\partial r} \right) + \frac{1}{r^{2}} \frac{\partial^{2}}{\partial \phi^{2}}
\end{gather}$$

$$\begin{cases}
\frac{1}{a^{2}}u_{tt} - \frac{1}{r}(ru_{r})_{r} - \frac{1}{r^{2}}u_{\phi \phi} = r^{2}\cos ^{2}\phi + tr\sin \phi, \ r < r_{0}, \ t > 0 \\
u|_{r=r_{0}} = 0 \\
u|_{t=0} = J_{0}\left( \frac{\mu_{32}^{(0)}r}{r_{0}} \right), \ u_{t}|_{t=0} = 0
\end{cases}$$

### 2. Разбиение на подзадачи

$$\begin{gather}
u = V + W
\end{gather}$$

$$\begin{cases}
\frac{1}{a^{2}}V_{tt} - \frac{1}{r}(rV_{r})_{r} \frac{1}{r^{2}}V_{\phi \phi} = 0 \\
V|_{r=r_{0}} = 0, \\
V|_{t=0} = J_{0}\left( \frac{\mu_{32}^{(0)}r}{r_{0}} \right), \ V_{t}|_{t=0} = 0
\end{cases}$$

$$\begin{cases}
\frac{1}{a^{2}}W_{tt} - \frac{1}{r}(rW_{r})_{r} \frac{1}{r^{2}}W_{\phi \phi} = r^{2}\cos ^{2}\phi + tr\sin \phi \\
W|_{r=r_{0}} = 0, \left( V_{\phi+2\pi} = V|_{\phi} \right)  \\
W|_{t=0} = 0, \ W_{t}|_{t=0} = 0
\end{cases}$$

### Разделение переменных

$$\begin{gather}
V = R(r)\Phi(\phi)T(t) \\
\frac{1}{a^{2}}R\Phi T'' - \frac{1}{r}(rR')'\Phi T - \frac{1}{r^{2}}R\Phi''T = 0 \\
\end{gather}$$

$$\begin{gather}
\frac{1}{a^{2}}\cdot \frac{T''}{T} - \frac{1}{rR}(rR')' - \frac{\Phi''}{r^{2}\Phi} = 0
\end{gather}$$

Будем искать базис в $\Phi$.

$$\begin{gather}
\frac{\Phi''}{\Phi} = r^{2} \cdot \frac{1}{a^{2}} \frac{T''}{T} - \frac{r}{R} (rR')' = -\xi^{2} = \mathrm{const} \\
\Phi'' + \xi^{2}\Phi = 0
\end{gather}$$

$$\begin{gather}
r^{2}\cdot \frac{1}{a^{2}} \frac{T''}{T} - \frac{r}{R}(rR')' = -\xi^{2} \\
\frac{1}{a^{2}}\cdot \frac{T''}{T} = \frac{1}{rR}(rR')' - \frac{\xi^{2}}{r^{2}} = -\eta^{2} = \mathrm{const} \\
\end{gather}$$

$$\begin{gather}
r(rR')' + (\eta^{2}r^{2} - \xi^{2})R = 0 \\
T'' + \eta^{2}a^{2}T = 0
\end{gather}$$

$$\begin{gather}
\begin{cases}
\Phi'' + \xi^{2}\Phi = 0 \\
\Phi(\phi + 2\pi) = \Phi(\phi) \\
\end{cases} \\
\Phi(\phi) = C_{1}\cos(\xi \phi) + C_{2}\sin(\xi \phi) \\
\end{gather}$$

$$\begin{gather}
\phi = 0: \ C_{1} = C_{1}\cos(\xi \cdot 2\pi) + C_{2}\sin(\xi \cdot 2\pi), \ (\Phi(0) = \Phi(2\pi)) \\
\phi = -\pi: \ C_{1}\cos(\xi \cdot \pi) - C_{2}\sin(\xi\cdot \pi) = \\C_{1}\cos(\xi \cdot \pi) + C_{2}\sin(\xi \cdot \pi), \ (\Phi(-\pi) = \Phi(\pi))
\end{gather}$$

$$\begin{gather}
2C_{2}\sin(\xi \cdot \pi) = 0 \\
\left[\begin{matrix}
C_{2} = 0 \\
\sin(\xi \cdot \pi) = 0
\end{matrix}\right.
\end{gather}$$

$$\begin{gather}
1. \ C_{1} = \cos(\xi \cdot 2\pi) \implies \xi_{n} = n, \ n \in \mathbb{Z} \\
2. \ \xi\cdot \pi = \pi n \implies \xi_{n} = n, \ n \in \mathbb{Z}
\end{gather}$$

Линейно независимые решения:

> [!important] Этот результат можно использовать всегда
> $$\begin{gather}
\Phi_{n} = e^{in\phi}, \\
\xi_{n} = n, \ n \in \mathbb{Z}.
\end{gather}$$

$$\begin{gather}
r^{2}R'' + rR' + (\eta^{2}r^{2} - n^{2})R = 0 \\
\end{gather}$$

Используем замену $x = \eta r$:

$$\begin{gather}
x^{2}R'' + xR' + (x^{2} - n^{2})R = 0 \\
\end{gather}$$

Тогда 

$$\begin{gather}
R = C_{1}\cdot J_{n}(x) + \cancel{ {C_{2}Y_{n}(x)} }
\end{gather}$$

В таком разбиении функция Бесселя в нуле ограничена, а фукнция Неймана - нет, потому мы eё выбрасываем.

$$\begin{gather}
R(r) = C_{1}J_{n}(\eta r) \\
R(r_{0}) = 0, \\
R(r_{0}) = C_{1}J_{n}(\eta r_{0}) = 0, \\
\eta r_{0} = \mu^{(n)}_{m} \\
\end{gather}$$

$$\begin{gather}
R_{n,m}(r) = J_{n}\left( \frac{\mu_{m}^{(n)}r}{r_{0}} \right), \ \eta_{m} = \frac{\mu_{m}^{(n)}}{r_{0}}, \ m = 1,2,3,\dots
\end{gather}$$

$$\begin{gather}
T''_{n,m} + \left( \frac{\mu_{m}^{(n)}}{r_{0}}\cdot a  \right)^{2} T_{n,m} = 0
\end{gather}$$

$$\begin{gather}
T_{n,m} = A_{n,m}\cos\left( \frac{\mu_{m}^{(n)}a}{r_{0}}\cdot t \right) + B_{n,m}\sin\left( \frac{\mu_{m}^{(n)}a}{r_{0}} \cdot t \right) \\
\end{gather}$$

$$\begin{gather}
V = \sum_{n=-\infty}^{+\infty} \sum_{m=1}^{+\infty} \left( A_{n,m}\cos\left( \frac{\mu_{m}^{(n)}a}{r_{0}}t \right) + B_{n,m}\sin\left( \frac{\mu_{m}^{(n)}a}{r_{0}}t \right) \right) J_{n}\left( \frac{\mu_{m}^{(n)}r}{r_{0}} \right)e^{in\phi}
\end{gather}$$

$$\begin{gather}
V|_{t=0} = \sum_{n,m}A_{n,m}J_{n}\left( \frac{\mu_{m}^{(n)}r}{r_{0}} \right)e^{in\phi} = J_{0}\left( \frac{\mu_{34}^{(0)}r}{r_{0}} \right) e^{i\cdot 0 \cdot \phi} \\
\begin{cases}
A_{n,m} = 0, \ n \neq 0 \vee m \neq 34 \\
A_{0,34} = 1
\end{cases}
\end{gather}$$

$$\begin{gather}
V_{t}|_{t=0} = \sum_{n,m} B_{n,m}\cdot \frac{\mu_{m}^{(n)}a}{r_{0}}J_{n}\left( \frac{\mu_{m}^{(n)}r}{r_{0}} \right)e^{in\phi} = 0, \ \implies B_{n,m} = 0
\end{gather}$$

$$\begin{gather}
V = 1\cdot \cos\left( \frac{\mu_{34}^{(0)}a}{r_{0}}t \right)J_{0}\left( \frac{\mu_{34}^{(0)}r}{r_{0}} \right)
\end{gather}$$
