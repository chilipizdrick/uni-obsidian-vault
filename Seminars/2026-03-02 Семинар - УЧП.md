u(x,y,t) \\
\end{gather}$$

\frac{1}{a^{2}}u_{tt} - \Delta u = x^{2} + ty, \ x^{2} + y^{2} < r^{2}_{0}, \ t > 0 \\
u|_{x^{2}+y^{2} = r^{2}_{0}} = 0 \\

### 1. Переход к полярным координатам

$$\begin{gather}
\begin{cases}
x = r\cos \phi \\
y = r\sin \phi
\end{cases} \\
\Delta = \frac{1}{r} \frac{\partial }{\partial r}\left( r \frac{\partial}{\partial r} \right) + \frac{1}{r^{2}} \frac{\partial^{2}}{\partial \phi^{2}}
\end{gather}$$

$$\begin{cases}
\frac{1}{a^{2}}u_{tt} - \frac{1}{r}(ru_{r})_{r} - \frac{1}{r^{2}}u_{\phi \phi} = r^{2}\cos ^{2}\phi + tr\sin \phi, \ r < r_{0}, \ t > 0 \\
u|_{r=r_{0}} = 0 \\
r|_{t=0} = J_{0}\left( \frac{\mu_{32}^{(0)}r}{r_{0}} \right), \ u_{t}|_{t=0} = 0
\end{cases}$$
