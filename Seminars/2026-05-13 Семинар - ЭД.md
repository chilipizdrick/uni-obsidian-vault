## Пр. №14. Возбуждение прямоугольного волновода ЭЭИ.

1. Бесконечный волновод

$$\begin{gather}
\dot{\vec{E}}_{m} = \vec{y}^{0} \dot{\vec{E}}_{0}^{ст} \sin\left( \frac{\pi}{a} x_{0} \right) \sin\left( \frac{\pi}{a} x \right) e^{-i \Gamma_{o} |z-z_{0}|} \\
\dot{\vec{H}}_{m} = \frac{\dot{E}_{0}^{ст}}{\dot{W}_{0}} \sin\left( \frac{\pi}{a} x_{0} \right)\left( \pm \vec{x}^{0} \sin \left( \frac{\pi}{a}x \right) + \vec{z}^{0}i \frac{\pi}{\Gamma_{o}a} \cos \left( \frac{\pi}{a} x \right) \right) e^{-i \Gamma_{o} |z-z_{o}|}
\end{gather}$$

$$\begin{gather}
\Gamma_{o} = k \sqrt{ 1- \left( \frac{\lambda}{2a} \right)^{2} } \\
W_{o} = \frac{\omega \mu_{a}}{\Gamma_{o}} = \frac{W}{\sqrt{ 1- \left( \frac{\lambda}{2a} \right)^{2} }}, \ W = \sqrt{ \frac{\mu_{a}}{\epsilon_{a}} }
\end{gather}$$

2. Полубесконечный волновод

$$\begin{gather}
\dot{\vec{E}}_{m} = \dot{\vec{E}}_{m} ^{(0)} + \dot{\vec{E}}_{m}^{(-)} = \vec{y}^{0} \dot{E}_{o}
\end{gather}$$
