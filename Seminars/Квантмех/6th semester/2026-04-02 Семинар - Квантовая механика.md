### Импульсное и координатное представления в квантовой механике

$$\begin{gather}
\ket{\Psi}  - 
\end{gather}$$

1. $\ket{\Psi}$ - абстрактный вектор в Гильбертовом пространстве.
2. $\ket{x}$ - базич из составляющих с определенной координатой
3. $\ket{p}$ - базич из составляющих с определенным импульсом
4. $\Psi(x) = \braket{ x | \Psi }$ - волновая ф. в коорд. представлении
5. $\Psi(p) = \braket{ p | \Psi }$ - волновая ф. в импульсном представлении

$$\begin{gather}
\hat{1} = \int_{-\infty}^{+\infty}\ket{x} \bra{x}   \, dx 
\end{gather}$$

$$\begin{gather}
\braket{ p | \Psi } = \int_{-\infty}^{+\infty} \braket{ p | x } \braket{ x | \Psi }  \, dx \\
\Psi(p) = \int_{-\infty}^{+\infty} \braket{ p | x } \Psi(x)  \, dx
\end{gather}$$

$$\begin{gather}
\braket{ p | x }  = \overline{\braket{ x | p } } = \overline{\Psi_{p}(x)}
\end{gather}$$
 волновая функция состояния с опредленным импульсом, т.е. собственная для оператора:
$$\begin{gather}
\hat{p} = -i\hbar \frac{ \partial  }{ \partial x } 
\end{gather}$$

$$\begin{gather}
\Psi(p) = \frac{1}{\sqrt{ 2\pi }} \int_{-\infty}^{+\infty} e^{-\frac{i}{\hbar}px} \Psi(x) \, dx \\
\Psi(x) = \frac{1}{\sqrt{ 2\pi }} \int_{-\infty}^{+\infty} e^{\frac{i}{\hbar} px}\Psi(p) \, dp
\end{gather}$$

Получили преобразования фурье.

### Задача 1. Показать, что в импульсном представлении $\hat{p} = p$

$$\begin{gather}
\hat{p}\Psi(x) = -i\hbar \frac{ \partial  }{ \partial x } \frac{1}{\sqrt{ 2\pi }} \int_{-\infty}^{+\infty} e^{\frac{i}{\hbar}px}\Psi(p) \, dp = \\
-\frac{i\hbar}{\sqrt{ 2\pi }} \int_{-\infty}^{+\infty} \frac{ip}{\hbar} e^{\frac{i}{\hbar}px} \Psi(p) \, dp = \\
= \frac{1}{\sqrt{ 2\pi }}\int_{-\infty}^{+\infty} e^{\frac{i}{\hbar}px}(p\Psi(p)) \, dp
\end{gather}$$

### Оператор эволюции и уравнение Шреденгера.

Макрковский процесс для амплитуды вероятности.

$$\Psi(x,t) = \hat{U}(t,t_{0})\Psi(x,t_{0})$$

$t_{0}$ - настоящее, $t$ - будущее.

$$\begin{gather}
\hat{U}(t,t) = 1 \\
\hat{U}(t + \delta t, t) = 1 - i \hat{H}(t)\Delta t + o(\Delta t)
\end{gather}$$

$\hat{H}^{\dagger} = \hat{H}$ - гамильтониан.

$$\begin{gather}
i\hbar \frac{ \partial \Psi }{ \partial x } = \hat{H}\Psi 
\end{gather}$$

$$\begin{gather}
\hat{H} = \underbrace{\frac{p^{2}}{2m}}_{кин. \ эн} + \underbrace{V(x)}_{пот. \ эн.}
\end{gather}$$

$$\begin{gather}
\underbrace{ \hat{E}}_{опер. эн.} \Psi = \underbrace{\hat{H}}_{эн., \ выраж. \ через \ \hat{x} \ и \ \hat{p}} \Psi
\end{gather}$$

Стационарное уравнение Шредингера - для состояния с определенной энергией: ;$\hat{E} \Psi = E \Psi$

$$\begin{gather}
\hat{H}\Psi = E \Psi - \text{стац. ур. Шредингера}
\end{gather}$$

Уравнение на собственное значение оператора $\hat{H}$.

$$\begin{gather}
\hat{E} = i\hbar \frac{ \partial }{ \partial t }  \\
\hat{p}_{i} = -i\hbar \frac{ \partial  }{ \partial x_{i} } 
\end{gather}$$

$$\begin{gather}
\hat{E}\Psi(x,t) = i\hbar \frac{ \partial  }{ \partial t }  = E\Psi(x,t) \implies \\
\implies \Psi(x,t) = \Psi(x)e^{-\frac{i}{\hbar} Et}
\end{gather}$$

### Задача 1. Стационарное решение свободного уравнения 

$$\begin{gather}
V(x) \equiv 0 \\
\end{gather}$$

$$\begin{gather}
i\hbar \frac{ \partial \Psi }{ \partial t } = \frac{\hat{p}^{2}}{2m}\Psi(x,t) \\
\hat{H}\Psi = E \Psi \\
\frac{\hat{p}^{2}}{2m} \Psi = E\Psi
\end{gather}$$

$$\begin{gather}
-\frac{\hbar^{2}}{2m}\frac{ \partial^{2}  }{ \partial x^{2} } \Psi = E \Psi
\end{gather}$$

$$\begin{gather}
\frac{ \partial^{2} }{ \partial x^{2} } \Psi = -\frac{2mE}{\hbar^{2}}\Psi
\end{gather}$$

$$\begin{gather}
k^{2} = \frac{2mE}{\hbar^{2}} \\
\frac{ \partial^{2} }{ \partial x^{2} } \Psi = -k^{2}\Psi \\
\Psi(x) = Ae^{ikx} + Be^{-ikx}
\end{gather}$$

$$\begin{gather}
\frac{E}{\hbar} = \omega \\
\Psi(x,t) = \Psi(x)e^{-i\omega t} = Ae^{i(-\omega k+kx)} + Be^{-i(\omega t+kx)} \\
p_{1} = \sqrt{ 2mE }, \ p_{2} = -\sqrt{ 2mE }
\end{gather}$$

Получили состояния с определенным (с точностью до знака) импульсом.
