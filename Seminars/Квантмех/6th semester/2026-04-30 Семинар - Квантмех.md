$\Delta x$ в состоянии $\ket{\Psi_{n}}$.

$$\begin{gather}
\hat{x} = i\sqrt{ \frac{\hbar}{2m\omega} }(\hat{a} - \hat{a}^{\dagger}) \\
\hat{x}^{2} = -\frac{\hbar}{2m\omega}(\hat{a} - \hat{a}^{\dagger})^{2} \\
(\Delta x)^{2} = \braket{ \Psi_{n} | \hat{x}^{2} | \Psi_{n}  }  - \braket{ \Psi_{n} | \hat{x} | \Psi_{n} }^{2}
\end{gather}$$

$$\begin{gather}
\braket{ \Psi_{n} | \hat{x} | \Psi_{n} }  = i \sqrt{ \frac{\hbar}{2m\omega} }\braket{ \Psi_{n} | (\hat{a} - \hat{a}^{\dagger}) | \Psi_{n} } = 0
\end{gather}$$

$$\begin{gather}
\braket{ \Psi_{n} | \hat{x}^{2} | \Psi_{n} }  = \dots\braket{ \Psi_{n} | - \hat{a}\hat{a}^{\dagger} - \hat{a}^{\dagger}\hat{a} | \Psi_{n} } = (-2n-1)\left( -\frac{\hbar}{2m\omega} \right)
\end{gather}$$

$$\begin{gather}
(\Delta x)^{2} = \frac{(2n+1)\hbar}{2m\omega}
\end{gather}$$

## Когерентные состояния гармонического осцилятора

$\hat{a}\ket{\Psi_{z}} = z\ket{\Psi_{z}}$, где $z \in \mathbb{C}$.

$$\braket{ \Psi_{n} | \Psi_{z} } = \frac{z^{n}}{\sqrt{ n! }}e^{-\frac{|z|^{2}}{2}}$$

$$\begin{gather}
\braket{ \Psi_{u} | \Psi_{z} }  = \exp \left( \overline{u}z - \frac{|z|^{2}}{2} - \frac{|u|^{2}}{2} \right) 
\end{gather}$$

### Физ. смысл параметра $z$

$$\begin{gather}
\langle x \rangle = \braket{ \Psi_{z} | \hat{x} | \Psi_{z} } = \braket{ \Psi_{z} | i\sqrt{ \frac{\hbar}{2m\omega} }(\hat{a} - \hat{a}^{\dagger}) | \Psi_{z} } = \\
= i\sqrt{ \frac{\hbar}{2m\omega} }(z - \bar{z}) \braket{ \Psi_{z} | \Psi_{z} }  = i\sqrt{ \frac{\hbar}{2m\omega} }(z - \bar{z}) = i \sqrt{ 2\frac{\hbar}{m\omega} } \mathrm{Im} \, z
\end{gather}$$

$$\begin{gather}
\langle p \rangle = \braket{ \Psi_{n} | \frac{\sqrt{ 2m\hbar\omega }}{2} (\hat{a}^{\dagger} + \hat{a}) | \Psi_{n} } = \sqrt{ 2m\omega \hbar } \cdot \mathrm{Re} \, z
\end{gather}$$

$$\begin{gather}
z = \frac{\langle p \rangle}{\sqrt{ 2m\omega \hbar }} - i \frac{\langle x \rangle\sqrt{ 2m\omega }}{\sqrt{ \hbar }}
\end{gather}$$

### Энергия в когерентных состояниях

$$\begin{gather}
\langle E \rangle = \braket{ \Psi_{z} | \hat{H} | \Psi_{z} }  = \frac{1}{2}\omega \hbar \braket{ \Psi_{z} | (\hat{a}^{\dagger}\hat{a} + \hat{a} \hat{a}^{\dagger}) | \Psi_{z} }  \\
\braket{ \Psi_{z} | \frac{1}{2}\omega \hbar (1 + 2 \hat{a}^{\dagger}\hat{a}) | \Psi_{z} } 
\end{gather}$$

$$\begin{gather}
\frac{1}{2}\omega \hbar (1 + 2 \braket{ \Psi_{z} | \hat{a}^{\dagger}\hat{a} | \Psi_{z} } ) = \frac{1}{2}\omega \hbar(1 + 2|z|^{2})
\end{gather}$$

$$\begin{gather}
|z|^{2} = \frac{1}{2}\omega \hbar + \omega \hbar\left( \frac{1}{2m\omega \hbar}\langle p \rangle + \frac{m\omega}{\hbar}\langle x \rangle^{2} \right) = \frac{1}{2}\omega \hbar + \underbrace{\frac{\langle p \rangle^{2}}{2m}}_{\text{кин. эн.}} + \underbrace{\frac{\langle x \rangle^{2}m\omega^{2}}{2}}_{\text{пот. эн.}}
\end{gather}$$

### Изменение среднего со временем

$$\begin{gather}
\langle A \rangle = \braket{ \Psi | \hat{A} | \Psi } \\
\hat{A} - \text{явно не зависит от времени} \\
\frac{d}{dt}\langle A \rangle = \frac{i}{\hbar}\braket{ \Psi | \left[ \hat{H}, \hat{A} \right] | \Psi } 
\end{gather}$$
