## Гармонический осцилятор

$$\begin{gather}
\hat{H} = \frac{\hat{p}^{2}}{2m} + \frac{m\omega^{2}x^{2}}{2}
\end{gather}$$

$\omega$ -  частота осцилятора, $m$ - масса.

Ищем стационарное решение (решение с определеноой $E$):

$$\begin{gather}
\hat{H} \Psi = E \Psi
\end{gather}$$

![[2026-04-16 Семинар - Квантмех 2026-04-16 13.14.29.excalidraw]]

$$\begin{gather}
E_{n} = \left( \frac{1}{2} + n \right)\omega \hbar \\
\Psi_{n} = c_{n}e^{\frac{-\lambda x^{2}}{2}} H_{n}(\sqrt{ \lambda }x), \ x = 0,1,2,\dots
\end{gather}$$

$$\begin{gather}
\lambda = \frac{m\omega}{\hbar} \\
H_{n} - \text{многочлен эрмита}, \ H_{n}(x) = (-1)^{n}e^{x^{2}} \frac{d^{n}}{dx^{n}} e^{-x^{2}}
\end{gather}$$

### Операторы рождения и уничтожения (лестничные операторы)

$$\begin{gather}
\hat{a} = \frac{1}{\sqrt{ 2m\hbar\omega }} (\hat{p} - i\omega mx) \\
\hat{a}^{\dagger} = \frac{1}{\sqrt{ 2m\hbar\omega }}(\hat{p} + i\omega mx)
\end{gather}$$

$$\begin{gather}
\left[ \hat{a}, \hat{a}^{\dagger} \right] = \underbrace{\frac{1}{2m\hbar\omega}}_{\alpha} \left[ \hat{p} - i\omega mx, \hat{p} + i\omega mx \right] = \dots = \\
= \frac{1}{m\hbar\omega} \left[ \hat{p}, i\omega mx \right] = \frac{i}{\hbar} \left[ \hat{p}, x \right]  = 1
\end{gather}$$

Получили прятное следствие:

$$\begin{gather}
\left[ \hat{a}, \hat{a}^{\dagger} \right] = 1
\end{gather}$$

$$\begin{gather}
\hat{H} = \frac{\hat{p}^{2}}{2m} + \frac{m\omega^{2} x^{2}}{2}  =\frac{1}{2}\omega \hbar(\hat{a}^{\dagger}\hat{a} + \hat{a}\hat{a}^{\dagger})
\end{gather}$$

$$\begin{gather}
\underbrace{\hat{a}^{\dagger}\hat{a}}_{\text{оператор номера уровня}} \ket{\Psi_{n}}   = n \ket{\Psi_{n}} 
\end{gather}$$

$$\begin{gather}
\hat{a}\ket{\Psi_{n}}  = ? \\
\hat{a}^{\dagger}\hat{a}\left( \hat{a}\ket{\Psi_{n}}  \right)  = \left( \hat{a}\hat{a}^{\dagger} - 1 \right) \hat{a}\ket{\Psi_{n}} = \hat{a}\hat{a}^{\dagger}\hat{a} \ket{\Psi_{n}}  - \hat{a}\ket{\Psi}_{n} = \\
= \hat{a}(n-1)\ket{\Psi_{n}} = (n-1)\hat{a}\ket{\Psi_{n}} 
\end{gather}$$

$$\begin{gather}
\implies \hat{a} \ket{\Psi_{n}} = c_{n}\ket{\Psi_{n-1}} 
\end{gather}$$

$$\begin{gather}
\braket{ \Psi_{n-1} | \bar{c}_{n} c_{n} | \Psi_{n-1}  } = \braket{ \Psi_{n} | \hat{a}^{\dagger}\hat{a}| \Psi_{n} } = \braket{ \Psi_{n} | n | \Psi_{n} } \\
|c_{n}|^{2} = n \\
c_{n} = \frac{1}{\sqrt{ n }}
\end{gather}$$

$$\begin{gather}
\hat{a}\ket{\Psi_{n}} = \frac{1}{\sqrt{ n }} \ket{\Psi_{n-1} } \\
\hat{a}^{\dagger}\ket{\Psi_{n}} = \frac{1}{\sqrt{ n+1 }} \ket{\Psi_{n+1}} 
\end{gather}$$

$$\begin{gather}
\hat{p} = \frac{\sqrt{ 2m\hbar\omega }}{2} (\hat{a}^{\dagger} + \hat{a}) \\
\hat{x} = i\sqrt{ \frac{\hbar}{2m\omega} } (\hat{a} - \hat{a}^{\dagger})
\end{gather}$$

$$\begin{gather}
\braket{ \Psi_{n} | \Psi_{n'} }  = \delta_{nn'} \\
\ket{\Psi_{n}} - \text{ортонорм. базис}, n = 0,1,2,\dots \\
\braket{ \Psi_{n} | \hat{a} | \Psi_{n}  } =  \braket{ \Psi_{n} | \frac{1}{\sqrt{ n }} | \Psi_{n-1} } = 0
\end{gather}$$

Также $\braket{ \Psi_{n} | \hat{x} | \Psi_{n} } = 0$.

$$\begin{gather}
\braket{ \Psi_{n} | (\hat{a} + \hat{a}^{\dagger})^{2} | \Psi_{n} } = \braket{ \Psi_{n} | \hat{a}^{2} + \hat{a}\hat{a}^{\dagger} + \hat{a}^{\dagger}\hat{a} + (\hat{a}^{\dagger})^{2} | \Psi_{n} } = \\
= \braket{ \Psi_{n} | \hat{a}\hat{a}^{\dagger} + \hat{a}^{\dagger} \hat{a} | \Psi_{n} } = \braket{ \Psi_{n}| 1 + 2\hat{a}^{\dagger}\hat{a} | \Psi_{n} }  = \\
= \braket{ \Psi_{n} | \Psi_{n} }  + 2n\braket{ \Psi_{n} | \Psi_{n} } = 1 + 2n
\end{gather}$$

$$\begin{gather}
\braket{ \Psi_{n} | (\hat{a} + \hat{a}^{\dagger})^{3} | \Psi_{n} } = 0
\end{gather}$$
