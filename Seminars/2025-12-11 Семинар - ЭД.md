## Принцип двойственности. Электромагнитное поле элементарного магнитного поля. Поле в дальней зоне


$$\begin{gather}
\dot{\vec{E}}^{м}_{m} = -\dot{\vec{H}}^{э}_{m} \ (\dot{\vec{j}}^{э.ст}_{m} \implies \dot{\vec{j}}_{m}^{м.ст}) \\
\end{gather}$$

$$\begin{gather}
\dot{\vec{H}}_{m}^{м} = \frac{\dot{\epsilon}_{a}}{\mu_{a}}\dot{\vec{E}}^{э}_{m} \ (\dot{\vec{j}}^{э.ст}_{m} \implies \dot{\vec{j}}_{m}^{м.ст})
\end{gather}$$

$$\begin{gather}
\dot{\vec{A}}_{m}^{м} = \dot{\vec{A}}_{m}^{э} \ (\dot{\vec{j}}^{э.ст}_{m} \implies \dot{\vec{j}}_{m}^{м.ст})
\end{gather}$$

$$\dot{\vec{j}}^{м.ст}_{m} - \text{объемная плотность магнитного стороннего тока}$$

Магнитные сторонние токи формально введены во второе уравнение электродинамики.

$$\begin{cases}
\mathrm{rot} \ \dot{\vec{H}}_{m} = i\omega\dot{\epsilon}_{a} \dot{\vec{E}}_{m} + \dot{\vec{j}}^{э.ст} \\
\mathrm{rot} \ \dot{\vec{E}}_{m} = -i\omega\mu_{a} \dot{\vec{H}}_{m} - \dot{\vec{j}}_{m}^{м.ст}
\end{cases}$$

Рассмотрим элементарный магнитный излучатель, расположенный в начале координат, с моментом направленным по оси $Oz$.

$$\begin{gather}
\dot{\vec{\mathrm{p}}}^{м.ст}_{m} = \dot{I}_{m}^{ст} \vec{l}^{м}, \ \vec{l} = \vec{z}^{0} l^{M}
\end{gather}$$

Условия элементарности такого излучателя - такие же, как и для элементарного электричского излучателя.

Короткий, прямолинейный отрезок линейного магнитного тока, который протекает по этому отрезку с постоянной амплитудой.

Формулы для элементарного электрического излучателя.

$\dot{\vec{A}}_{m\perp}$ - поперечная составляющая векторного потенциала.

Используя принцип двойственности получем выражение для характеристик элементарного магнитного излучателя.

$$\begin{gather}
\dot{\vec{E}}^{м}_{m} = -\dot{\vec{H}}^{э}_{m} = -(\mathrm{rot} \ A)
\end{gather}$$

Элементарный рамочный излучатель является физической реализацией элементарного магнитного излучателя.

Найдем амплитуды направленности:

$$\begin{gather}
r = \tilde{E}_{m}(\theta, \alpha), \ 0 \leq \theta \leq 180^{\circ}, \ 0 \leq \alpha \leq 360^{\circ} \\
\tilde{E}_{m}(\theta, \alpha) = \sin \theta
\end{gather}$$

## 15. Примеры решения зачетных задач

Найти электромагнитное поле 2ух элементарных излучателей, расположенных в одной точке - в начале координат.
1. Элементарный электрический излучатель
2. Элементарный магнитный излучатель

Определить $$\begin{gather}
\dot{\vec{E}}_{m} = \dot{\vec{E}}_{m}^{э} + \dot{\vec{E}}_{m}^{м}, \ \dot{\vec{H}}_{m}|_{Д.З} = \frac{1}{W} \left[\vec{r}^{0}, \dot{\vec{E}}\right] \\
\end{gather}$$
$$\begin{gather}
\mathrm{p}^{э.ст}_{m} = -\vec{x}^{0}I^{э.ст}_{m}l^{э} \\
\mathrm{p}^{м.ст}_{m} = -\vec{y}^{0}I^{м.ст}_{m}l^{м}
\end{gather}$$

$$\begin{gather}
\dot{\vec{A}}_{m}^{э} = \mathrm{p}^{э.ст}_{m}G(r) = -\vec{x}^{0}I^{э.ст}_{m}l^{э}G(r) \\
\dot{\vec{A}}_{m}^{м} = \mathrm{p}^{м.ст}_{m}G(r) = -\vec{y}^{0}I^{м.ст}_{m}l^{м}G(r) \\
\end{gather}$$

$$\begin{gather}
\dot{\vec{E}}_{m}^{э}|_{Д.З.} = -ikW \dot{\vec{A}}_{m\perp}^{э} \\
\dot{\vec{E}}_{m}^{м} = -\dot{\vec{H}}_{m}^{э} = -\mathrm{rot} \dot{\vec{A}}_{m}^{м} = ik \left[ \vec{r}^{0}, \dot{\vec{A}}_{m}^{м} \right] \\
\end{gather}$$

$$\begin{gather}
\begin{cases}
\vec{x}^{0} = (\vec{r}^{0}\sin \theta + \vec{\theta}^{0}\cos \theta)\cos\alpha - \vec{\alpha}^{0}\sin \alpha \\
\vec{y}^{0} = (\vec{r}^{0}\sin \theta + \vec{\theta}^{0}\cos \theta)\sin\alpha + \vec{\alpha}^{0}\cos \alpha \\
\end{cases}
\end{gather}$$

$$\begin{gather}
\dot{\vec{E}}_{m}^{э} = (-\vec{\theta}^{0} \cos \theta \cos\alpha + \vec{\alpha}^{0}\sin\alpha)Wi\dot{I}_{m}^{э.ст}kl^{э} G(r)
\end{gather}$$

$$\begin{gather}
\dot{\vec{E}}_{m}^{м} = ik\left[ \vec{r}^{0}, \vec{A}_{m}^{м} \right] = \\
= ik\left[\vec{r}^{0}, (-\vec{r}^{0}\sin \theta \cos\alpha - \vec{\theta}^{0}\cos \theta\cos\alpha - \vec{\alpha}^{0}\cos\alpha) \dot{I}_{m}^{м.ст} l^{м} G(r)\right] = \\
\end{gather}$$

$$\begin{gather}
= (-\vec{\alpha}^{0}\cos \theta \cos\alpha + \vec{\theta}^{0} \cos\alpha)i\dot{I}_{m}^{м.ст}kl^{м}G(r)
\end{gather}$$

$$\begin{gather}
\dot{\vec{E}}_{m} = (-\vec{\theta}^{0} \cos \theta \cos\alpha + \vec{\alpha}^{0} \sin\alpha) W i \dot{I}_{m}^{э.ст} k l^{э} G(r) + \\
+ (-\vec{\alpha}^{0}\cos \theta \cos\alpha + \vec{\theta}^{0} \cos\alpha) i \dot{I}_{m}^{м.ст} k l^{м} G(r) = \\
= ikE_{0}(\vec{\theta}^{0}\cos \theta \cos\alpha - \vec{\alpha}^{0}\sin\alpha)
\end{gather}$$

$$\begin{gather}
\dot{\vec{H}}_{m}^{м} = \frac{\dot{\epsilon}_{a}}{\mu_{a}}\dot{\vec{E}}^{э}_{m} \\
\dot{\vec{E}}_{m}^{э} = \dot{W}^{2}\dot{\vec{H}}_{m}^{м} \\
\end{gather}$$

$$\begin{gather}
\dot{\vec{H}}_{m}^{м} = \frac{1}{\dot{W}}\left[ \vec{r}^{0},\dot{\vec{E}}_{m}^{м} \right] 
\end{gather}$$
