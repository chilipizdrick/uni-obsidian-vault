### К/р
1. Теорема об изменении кинетической энергии + к данной схеме составить уравнение Лагранжа.

$$\begin{gather}
\begin{cases}
\frac{d}{dt}\left[ \frac{ \partial T }{ \partial \dot{q}_{1} }  \right] - \frac{ \partial T }{ \partial q_{1} } = Q_{1}, \\
\frac{d}{dt}\left[ \frac{ \partial T }{ \partial \dot{q}_{2} }  \right] - \frac{ \partial T }{ \partial q_{2} } = Q_{2}, \\
\dots \\
\frac{d}{dt}\left[ \frac{ \partial T }{ \partial \dot{q}_{n} }  \right] - \frac{ \partial T }{ \partial q_{n} } = Q_{n}, \\
\end{cases}
\end{gather}$$

где $T$ - кинетическая энергия системы, $\dot{q}_{1},\dot{q}_{2},...,\dot{q}_{n}$ - обобщенные скорости системы, $q_{1},q_{2},\dots,q_{n}$ -  обобщенные координаты системы, $Q_{1}, Q_{2},\dots,Q_{n}$ - обобщенные силы системы.

### Задача 1

![[2026-05-13 Семинар - Механика 2026-05-13 14.34.00.excalidraw]]

$$\begin{gather}
m_{1},m_{2}, m_{3} \\
R, r, M, c \\
\hline \text{ур-я Лагранжа}
\end{gather}$$

$$\begin{gather}
J_{O} = \frac{m_{2}r^{2}}{2} \\
\omega_{2} = \frac{v_{1}}{r} = \frac{\dot{x}_{1}}{r} \\
\dot{x}_{B} = \frac{\dot{x}_{1}}{2} \\
\omega_{3} = \frac{\dot{x}_{B}}{R} = \frac{\dot{x}_{1}}{2R} \\
J_{B} = \frac{m_{3}R^{2}}{2}
\end{gather}$$

$$\begin{gather}
T = T_{1} + T_{2} + T_{3} \\
T_{1} = \frac{m_{1}v_{1}^{2}}{2} = \frac{m_{1}\dot{x}^{2}_{1}}{2}
\end{gather}$$

$$\begin{gather}
T_{2} = \frac{J_{O}\omega_{2}^{2}}{2} = \frac{m_{2}r^{2}\dot{x}_{1}^{2}}{4r^{2}} = \frac{m_{2}\dot{x}_{1}}{4}
\end{gather}$$


$$\begin{gather}
T_{3} = \frac{m_{3}v^{2}_{B}}{2} + \frac{J_{B}\omega_{3}^{2}}{2} = \frac{m_{3}\dot{x}_{1}}{8} + \frac{m_{3}R^{2}\dot{x}_{1}}{16R^{2}} = \frac{3m_{3}\dot{x}_{1}^{2}}{16}
\end{gather}$$

$$\begin{gather}
T = \left( \frac{m_{1}}{2} + \frac{m_{2}}{4} + \frac{3m_{3}}{16} \right) \dot{x}_{1}^{2} \\
\end{gather}$$

$$\begin{gather}
\frac{ \partial T }{ \partial \dot{x}_{1} } = 2\left( \frac{m_{1}}{2} + \frac{m_{2}}{4} + \frac{3m_{3}}{16} \right) \dot{x}_{1} \\
\frac{\partial T}{\partial \dot{x}_{1}} = 0 \\
\frac{d}{dt} \frac{ \partial T }{ \partial \dot{x}_{1} }  = 2\left( \frac{m_{1}}{2} + \frac{m_{2}}{4} + \frac{3m_{3}}{16} \right) \ddot{x}_{1}
\end{gather}$$

$$\begin{gather}
\delta A_{P_{1}} = P_{1} \delta x_{1} \\
\delta A_{P_{2}} = \delta A_{P_{3}} = 0 \\
\delta A_{M} = M\delta \phi_{2} = M\frac{\delta x_{1}}{r} \\
\delta A_{F} = -c (\delta_{ст} +  x_{B}) \delta x_{B} = -c\left( \delta_{ст} + \frac{x_{1}}{2} \right) \frac{\delta x_{1}}{2} \\
\end{gather}$$

$$\begin{gather}
\sum \delta A_{k} = \left( \underbrace{P_{1} + \frac{M}{r}  - \frac{c\delta_{ст}}{2}}_{0} - \frac{cx_{1}}{4} \right)\delta x_{1} = \underbrace{-\frac{c}{4} x_{1}}_{Q_{1}} \delta x_{1}
\end{gather}$$

$$\begin{gather}
Q_{1} = -\frac{c}{4}x_{1} \\
\end{gather}$$

Получаем уравнение Лагранжа:

$$\begin{gather}
2\left( \frac{m_{1}}{2} + \frac{m_{2}}{4} + \frac{3m_{3}}{16} \right) \ddot{x}_{1} = -\frac{c}{4} x_{1}
\end{gather}$$
