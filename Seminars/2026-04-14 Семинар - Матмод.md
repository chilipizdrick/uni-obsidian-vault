## Спинодальный распад. Уравнение Кана-Хиллиарда

$$\begin{gather}
\frac{ \partial c }{ \partial t } = D \Delta (\underbrace{c^{3} - c - \gamma \Delta c}_{\mu}),
\end{gather}$$

где $c$ - локальная относительная концентрация двух фаз - $\alpha'$ и $\alpha''$, $D$ - коэффициент диффузии, $\left[ \frac{L^{2}}{T} \right]$, $\sqrt{ \gamma }$ - длина области перехода между двумя фазами, $\mu$ - иногда называют химический потенциал.

Выводится из трех "законов":

1. Закон сохранения массы:

$$\begin{gather}
\frac{ \partial c }{ \partial t }  = -\nabla \cdot \mathbf{J},
\end{gather}$$

где $\frac{ \partial c }{ \partial t }$ - изменение концентрации в точке со временем, $\mathbf{J}$ - поток частиц (атомов в данном случае).

2. Движущая сила

$$\begin{gather}
\mathbf{J} = -M \nabla \mu,
\end{gather}$$

где $\mu$ - химический потенциал (атомы движутся из областей с высоким химическим потенциалом с области с низким химическим потенциалом, чтобы минимизировать энергию системы), $M$ - мобильнось индивидуальных частиц системы.

3. Описание энергии смеси (сплава):

$$\begin{gather}
\mu = \frac{df}{dc} - \kappa_{1} \Delta c
\end{gather}$$
