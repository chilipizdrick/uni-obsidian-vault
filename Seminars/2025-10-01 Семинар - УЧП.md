### 1)

Пусть
$$\begin{gather}
u = X(x)Y(y) \\
X''Y + XY'' = 0 \\
\end{gather}$$

Тогда
$$\begin{gather}
\frac{X''}{X} + \frac{Y''}{Y} = 0, \ \frac{X''}{X} = -\frac{Y''}{Y} = \lambda = \mathrm{const}
\end{gather}$$

$$\begin{gather}
\lambda = -\mu^{2} \\
\begin{cases}
\frac{X''}{X} = -\mu^{2} \\
\frac{Y''}{Y} = \mu^{2} \\
\end{cases}
\end{gather}$$

$$\left[ \begin{align}
X'' + \mu^{2}X = 0 \\
Y'' - \mu^{2}Y = 0
\end{align} \right.$$

$$\begin{gather}
u_{xx} - 2u_{x} + u_{yy} = 0 \\
X''Y - 2X'Y + XY'' = 0 \\
\frac{X''}{X} -2\frac{X'}{X} + \frac{Y''}{Y} = 0 \\
\frac{X''}{X} -2\frac{X'}{X} = -\frac{Y''}{Y} = \lambda = \mathrm{const} \\
\lambda = -\mu^{2} \\
\end{gather}$$

$$\begin{gather}
X'' = \mu^{2} X = 0 \\
X(x) = C_{1}\sin(\mu x) + C_{2}\cos(\mu x)
\end{gather}$$

$$\begin{gather}
u(0,y) = 0 \implies X(0) = 0 \\
u_{x}(2,y) = 0 \implies X'(2) = 0 \\
X(0) = C_{2} = 0 \\
X'(2) = C_{1}\mu \cos(\mu 2)  = 0, \ C_{1} \neq 0, \ \mu \neq 0
\end{gather}$$

$$\begin{gather}
2\mu = \frac{\pi}{2} + \pi n, \ n \in\mathbb{Z} \\
\mu_{n} = \frac{\pi}{4}(1+2n), \ n \in \mathbb{Z} \\
X_{n}(x) = C_{1,n}\sin\left( \frac{\pi}{4}(1+2n)x \right), \ n \in \mathbb{Z} \\
\end{gather}$$
