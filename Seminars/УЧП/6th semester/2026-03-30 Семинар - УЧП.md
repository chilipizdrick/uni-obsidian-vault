### Формула Даламбера (продолжение)

$$\begin{gather}
u_{tt} - a^{2}u_{xx} = f(x,t), x > 0, \ t > 0, \\
u_{x}(0, t) = 0, u(x,0) = \phi(x), \ u_{t}(x,0) = \psi(x)
\end{gather}$$

![[2026-03-30 Семинар - УЧП 2026-03-30 10.42.24.excalidraw]]

Построим четное продолжение функции для данного случая на $x<0$. Для таких функций в нуле производная равна нулю, что необходимо нам для удовлетворения начальных условий.

$$\begin{gather}
u(x,t) = \frac{\phi(x+at) + \phi(x-at)}{2} + \frac{1}{2a}\int_{x- at}^{x+at} \tilde{\psi}(\xi)\, d\xi + \\
+ \frac{1}{2a}\int _{0}^{t} d\tau \int_{-x-a(t-\tau)}^{-x+a(t-\tau)} d\xi \cdot \tilde{f}(\xi,\tau) = \frac{\tilde{\phi}(x-at)+\tilde{\phi}(x+at)}{2} + \\
= + \frac{1}{2a} \int_{x+at}^{x-at} \tilde{\psi}(-\tilde{\xi})(-1) \, d\xi  + \\
+ \frac{1}{2a} \int_{0}^{t} d\tau \int_{x+a(t-\tau)}^{x-a(t-\tau)} \tilde{f}(-\tilde{\xi},\tau)(-1) \, d \tilde{\xi} = u(x,t)
\end{gather}$$

И эта штука приведет нас к изначальной формуле в силу четности функций. => Можно использовать четные продолжения функций в ходе решения таких задач.
