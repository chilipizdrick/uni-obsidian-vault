## Формула Пуассона

$$\begin{gather}
n = 2 \\
\begin{cases}
u_{tt} + a^{2}\Delta u = f(x,y,t), \ (x,y)\in \mathbb{R}, t > 0 \\
u|_{t=0} = \phi(x,y), \ u_{t}|_{t=0} = \psi(x,y)
\end{cases}
\end{gather}$$

$$\begin{gather}
u(x,y,t) = \frac{1}{2\pi a} \frac{ \partial  }{ \partial t } \left( \iint_{r < at} \frac{\phi(\xi,\eta)d\xi d \eta}{\sqrt{ a^{2}t^{2} - r^{2} }}\right) + \frac{1}{2\pi a} \iint_{r<at} \frac{\psi(\xi,\eta)d\xi d \eta}{\sqrt{ a^{2}t^{2} - r^{2} }} + \\
+ \frac{1}{2\pi a} \int_{0}^{t} d\tau \iint_{r<a(t-\tau)} \frac{f(\xi,\eta,\tau)d\xi d \eta}{\sqrt{ a^{2}(t-\tau)^{2} - r^{2} }} \\

r^{2} = |\xi-x|^{2} + |\eta-y|^{2}
\end{gather}$$

### Задача 1

$$\begin{gather}
\begin{cases}
u_{tt} - \Delta u = 2 \\
u|_{t=0}=x, u_{t}|_{t=0} = y
\end{cases} \\
\end{gather}$$

$$\begin{gather}
a = 1 \\
\phi = x \\
\psi = y \\
f = 2 \\
\end{gather}$$
$$\begin{gather}
I_{1} = \iint_{r < t} \frac{\xi d\xi d \eta}{\sqrt{ t^{2}-r^{2} }} = \begin{bmatrix}
\xi = x + r\cos\alpha \\
\eta = y + r\sin\alpha
\end{bmatrix} = \\
= \int_{0}^{t}\int_{0}^{2\pi} \frac{r(x+r\cos\alpha)dr d\alpha}{\sqrt{ t^{2} - r ^{2} }} = \pi\int_{0}^{t} \frac{d(r^{2})x}{\sqrt{ t^{2} - r^{2} }} = \\
= \left.\pi x(-2 \sqrt{ t^{2} - r^{2} })\right|_{0}^{t} = 2\pi xt
\end{gather}$$

Лучше всегда переходить к полярным координатам и интегрировать по $\phi$ в первую очередь.

Второй интеграл аналогичен первому:

$$\begin{gather}
I_{2} = \iint_{r < t} \frac{\eta d\xi d \eta}{\sqrt{ t^{2} - r^{2} }} = \dots = 2\pi yt
\end{gather}$$

$$\begin{gather}
I_{3} = \int_{0}^{t} d\tau \iint_{r < t-\tau} \frac{f(\xi,\eta, \tau) d \xi d \tau}{\sqrt{ (t-\tau)^{2}-r^{2} }} = \\
= \int_{0}^{t} d\tau \int_{0}^{t-\tau}\int_{0}^{2\pi} \frac{2r dr d\alpha}{\sqrt{ (t-\tau)^{2} - r^{2} }} = \\
= \int_{0}^{t} \, d\tau \left(\left.-2\sqrt{ (t-\tau)^{2} - t^{2} }\right|_{0}^{t-\tau}\right) = 2\pi t^{2}
\end{gather}$$

$$\begin{gather}
u(x,y,t) = x + yt + t^{2}
\end{gather}$$

### Задача 2

$$\begin{gather}
\begin{cases}
u_{tt} - \Delta u = 8xyt \\
u|_{t=0} = x^{2} - y^{2}, \ u_{t}|_{t=0} = xy
\end{cases}
\end{gather}$$

$$\begin{gather}
u(x,y,t) = x^{2} - y^{2} + xyt + \frac{4}{3}xyt^{3}
\end{gather}$$

### Задача 3

$$\begin{gather}
\begin{cases}
u_{tt} -\Delta u = x^{3} - 3xy^{2} \\
u|_{t=0} = e^{x}\cos y, \ u_{t}|_{t=0} = e^{y}\sin x
\end{cases}
\end{gather}$$

Что делать, если несчитается? - Делить на части:


$$\begin{gather}
u = v + \phi + t \psi
\end{gather}$$

Тогда для $v$ все становится классно:

$$\begin{gather}
\begin{cases}
v_{tt} = \delta v = x^{3} - 3xy^{2} \\
v|_{t=0} = 0, \ v_{t}|_{t=0} = 0
\end{cases} \\
\end{gather}$$

### Замены

1. 

$$\begin{gather}
\Delta \phi = 0, \ \Delta \psi = 0 \implies \\
\implies u = v + \phi + t\psi
\end{gather}$$

Тогда

$$\begin{gather}
u|_{t=0} = v|_{t=0} + \phi + 0 \cdot \psi \implies v|_{t=0} = 0 \\
u_{t}|_{t=0} = v_{t}|_{t=0} + \psi \implies v_{t}|_{t=0} = 0
\end{gather}$$

2. 

$$\begin{gather}
f(x,y,t) = t^{n}g(x,y) \\ \Delta f = t^{n}\Delta g = 0 \\
u = v + \frac{t^{2}f}{(n+2)(n+1)} \\
v_{tt} - a^{2}\Delta v = 0
\end{gather}$$

$$\begin{gather}
u|_{t=0} = v|_{t=0} = \phi(x,y) \\
u_{t}|_{t=0} = v_{t}|_{t=0} = \psi(x,y) \\
\end{gather}$$

Итого полная замена, слагаемые включаются если они представлены гармооническими функциями.

$$\begin{gather}
u = v + \phi + t\psi + \frac{t^{2}f}{(n+2)(n+1)}
\end{gather}$$
