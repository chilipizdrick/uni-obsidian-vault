## Пр. №5. Вывод граничных условий электродинамики

![[2025-10-02 Семинар - ЭД 2025-10-02 16.19.00.excalidraw]]

$S$ - граница раздела 2-ух областей

$\epsilon_{a}$ - абслютная диэлектрическая проницаемость среды
$\mu_{a}$ - абслютная магнитная проницаемость среды

1. $\epsilon_{a1}, \ \mu_{a_{1}}, \ \sigma_{1}$
2. $\epsilon_{a_{2}}, \ \mu_{a2}, \ \sigma_{2}$

Условия:

1. $(\vec{D}_{1} - \vec{D}_{2})\vec{\nu}^{0} = \xi = \lim_{ \Delta S \to 0 } \frac{\Delta q}{\Delta S}$ 
2. $[\vec{\nu}^{0}, (\vec{E}_{1} - \vec{E}_{2})] = 0$
3. $(\vec{B}_{1} - \vec{B}_{2}) \vec{\nu}^{0} = 0$
4. $[\vec{\nu}^{0}, (\vec{H}_{1} - \vec{H}_{2})] = \vec{\eta} = \vec{\eta}^{0} \lim_{ \Delta l \to 0 } \frac{\Delta I}{\Delta l}, \ \Delta l \perp \vec{\eta}^{0}$

$\eta$ - поверхностная плотность электрического тока
