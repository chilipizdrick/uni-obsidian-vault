## Пр. №5. Вывод граничных условий электродинамики

![[2025-10-02 Семинар - ЭД 2025-10-02 16.19.00.excalidraw]]

$S$ - граница раздела 2-ух областей

$\epsilon_{a}$ - абслютная диэлектрическая проницаемость среды
$\mu_{a}$ - абслютная магнитная проницаемость среды

1. $\epsilon_{a1}, \ \mu_{a_{1}}, \ \sigma_{1}$
2. $\epsilon_{a_{2}}, \ \mu_{a2}, \ \sigma_{2}$

Условия:

1. $(\vec{D}_{1} - \vec{D}_{2})\vec{\nu}^{0} = \xi = \lim_{ \Delta S \to 0 } \frac{\Delta q}{\Delta S}$ - нормальная составляющая вектора электрической индукции непрерывна ($\xi = 0$) или нормальная составляющая вектора электрической игдукции терпит разрыв
2. $[\vec{\nu}^{0}, (\vec{E}_{1} - \vec{E}_{2})] = 0$ - тангенциальная составляющая  напряженности электрического поля непрерывна на границе раздела любых сред
3. $(\vec{B}_{1} - \vec{B}_{2}) \vec{\nu}^{0} = 0$ - нормальная составляющая вектора магнитной индукции непрерывна на границе раздела любых сред.
4. $[\vec{\nu}^{0}, (\vec{H}_{1} - \vec{H}_{2})] = \vec{\eta} = \vec{\eta}^{0} \lim_{ \Delta l \to 0 } \frac{\Delta I}{\Delta l}, \ \Delta l \perp \vec{\eta}^{0}$

$\eta$ - поверхностная плотность электрического тока $\left[ \frac{А}{м} \right]$

$\vec{a}\cdot \vec{\nu}^{0}$ - нормальная составляющая вектора $\vec{a}$
$\vec{a}\cdot \vec{\tau}^{0}$ - тангенциальная составляющая вектора $\vec{a}$


### 1. Доказательство граничного условия для нормальной составляющей $\vec{D}$.

![[2025-10-02 Семинар - ЭД 2025-10-02 16.58.33.excalidraw]]

$$\begin{gather}
\mathrm{div} \ \vec{D} = \rho \implies \int_{V_{ц}}\mathrm{div} \ \vec{D} \, dv = \int_{V_{ц}} \rho \, dv = \Delta q \\
\int_{V_{ц}}\mathrm{div} \ \vec{D} \, dv = \oint_{S_{ц}} \vec{D} \vec{ds} = \oint_{S_{ц}} \vec{D} \vec{\nu}^{0} \, ds = \\
= \left. \oint_{\Delta S_{1}} \vec{D}\vec{\nu}^{0}_{1}  \, ds + \oint_{\Delta S_{2}} \vec{D}\vec{\nu}^{0}_{2} ds  + \oint_{S_{Бок} = \Delta l \Delta S} \vec{D}\vec{\nu}_{Бок} \, ds \right|_{\Delta l \to 0} = \Delta q
\end{gather}$$

$$\begin{gather}
\int_{\Delta S} \vec{D}_{1} \vec{\nu}^{0} \, ds - \int_{\Delta S} \vec{D}_{2}\vec{\nu}^{0}\, ds + 0 = \Delta q \\
(\vec{D}_{1} - \vec{D}_{2})\vec{\nu}^{0}\int_{\Delta S} ds = \Delta q \\
(\vec{D}_{1} - \vec{D}_{2})\vec{\nu}^{0} = \lim_{ \Delta S \to 0 } \frac{\Delta q}{\Delta S} = \xi
\end{gather}$$

### 2. Граничные условия для тангенциальной составляющей $\vec{E}$

Через вектор нормали $\vec{\nu}^{0}$ проводим произвольную плоскость (так, чтобы вектор лежал в плоскости).

По пересечению плоскостью поверхности определим линию пересечения, $\Delta l$ - бесконечно малый ее фрагмент, будем считать, что он прямой.

Теперь возьмем прямоугольный контур, включающий $\Delta l$, применим в нем второе уравнение Максвелла в интегральной форме.

![[2025-10-02 Семинар - ЭД 2025-10-02 17.27.33.excalidraw]]

$$\begin{gather}
\mathrm{rot} \ \vec{E} = -\frac{\partial  \vec{B}}{\partial t} \\
\int_{\Delta P=\Delta l \Delta h}\mathrm{rot} \ \vec{E} \, \vec{ds} = -\frac{d}{dt}\int_{\Delta P} \vec{B} \, \vec{ds} \\
\int_{ABCD} \vec{E}  \, \vec{dl} = -\frac{d}{dt}\int_{\Delta P} \vec{B} \vec{n}^{0} \, ds \\
\end{gather}$$

$$\begin{gather}
\left. \int_{AB} \vec{E} \, \vec{dl} + \int_{BC} \vec{E} \, \vec{dl} + \int_{CD} \vec{E} \, \vec{dl} + \int_{DA} \vec{E}  \, \vec{dl}  = -\frac{d}{dt}\int_{\Delta P} \vec{B} \vec{n}^{0} \, ds \right|_{\Delta h \to 0} \\
\int_{AB} \vec{E}_{1} \, \vec{dl} + \int_{CD} \vec{E}_{2} \, \vec{dl} = 0 \\
(E_{1} - E_{2})\vec{\tau}^{0}\int_{\Delta l} dl = 0 \\
(\vec{E}_{1} - \vec{E}_{2})\vec{\tau}^{0}\Delta l = 0 \\
(\vec{E}_{1} - \vec{E}_{2})\vec{\tau}^{0} = 0 \\
[\vec{\nu}^{0}, (\vec{E}_{1} - \vec{E}_{2})] = 0
\end{gather}$$
