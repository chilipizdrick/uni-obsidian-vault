# Метод Фурье для волнового уравнения - задача 2

Уравнение описывает движение струны.
Неоднородная часть уравнения описывает внешние воздействия.

$$\begin{gather}
u_{tt} - u_{xx} = x+3t, \ x \in (0,\pi), t > 0 \\
t(0,t) = 0, \ u(\pi,t) = 2t - t^{2} \\
u(x,0) = 0, u_{t}(x,0) = 1 + \cos(2x)
\end{gather}$$

$$\begin{gather}
u = H + V - \text{ЗАМЕНА} \\
H(x,t) = a(t) + x\cdot b(t) \\
H(0,t) = 0, H(\pi,t) = 2t - t^{2}
\end{gather}$$

$H(x,t) = a(t) + x\cdot b(t)$ - берет на себя граниченые условия

$$\begin{gather}
a = 0, \ \pi \cdot b(t) = 2t - t^{2} \\
b(t) = \frac{2t-t^{2}}{\pi}
\end{gather}$$

$$\begin{gather}
H = \frac{x}{\pi} \cdot (2t - t^{2}) \\
\begin{cases}
H_{tt} + V_{tt} - H_{xx} - V_{xx} = x + 3t \\
H(0,t) + V(0,t) = 0, \ H(\pi, t) + V(\pi ,t) = 2t - t^{2} \\
H(x,0) + V(x,0) = 0, \ H_{t}(x,0) + V_{t}(x,0) = 1 + \cos(2x)
\end{cases}
\end{gather}$$

$$\begin{gather}
\begin{cases}
V_{tt} - V_{xx} = x\left( 1+\frac{2}{\pi} \right) + 3t \\
V(0,t) = 0, \ V(\pi, t) = 0 \\
V(x,0) = 0, \ V_{t}(x,0) = 1+\cos(2x) - \frac{2x}{\pi}
\end{cases}
\end{gather}$$

Теперь применяем метод Фурей:

$$\begin{gather}
V = X(x)T(t) \\
XT_{tt} - X_{xx}T = 0 \\
\frac{T_{tt}}{T} - \frac{X_{xx}}{X} = 0 \\
\frac{T_{tt}}{T} = \frac{X_{xx}}{X} = -\mu^{2} \\
\begin{cases}
X_{xx} + \mu^{2}X = 0 \\
T_{tt} + \mu^{2}T = 0 \\
\end{cases} \\
X(x) = C_{1}\cos(\mu x) + C_{2}\sin (\mu x) \\
X(0) = 0, \ X(\pi) = 0 \\
C_{1} \cdot 1 + 0 = 0 \implies C_{1} = 0 \\
C_{2}\sin(\pi \mu) = 0 \implies \pi \mu = \pi n, \implies \mu = n, \ n = 1,2,3,\dots \\
X(x) = \sin(nx), \ n = 1,2,3,\dots \\
\end{gather}$$

$$\begin{gather}
V(x,t) = \sum_{n=1}^{\infty}\left( A_{n}\cos (nt) + B_{n}\sin(nt) \right) \sin(nx)
\end{gather}$$
