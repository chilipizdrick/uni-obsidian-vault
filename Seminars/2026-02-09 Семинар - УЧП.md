# Метод Фурье для волнового уравнения - задача 2

Уравнение описывает движение струны.
Неоднородная часть уравнения описывает внешние воздействия.

$$\begin{gather}
u_{tt} - u_{xx} = x+3t, \ x \in (0,\pi), t > 0 \\
t(0,t) = 0, \ u(\pi,t) = 2t - t^{2} \\
u(x,0) = 0, u_{t}(x,0) = 1 + \cos(2x)
\end{gather}$$

$$\begin{gather}

H(0,t) = 0, H(\pi,t) = 2t - t^{2}
\end{gather}$$

$H(x,t) = a(t) + x\cdot b(t)$ - берет на себя граниченые условия

$$\begin{gather}

b(t) = \frac{2t-t^{2}}{\pi}
\end{gather}$$

$$\begin{gather}

Теперь применяем метод Фурей:

$$\begin{gather}
V = X(x)T(t) \\
XT_{tt} - X_{xx}T = 0 \\
\frac{T_{tt}}{T} - \frac{X_{xx}}{X} = 0 \\
\frac{T_{tt}}{T} = \frac{X_{xx}}{X} = -\mu^{2} \\
\begin{cases}
X_{xx} + \mu^{2}X = 0 \\
T_{tt} + \mu^{2}T = 0 \\
\end{cases} \\
X(x) = C_{1}\cos(\mu x) + C_{2}\sin (\mu x) \\
X(0) = 0, \ X(\pi) = 0 \\
C_{1} \cdot 1 + 0 = 0 \implies C_{1} = 0 \\
C_{2}\sin(\pi \mu) = 0 \implies \pi \mu = \pi n, \implies \mu = n, \ n = 1,2,3,\dots \\
X_{n}(x) = \sin(nx), \ n = 1,2,3,\dots \\
\end{gather}$$
