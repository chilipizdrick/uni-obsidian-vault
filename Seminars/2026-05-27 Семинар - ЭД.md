### Пр. №16 Основное поле прямоугольного резонатора

![[2026-05-27 Семинар - ЭД 2026-05-27 12.58.26.excalidraw]]

При $L > b$ основное поле: $H_{101}$

Собственные поля резонатора представляют собой решение однородной системы уравнений электродинамики с граничными условиями на стенках резонатора.

$$\begin{gather}
E_{mnp} (E_{z} \neq 0, H_{z} = 0), m = 1,2,\dots, n = 1,2,\dots, p = 0,1,2,\dots \\
H_{mnp} (H_{z} \neq 0, E_{z} = 0), m = (0),1,2,\dots, n = (0),1,2,\dots, p = 1,2,\dots
\end{gather}$$

$$\begin{gather}
\omega = \omega_{\text{собств.}}, \omega_{mnp} = \frac{1}{\epsilon_{a} \mu_{a}} \sqrt{ \varkappa^{2} + \left( \frac{\pi}{L}p \right)^{2} }, \ \varkappa = \sqrt{ \left( \frac{\pi}{a} \right) }
\end{gather}$$
