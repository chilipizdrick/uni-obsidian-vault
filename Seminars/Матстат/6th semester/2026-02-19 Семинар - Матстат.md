## Распределение Пуассона $P(\lambda)$

- $p_{k} = \frac{e^{-\lambda}\lambda^{k}}{k!}$
- $\mathrm{M}\xi = \lambda$
- $\mathrm{D}\xi = \lambda$
- $W_{\xi}(s) = \mathrm{M}s ^{\xi} = e^{\lambda(s-1)}$

Найдем моду распределения:

$$\begin{gather}
p_{m-1}\leq p_{m} \geq p_{m+1} \\
\end{gather}$$

$$\begin{gather}
\frac{e^{-\lambda}\lambda^{k-1}}{(k-1)!} \leq \frac{e^{-\lambda}\lambda^{k}}{k!} \\
\frac{\lambda^{k-1}}{(k-1)!} \leq \frac{\lambda^{k}}{k!} \\
\lambda^{k-1}k! \leq \lambda^{k}(k-1)!
\end{gather}$$

$$\begin{gather}
\lambda^{k-1}k \leq \lambda^{k} \\
k\leq \lambda
\end{gather}$$

$$\begin{gather}
p_{m} \geq p_{m+1} \\
\frac{e^{-\lambda}\lambda^{k}}{k!}\geq \frac{e^{-\lambda}\lambda^{k+1}}{(k+1)!} \\
\lambda^{k}(k+1)! \geq \lambda^{k+1}k! \\
\end{gather}$$

$$\begin{gather}
k+1 \geq \lambda \\
k \geq \lambda - 1
\end{gather}$$

Итого:

$$\begin{gather}
\begin{cases}
k \leq \lambda \\
k \geq \lambda - 1
\end{cases}, \ k \in [\lambda-1, \lambda]
\end{gather}$$

Тогда $M_{o}\xi = \{ \lfloor \lambda \rfloor, \lfloor \lambda-1 \rfloor \}$.

Рассчет коэффициента ассиметрии:

$$\begin{gather}
\gamma_{1} = \frac{\mu_{3}^{0}}{\sigma^{3}} \\
\mu_{3}^{0} = \mathrm{M}(\xi - \mathrm{M}\xi)^{3} = \mathrm{M}(\xi^{3} - 3\xi^{2}\mu_{1} + 3\xi (\mu_{1})^{2} - (\mu_{1})^{3}) = \\
= \mu_{3} - 3\mu_{2}\mu_{1} + 2(\mu_{1})^{3}
\end{gather}$$

$$\begin{gather}
W_{\xi}'(1) = \mu_{1} \\
W_{\xi}''(1) = \mu_{2} - \mu_{1} \\
W_{\xi}'''(1) = \mu_{3} - 3\mu_{2} + 2\mu_{1}
\end{gather}$$

$$\begin{gather}
W'_{\xi}(s) = \lambda e^{\lambda(s-1)} \\
W''_{\xi}(s) = \lambda^{2} e^{\lambda(s-1)} \\
W'''_{\xi}(s) = \lambda^{3} e^{\lambda(s-1)}
\end{gather}$$

$$\begin{gather}
W_{\xi}''(1) = \lambda^{2} = \mu_{2} - \mu_{1} \\
\mu_{2} - \lambda = \lambda^{2} \\
\mu_{2} = \lambda^{2} + \lambda
\end{gather}$$

$$\begin{gather}
W_{\xi}'''(1) = \lambda^{3} = \mu_{3} - 3\mu_{2} + 2\mu_{1} \\
\mu_{3} = \lambda^{3} + 3\lambda^{2} + 3\lambda - 2\lambda = \lambda^{3} + 3\lambda^{2} + \lambda
\end{gather}$$

$$\begin{gather}
\mu_{3}^{0} = \lambda^{3} + 3\lambda^{2} + \lambda - 3\lambda^{3} - 3\lambda^{2} + 2\lambda^{3} = \lambda \\
\end{gather}$$

$$\begin{gather}
\gamma_{1} = \frac{\lambda}{\lambda \sqrt{ \lambda }}= \frac{1}{\sqrt{ \lambda }}
\end{gather}$$


$$\begin{gather}
\gamma_{2} = \frac{\mu_{4}^{0}}{\sigma^{4}} - 3 \\
\end{gather}$$

$$\begin{gather}
\mu_{4}^{0} = \mathrm{M}(\xi - \mathrm{M} \xi)^{4} = \\
= \mathrm{M}(\xi^{4} -4\xi^{3}\mu_{1} + 6\xi^{2}(\mu_{1})^{2} - 4\xi(\mu_{1})^{3} + (\mu_{1})^{4}) = \\
= \mu_{4} -4\mu_{3}\mu_{1} + 6\mu_{2}(\mu_{1})^{2} - 3(\mu_{1})^{4}
\end{gather}$$

$$\begin{gather}
W^{IV}_{\xi}(t) = \lambda^{4}e^{\lambda(s-1)} \\
W^{IV}_{\xi}(1) = \lambda^{4}
\end{gather}$$

$$\begin{gather}
\mathrm{M}(\xi(\xi-1)(\xi-2)(\xi-3)) = \lambda^{4} \\
\mathrm{M}(\xi(\xi-1)(\xi-2)(\xi-3)) = \mathrm{M}(\xi^{4} - 6\xi^{3} + 11 \xi^{2} - 6\xi) = \\
= \mu_{4} - 6\mu_{3} + 11 \mu_{2} - 6\mu_{1} = \lambda^{4}
\end{gather}$$

$$\begin{gather}
\mu_{4} = \lambda^{4} + 6(\lambda^{3} + 3\lambda^{2} + \lambda) - 11(\lambda^{2} + \lambda) + 6\lambda
\end{gather}$$

$$\begin{gather}
\mu_{4} = \lambda^{4} + 6\lambda^{3} + 18\lambda^{2} + 6\lambda - 11\lambda^{2} - 11\lambda + 6\lambda = \\
= \lambda^{4} + 6\lambda^{3} + 7\lambda^{2} + \lambda
\end{gather}$$

$$\begin{gather}
\mu_{4}^{0} = \\
= \lambda^{4} + 6\lambda^{3} + 7\lambda^{2} + \lambda - 4(\lambda^{3} + 3\lambda^{2} + \lambda)\lambda + 6(\lambda^{2} + \lambda)\lambda^{2} - 3\lambda^{4} = \\
= \lambda(3\lambda+1)
\end{gather}$$

$$\begin{gather}
\gamma_{2} = \frac{\mu_{4}^{0}}{\sigma^{4}} - 3 = \frac{3\lambda^{2} + \lambda}{\lambda^{2}} - 3 = \frac{1}{\lambda} - 3 + 3 = \frac{1}{\lambda}
\end{gather}$$

## Равномерное распределение $U(\{1,\dots,n\})$ (продолжение)

- $p_{k} = \frac{1}{n}$
- $\mathrm{M}\xi = \frac{n+1}{2}$
- $\mathrm{D}\xi = \frac{n^{2}-1}{12}$
- $W_{\xi}(s) = \frac{s(1-s^{n})}{n(1-s)}$

$$\begin{gather}
W_{\xi}(s) = \mathrm{M}(s ^{\xi}) = \sum_{k=1}^{n} \frac{1}{n} s ^{k}
\end{gather}$$

$$\begin{gather}
\mu_{3}^{0} = \mu_{3} - 3\mu_{2}\mu_{1} + 2(\mu_{1})^{3} \\
\end{gather}$$

$$\begin{gather}
\mu_{1} = \frac{n+1}{2}, \ \mu_{2} - \mu_{1} = \frac{n^{2}-1}{12} \implies \mu_{2} = \\
= \frac{n^{2}-1 + 6n+6}{12} = \frac{n^{2}+ 6n + 5}{12}
\end{gather}$$
