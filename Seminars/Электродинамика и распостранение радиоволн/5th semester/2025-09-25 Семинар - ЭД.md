## 4. Примеры решения граничных задач электростатики с использованием уравнения лапласа


### 1. Определить потенциал проводящего шара

![[2025-09-25 Семинар - ЭД 2025-09-25 16.23.20.excalidraw]]

У шара есть заряд $q$ - его нужно определить.

$$\Delta \phi = 0$$

$$\begin{gather}
\epsilon = \frac{\epsilon_{a}}{\epsilon_{0}} \\
\epsilon_{0} - \text{диэлектрическая проницаемость вакуума.}
\end{gather}$$

$$\begin{gather}
\vec{E} = -\mathrm{grad} \ \phi \\
\vec{j}_{ш} = \sigma_{ш} \vec{E}_{ш} \\
\vec{j}_{ш} = 0 \implies \vec{E}_{ш} = 0 \\
\end{gather}$$

$$\begin{gather}
-\mathrm{grad} \ \phi = -\left( \vec{x} \frac{\partial \phi}{\partial x} + \vec{y} \frac{\partial \phi}{\partial y} + \vec{z} \frac{\partial \phi}{\partial z} \right) = 0 \implies \phi_{ш} = \mathrm{const} = \Phi
\end{gather}$$

На границе тангенциальная составляющая электрического поля равна нулю.

$$\begin{gather}
r = R \implies \vec{E}_{\tau} = 0 \implies \left.\vec{E}\right|_{r = R} = \vec{\nu}^{0} E
\end{gather}$$

Тогда поверхность проводника является эквипотенциальной:

$$\mathrm{grad} \ \phi = \vec{\nu}^{0} \frac{\partial \phi}{\partial \vec{\nu}}$$

$$\begin{gather}
\left.\phi \right|_{r=R} = \Phi \\
\left.\phi \right|_{r \to \infty} = 0
\end{gather}$$

$$\begin{gather}
\text{Из 2а)} \implies \phi = -\frac{C_{1}}{r} \\
\text{Из 2б)} \implies C_{1} = -\Phi R \implies \phi = \frac{\Phi R}{r}
\end{gather}$$

$$\begin{gather}
\vec{E} = -\mathrm{grad} \ \phi = -\vec{r}^{0} \frac{\partial \phi}{\partial r} = \vec{r}^{0}\frac{\Phi R}{r^{2}} \\
\end{gather}$$

$$\begin{gather}
\xi_{ш} = \vec{D}_{ш}\vec{\nu_{0}} = \vec{D}_{ш}\vec{r}^{0} = \epsilon_{a}\vec{E}_{ш}\vec{r}^{0}
\end{gather}$$

$$\begin{gather}
Q = \oint_{S_{R}} \xi \, ds = \frac{\epsilon_{a}\Phi}{R}S_{R} = \underbrace{\epsilon_{a}4\pi R}_{C - \text{емкость}}\Phi
\end{gather}$$

### ЗАДАЧА: Определить потенциал в сферическом конденсаторе (сфера внутри сферы)

$$\begin{gather}
\vec{E} - \mathrm{grad} \ \phi \\
\Delta \phi = 0 \\
\phi|_{r = R_{1}} = \Phi_{1} \\
\phi|_{r = R_{2}} = \Phi_{2} \\
\phi = -\frac{C_{1}}{r} + C_{2} \\
\begin{cases}
\Phi_{1} = -\frac{C_{1}}{R_{1}} + C_{2} \\
\Phi_{2} = -\frac{C_{1}}{R_{2}} + C_{2} \\
\end{cases} \\
C_{2} = \Phi_{1} + \frac{C_{1}}{R_{1}} \\
\Phi_{2} = -\frac{C_{1}}{R_{2}} + \Phi_{1} + \frac{C_{1}}{R_{1}} \\
C_{1} = \frac{\Phi_{2}-\Phi_{1}}{\frac{1}{R_{1}} - \frac{1}{R_{2}}} \\
C_{2} = \Phi_{1} + \frac{1}{R_{1}}\left( \frac{\Phi_{2}-\Phi_{1}}{\frac{1}{R_{1}} - \frac{1}{R_{2}}} \right) \\
C_{2} = \Phi_{1} + \frac{\Phi_{2} - \Phi_{1}}{1-\frac{R_{1}}{R_{2}}}
\end{gather}$$

$$\begin{gather}
U = \Phi_{1}-\Phi_{2} = C_{1}\left( \frac{1}{R_{2}} - \frac{1}{R_{1}} \right) \implies C_{1} = \frac{(\Phi_{1} - \Phi_{2})(R_{1}-R_{2})}{R_{1}R_{2}} \\
C_{1} = -U\left( \frac{1}{R_{1}} - \frac{1}{R_{2}} \right) \\
\end{gather}$$

$$\begin{gather}
\vec{E} = \vec{r}^{0} \frac{U}{\frac{1}{R_{1}} - \frac{1}{R_{2}}} \frac{1}{r^{2}} \\
\xi|_{r=R_{1}} = \frac{U\epsilon_{a}}{\frac{1}{R_{1}} - \frac{1}{R_{2}}} \frac{1}{R_{1}^{2}} \\
\xi|_{r=R_{2}} = \frac{U\epsilon_{a}}{\frac{1}{R_{1}} - \frac{1}{R_{2}}} \frac{1}{R_{2}^{2}}
\end{gather}$$

$$\begin{gather}
Q = \oint_{S} \xi dS = \underbrace{\epsilon_{a}\cdot \frac{1}{\frac{1}{R_{1}} - \frac{1}{R_{2}}} 4\pi}_{C - \text{емкость конденсатора}}U
\end{gather}$$
