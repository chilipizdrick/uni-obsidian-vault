### Электромагнитное поле точечного источника в дальней зоне. Диаграмы направленности

$$\begin{gather}
\dot{\vec{\mathrm{p}}}^{ст} = \dot{I}_{m}^{ст}\vec{l}, \ \vec{l} = \vec{z}^{0}l \\
\dot{\vec{E}}_{m} = \vec{\theta}^{0}i \dot{W} \dot{I}^{ст}_{m} \dot{k} l \sin \theta G(r) \\
\dot{\vec{H}}_{m} = \vec{\alpha}^{0}i \dot{I}^{ст}_{m} \dot{k} l \sin \theta G(r) \\
G(r) = \frac{e^{-i \dot{k}z}}{4\pi r}
\end{gather}$$

$$\begin{gather}

\end{gather}$$
Диаграмма направленности показывает зависимость амплетуды напряженности поля в дальней зоне в зависимости от направления в пространстве.

Формула расчета для пространственной диаграмы направленности:
$$\begin{gather}
r = \tilde{E}_{m}(\theta, \alpha) = \tilde{H}_{m}(\theta, \alpha), 0 \leq \theta \leq \pi, 0 \leq \alpha \leq 2\pi, 
\end{gather}$$
где $\tilde{E}_{m}, \tilde{H}_{m}$ - норминованные амплитуды.

$$\begin{gather}
\tilde{E}_{m} = \frac{E_{m}}{E_{m\ \mathrm{max}}} \\
E_{m} = |\dot{W}| \dot{I}_{m}^{ст} |\dot{k}|l \sin \theta |G(r)| \\
\tilde{E}_{m} = \frac{|\dot{W}| |\dot{I}_{m}^{ст}| |\dot{k}|l \sin \theta|G(r)|}{|\dot{W}| |\dot{I}_{m}^{ст}| |\dot{k}|l|G(r)|} = \sin \theta \\
\end{gather}$$

$$\begin{gather}
r = \sin \theta, \ 0 < \theta < \pi, 0 < \alpha < 2\pi
\end{gather}$$

$$\begin{gather}
xOy: \ z = 0 \implies z = r\cos \theta = 0
\end{gather}$$

$$\begin{gather}
xOz: \ y = 0 \implies r \sin \theta \sin \alpha = 0 \\
\sin \alpha = 0 \implies \alpha_{1} = 0^{\circ}, \alpha_{2} = 180^{\circ}
\end{gather}$$

$$\begin{gather}
r = \sin \theta, 0^{\circ} \leq \theta \leq 180^{\circ}, \alpha \in \{ 0^{\circ}, 180^{\circ} \}
\end{gather}$$
