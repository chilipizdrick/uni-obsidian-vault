### Пр. №4. Нормальное падение ПОВ на бесконечную идеальную проводящую плоскость.

### 1. Постановка задачи

![[2026-03-04 Семинар - ЭД 2026-03-04 12.43.54.excalidraw]]

Дано: $\dot{\vec{E}}_{m}^{(0)} = \vec{x}^{0} \dot{E}_{0} e^{i\dot{k}z}$

Определить: $\dot{\vec{E}}_{m}(\vec{r}), \ \dot{\vec{H}}_{m}(\vec{r})$


$$\begin{gather}
\dot{\vec{E}}_{m\tau}|_{z=0} = 0 \ (*)
\end{gather}$$

### 2. Решение задачи

$$\begin{gather}
\dot{\vec{E}}_{m}(\vec{r}) = \dot{\vec{E}}_{m}^{(0)} + \dot{\vec{E}}_{m}^{вт}
\end{gather}$$

$$\begin{cases}
\dot{\vec{E}}_{m}(\vec{r}) = \frac{1}{i\omega\dot{\epsilon}_{a}} (\mathrm{grad}\, \mathrm{div}\, \dot{\vec{A}}_{m} + \dot{k}^{2} \dot{\vec{A}}_{m}) \\
\dot{\vec{H}}_{m}(\vec{r}) = \mathrm{rot}\, \dot{\vec{A}}_{m}
\end{cases}$$

$$\begin{gather}
\dot{\vec{A}}_{m}(\vec{r}) = \int_{S(z=0)} \dot{\vec{\eta}}_{m}(\vec{r})G(\vec{r}, \vec{r}') \, dv' \ (4)
\end{gather}$$

$$\begin{gather}
G(\vec{r}, \vec{r}') = \frac{e^{-ik|\vec{r}-\vec{r}'|}}{4\pi|\vec{r}-\vec{r}'|} \\
|\vec{r}-\vec{r}'| = \left.\sqrt{ (x-x')^{2} + (y-y')^{2} + (z-z')^{2} }\right|_{z'=0} = \sqrt{ (x-x')^{2} + (y-y')^{2} + z^{2} }
\end{gather}$$

Из-за плоскостной симметрии $\dot{\vec{\eta}}_{m}^{ст} = \mathrm{const}$

$$\begin{gather}
\dot{\vec{A}}_{m}(\vec{r}) = \dot{\vec{\eta}}_{m}^{ст}\int_{S(z=0)} \frac{e^{-ik}\sqrt{ (x')^{2} + (y')^{2} + z^{2} }}{4\pi\sqrt{ (x')^{2} + (y')^{2} + z^{2} }} \, ds'
\end{gather}$$

Перейдем к полярным координатам

$$\begin{gather}
\dot{\vec{A}}_{m}(\vec{r}) = \dot{\vec{\eta}}_{m}^{ст} \int_{} \, dr'
\end{gather}$$
