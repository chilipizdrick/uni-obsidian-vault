### Пр. №3. (1) Нормальное падение ПОВ на на бесконучную плоскую границу идеально проводящей среды

![[2026-02-25 Семинар - ЭД 2026-02-25 12.58.46.excalidraw]]

Дано:

$$\begin{gather}
\dot{\vec{E}}_{m}^{(0)} = \vec{x}^{0}\dot{E}_{0} e^{ikz} \\
\dot{\vec{H}}_{m}^{(0)} = \frac{1}{W} \left[ -\vec{z}^{0}, \dot{\vec{E}}_{m}^{(0)} \right] = -\vec{y}^{0}  \frac{\dot{E}_{0}}{W}e^{ikz} \\
\end{gather}$$

Определить:

$$\begin{gather}
\dot{\vec{E}}_{m}(\vec{r}), \dot{\vec{H}}_{m}(\vec{r}), \ \vec{\eta}_{m}
\end{gather}$$

Решение:

$$\begin{gather}
\dot{\vec{E}}_{m} = \begin{cases}
\dot{\vec{E}}_{m}^{(1)} = \dot{\vec{E}}_{m}^{(=)} + \dot{\vec{E}}_{m}^{(-)} \\
\dot{\vec{E}}_{m}^{(2)} = 0
\end{cases}
\end{gather}$$

$$\begin{gather}
\left.\dot{\vec{E}}_{m}^{(1)}\right|_{z=0} = \left.\dot{\vec{E}}_{m}^{(2)}\right|_{z=0} = 0 \ (*)
\end{gather}$$

$$\begin{gather}
\dot{\vec{E}}_{m}^{(-)} = \vec{x}^{0}\dot{E}_{0} \rho e^{-ikz} \\
\dot{\vec{H}}_{m}^{(-)} = \frac{1}{W}\left[ \vec{z}^{0}, \dot{\vec{E}}_{m}^{(-)} \right] = \vec{y}^{0}\frac{\dot{E}\rho}{W}e^{-ikz}
\end{gather}$$

$$\begin{gather}
(*) \implies \left.(\dot{\vec{E}}_{m}^{(0)} + \dot{\vec{E}}_{m}^{(-)})\right|_{z=0} = 0 \implies \\
\implies \vec{x}^{0} \dot{E}_{0} + \vec{x}^{0}\dot{E}_{0} \rho = 0 \implies \rho = -1
\end{gather}$$

$$\begin{gather}
\dot{\vec{E}}_{m}^{(1)} = \vec{x}^{0}2i\dot{E}_{0}\sin kz \\
\dot{\vec{H}}_{m}^{(1)} = -\vec{y}^{0}\frac{2\dot{E}_{0}}{W} \cos kz \\
\end{gather}$$

$$\begin{gather}
\vec{\eta}_{S_{и.п.}} = \left[ \vec{\nu}^{0}, (\dot{\vec{H}}_{m}^{(1)} - \dot{\vec{H}}_{m}^{(2)}) \right] \\
\vec{\eta}|_{S_{и.п.}} = \vec{x}^{0} \frac{2\dot{E}_{0}}{W}
\end{gather}$$

Но можно было обойтись и без знания напряженности магнитного поля. Используем систему однородных урвнений электродинимики:

$$\begin{cases}
\mathrm{rot} \ \dot{\vec{H}}_{m} = i\omega\dot{\epsilon}_{a} \dot{\vec{E}}_{m} \\
\mathrm{rot} \ \dot{\vec{E}}_{m} = -i\omega\dot{\mu}_{a} \dot{\vec{H}}_{m}
\end{cases}$$

$$\begin{gather}
\dot{\vec{H}} = \frac{\mathrm{rot} \ \dot{\vec{E}}_{m}}{-i\omega \mu_{a}} = -\vec{y}^{0}\left( -\frac{\partial \dot{\vec{E}}_{mx}}{\partial z} \right) + \vec{z}^{0}\left( -\frac{\partial \dot{\vec{E}}_{mx}}{\partial y} \right) = \\
= -\vec{y}^{0} \frac{2\dot{E}_{0}}{W} \cos kz
\end{gather}$$

### Дз

1. Прорешать идентичную задачу (задача 1), только не нормальное, а наклонное падение.

Решение:

$$\begin{gather}
\dot{\vec{E}}_{m}^{(0)} = \vec{x}^{0}\dot{E}_{0}e^{-ik_{1}(y\sin \phi + z\cos \phi)} \\
\end{gather}$$

$$\begin{gather}
\dot{\vec{E}}_{m} = \begin{cases}
\dot{\vec{E}}_{m}^{(1)} = \dot{\vec{E}}_{m}^{(0)} + \dot{\vec{E}}_{m}^{(-)} \\
\dot{\vec{E}}_{m}^{(2)} = 0
\end{cases}
\end{gather}$$
$$\begin{gather}
\begin{cases}
\dot{\rho}_{\perp} = \frac{\dot{W}_{2}\cos \phi - W_{1}\cos \theta}{\dot{W}_{2}\cos \phi + W_{1}\cos \theta} \\
\dot{\tau}_{\perp} = \frac{2\dot{W}_{2}\cos \phi}{\dot{W}_{2}\cos \phi + W_{1}\cos \theta}
\end{cases}
\end{gather}$$

Т.к. $\sigma_{2} = \infty \implies \tau = 0 \implies \rho = 1$

$$\begin{gather}
\dot{\vec{E}}_{m}^{(-)} = \vec{x}^{0}\dot{E}_{0}\rho e^{-ik_{1}(y\sin \psi + z \cos \psi)} = \vec{x}^{0}\dot{E}_{0}e^{-ik_{1}(y\sin \phi - z\cos \phi)}
\end{gather}$$

$$\begin{gather}
\dot{\vec{E}}_{m}^{(1)} = \vec{x}^{0}\dot{E}_{0}(e^{-ik_{1}(y\sin \phi + z\cos \phi)} + e^{-ik_{1}(y\sin \phi - z\cos \phi)}) = \\
= \vec{x}^{0} \dot{E}_{0}e^{-ik_{1}y\sin \phi}(e^{ik_{1}z\cos \phi} + e^{-ik_{1}z\cos \phi}) = \\
= \vec{x}^{0}2\dot{E}_{0}e^{-ik_{1}y\sin \phi}\cos(k_{1}z\cos \phi)
\end{gather}$$

$$\dot{\vec{E}}_{m} = \begin{cases}
\dot{\vec{E}}_{m}^{(1)} = \vec{x}^{0}2\dot{E}_{0}e^{-ik_{1}y\sin \phi}\cos(k_{1}z\cos \phi) \\
\dot{\vec{E}}_{m}^{(2)} = 0
\end{cases}$$

$$\begin{gather}
\vec{\xi}^{(0)0} = \vec{y}^{0}\sin \phi + \vec{z}^{0}\cos \phi \\
\dot{\vec{H}}_{m}^{(0)} = \frac{1}{W_{1}}\left[ \vec{\xi}^{(0)0}, \dot{\vec{E}}_{m}^{(0)} \right] = \frac{\dot{E}_{0}}{W_{1}}(\vec{y}^{0}\cos \phi - \vec{z}^{0}\sin \phi)e^{-ik_{1}(y\sin \phi + z \cos \phi)}
\end{gather}$$

$$\begin{gather}
\vec{\xi}^{(-)0} = \vec{y}^{0}\sin \psi + \vec{z}^{0}\cos \psi = \vec{y}^{0}\sin \phi - \vec{z}^{0}\cos \phi
\end{gather}$$

$$\begin{gather}
\dot{\vec{H}}_{m}^{(-)} = \frac{1}{W_{1}}\left[ \vec{\xi}^{(-)0}, \dot{\vec{E}}_{m}^{(-)} \right] = \frac{\dot{E}_{0}}{W_{1}}(-\vec{y}^{0}\cos \phi - \vec{z}^{0}\sin \phi)e^{-ik_{1}(y\sin \phi - z\cos \phi)} \\
\end{gather}$$

$$\begin{gather}
\dot{\vec{H}}_{m}^{(1)} = \\
= \frac{\dot{E}_{0}}{W_{1}}(\vec{y}^{0}\cos \phi - \vec{z}^{0}\sin \phi)e^{-ik_{1}(y\sin \phi + z \cos \phi)} + \frac{\dot{E}_{0}}{W_{1}}(-\vec{y}^{0}\cos \phi - \vec{z}^{0}\sin \phi)e^{-ik_{1}(y\sin \phi - z\cos \phi)} = \\
= \frac{\dot{E}_{0}}{W_{1}}e^{-ik_{1}y\sin \phi}\left( (\vec{y}^{0}\cos \phi - \vec{z}^{0}\sin \phi)e^{-ik_{1}z\cos \phi} + (-\vec{y}^{0}\cos \phi - \vec{z}^{}) \right) 
\end{gather}$$
