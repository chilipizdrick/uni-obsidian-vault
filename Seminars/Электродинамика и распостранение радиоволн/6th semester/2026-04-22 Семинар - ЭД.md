## Пр. №11. Собственные волны прямоугольного волновода

![[2026-04-22 Семинар - ЭД 2026-04-22 12.41.26.excalidraw]]

(Тут все те же уравнения / грничные условия, которые были выведены на прошлом семинаре.)

Решив уравнения, полученные для прямоугольного волновода, получаем
$$\begin{gather}
T^{э}_{mn}(x,y) = C_{mn}^{э}\sin\left( \frac{\pi}{a}mx \right)\sin \left( \frac{\pi}{b} ny \right), m = 1,2,\dots, \ n = 1,2,\dots \\
T^{м}_{mn}(x,y) = C_{mn}^{м}\cos\left( \frac{\pi}{a}mx \right)\cos\left( \frac{\pi}{b} ny \right), \\
 m = (0),1,2,\dots, \ n = (0),1,2,\dots
\end{gather}$$

$$\begin{gather}
\varkappa^{э/м} = \sqrt{ \left( \frac{\pi m}{a} \right)^{2} + \left(\frac{\pi n}{b}\right)^{2} }
\end{gather}$$
При этом $mn \approx l$.

$E$-волны обозначаются $E_{mn}$, $H$-волны обозначаются $H_{mn}$.

$$\begin{gather}
\lambda_{кр.mn} = \frac{2\pi}{\varkappa_{mn}} = \frac{2}{\sqrt{ \left( \frac{m}{a} \right)^{2} + \left( \frac{n}{b} \right)^{2} }}
\end{gather}$$

В данном случае $\lambda_{кр,o}=  \lambda_{кр10} = 2a$.

Получение выражений для основных характеристик основной волны в прямоугольном волноводе:

$$\begin{gather}
\dot{\vec{H}}_{mo}^{(\pm)} = \frac{1}{i\omega \mu_{a}}\left( \frac{dZ_{0}^{(\pm)}}{dz} \mathrm{grad}_{\perp} \, T_{o} + \vec{z}^{0}(\varkappa_{o})^{2} T_{0} Z_{0}^{(\pm)} \right), \\
\dot{\vec{E}}_{mo}^{(\pm)} = - \left[ \mathrm{grad}_{\perp} \, T_{o}, \vec{z}^{0} \right] Z_{o}^{(\pm)}, \\
Z_{0}^{м} = e^{\mp \Gamma_{o}z}
\end{gather}$$

$$\begin{gather}
e^{-i\Gamma_{o}z} - \text{для осн. волн полож. типа} \\
e^{i\Gamma_{o}z} - \text{для осн. волн отриц. типа}
\end{gather}$$

$$\begin{gather}
\Gamma_{o}^{(+)} = k_{0}\sqrt{ 1- \left( \frac{\lambda}{\lambda_{кр,o}} \right)^{2} }
\end{gather}$$

$$\begin{gather}
T_{o} = C_{0}\cos \left( \frac{\pi x}{a} \right)
\end{gather}$$

$$\begin{gather}
\dot{\vec{E}}_{mo}^{(+)} = -\left[ \mathrm{grad} \, \left( C_{o}\cos \left( \frac{\pi x}{a} \right) \right), \vec{z}^{0}  \right]  = \\
= -\left[ \vec{x}^{0}\left( -\frac{\pi}{a}C_{o}\sin \right) \right] 
\end{gather}$$
