Пятиминутка:

1. Оператор конечного рагна - линейный ограниченный оператор, область значений которого - конечномерна.
2. Вполне непрерывный оператор - оператор, который может с любой точностью аппроксимирован оператором конечного ранга.
3. $L(X,Y)$ - линейное пространство полноопределенных операторов, действующих из линейного пространства $X$ в линейное пространство $Y$.
4. $L_{O}(X,Y)$ - линейное нормированное пространство полгоопределенных ограниченных операторов, действующих из ЛНП $X$ в ЛНП $Y$.
5. $X^{*}$ - ЛНП линейных ограниченных функционалов над $X$.

$$\begin{gather}
x = (x_{1}, x_{2}, \dots, x_{n},\dots ) \\
l_{2}: \ ||x|| = \sqrt{ \sum_{k=1}^{\infty} x_{k}^{2} } \\
x^{(N)} = (x_{1}, x_{2}, \dots, x_{N}, 0,0,\dots ) = \sum_{k=1}^{N} x_{k}e_{k}, \\
e_{k} = (0,0,\dots,0,1,0,\dots)
\end{gather}$$

$$\begin{gather}
f(x^{(N)}) = \sum_{k=1}^{N} x_{k}f_{k} , \ f_{k}=f(e_{k})
\end{gather}$$

Множество $\{e_{k}\}$ - полная система элементов $l_{2}$.

$$\begin{gather}
|f(x^{(N)})| = \left| \sum_{k=1}^{N}x_{k}f_{k} \right| \le \sqrt{ \sum_{k=1}^{N} x_{k}^{2} } \sqrt{ \sum_{k=1}^{N}f_{k}^{2} } = ||x^{(N)}|| \cdot\sqrt{ \sum_{k=1}^{N} f_{k}^{2} } \leq  \\
\leq ||x^{(N)}||\cdot\sqrt{ \sum_{k=1}^{\infty} f_{k}^{2} }
\end{gather}$$

Тогда если соответствующий ряд сходится, то функционал ограничен, ряд расходится $\implies$ функционал неограничен.

$$\begin{gather}
x^{(N)} \to x, \ f(x) = \lim_{ N \to \infty } f(x^{(N)}) = \lim_{ N \to \infty } \sum_{k=1}^{N} x_{k}f_{k} = \sum_{k=1}^{\infty}x_{k}f_{k}
\end{gather}$$

Получается, что все линейные ограниченные функционалы в $l_{2}$ задаются описанным образом и функционал полностью определен значениями $f_{k}$.

Норма функционала достигается для элемента пропорционального $f_{k}$: $x_{k} = \frac{f_{k}}{||f||}$.

Тогда $l_{2}^{*} = l_{2}$, пространство $l_{2}$ - рефлексивное.

### Пространства $R_{p}^{n}$

![[2026-02-16 Семинар - Функан 2026-02-16 09.34.58.excalidraw]]

$$\begin{gather}
\alpha\beta = 1 \\
\alpha = p-1 \\
\beta = q-1
\end{gather}$$

$$\begin{gather}
S_{1} = \frac{u^{\alpha+1}}{\alpha+1} = \frac{u^{p}}{p} \\
S_{2} = \frac{c^{\beta+1}}{\beta+1} = \frac{v^{q}}{q} \\
S_{1} + S_{2} \geq uv \\
\end{gather}$$

$$\begin{gather}
v = u^{\alpha} = u^{p-1} \\
u = v^{\beta} = v^{q-1}
\end{gather}$$

$$\begin{gather}
(p-1)(q-1) = 1 \\
p+q = pq \\
\frac{1}{p} + \frac{1}{q} = 1
\end{gather}$$

$$\begin{gather}
uv \leq \frac{u^{p}}{p} + \frac{v^{q}}{q} \\
uv = u^{p} = v^{q}
\end{gather}$$

Неравенство Юнга: $uv \leq \frac{u^{p}}{p} + \frac{v^{q}}{q}$

Полученные степени $p$ и $q$ называются сопряженными показателями.

Рассмотрим векторы:

$$\begin{gather}
(u_{1}, u_{2}\dots u_{n}) \\
(v_{1}, v_{2}, \dots, v_{n} ) \\
u_{j},v_{j} \geq 0
\end{gather}$$

$$\begin{gather}
u_{k}v_{k} \leq \frac{u_{k}^{p}}{p} + \frac{v_{k}^{q}}{q} \\
\end{gather}$$

Теперь рассмотрим только нормированные векторы

$$\begin{gather}
\sum_{k=1}^{n}u_{k}^{p} = 1 \\
\sum_{k=1}^{n}v_{k}^{q} = 1
\end{gather}$$

$$\begin{gather}
\sum_{k=1}^{n}u_{k}v_{k} \leq \frac{1}{p} + \frac{1}{q} = 1
\end{gather}$$

равенство, если $u_{k}^{p} = v_{k}^{q}$.

Теперь пусть есть векторы $x=(x_{1}, x_{2}, \dots, x_{n})$ и $y=(y_{1}, y_{2}, \dots, y_{n})$.

Рассмотрим вектор из модулей $(|y_{1}|, |y_{2}|, \dots, |y_{n}|) = A(v_{1}, v_{2}, \dots, v_{n})$, $(|y_{1}|, |y_{2}|, \dots, |y_{n}|) = B(v_{1}, v_{2}, \dots, v_{n})$

$$\begin{gather}
|x_{k}| = Au_{k} \\
|x_{k}|^{p} = A_{^{p}}u_{k}^{p} \\
\sum_{k=1}^{n} |x_{k}|^{p} = A^{p}, \ 
A = \left(\sum_{k=1}^{n} |x_{k}|^{p} \right)^{1/p}
\end{gather}$$

$$\begin{gather}
B = \left( \sum_{k=1}^{n} |y_{k}|^{q} \right)^{1/q} \\
\end{gather}$$

$$\begin{gather}
\left| \sum_{k=1}^{n} x_{k}y_{k} \right|  \leq \sum_{k=1}^{n} |x_{k}||y_{k}| = AB \sum_{k=1}^{n}u_{k}v_{k} \leq AB = \\
= \left( \sum_{k=1}^{n} |x_{k}| \right) ^{1/p}\left( \sum_{k=1}^{n} |y_{k}|^{q} \right) ^{1/q}
\end{gather}$$

Неравенство Гёльдера (общий случай неравенства КБШ):

$$\begin{gather}
\left| \sum_{k=1}^{n}x_{k}y_{k} \right|  \leq \left( \sum_{k=1}^{n} |x_{k}^{p}| \right)^{1/p}\left( \sum_{k=1}^{n} |y_{k}|^{q} \right) ^{1/q}
\end{gather}$$

Будет равенством, когда вектора из $p/q$-ых степеней модулей векторов пропорциональны $|x_{k}|^{p} = \alpha |y_{k}|^{q}$, а знаки $x_{k}$ и $y_{k}$ - совпадают.

Наконец, пространство $R_{p}^{n}$:

$$\begin{gather}
x = (x_{1}, x_{2}, \dots, x_{n} ) \\
f(x) = \sum_{k=1}^{n} x_{k}f_{k} \\
|f(x)| = \left| \sum_{k=1}^{n} x_{k}f_{k} \right| \leq ||x||_{p} \cdot ||f||_{q}
\end{gather}$$

Равенство достигается для $$
x_{k} = \left(\frac{|f_{k}|}{||f||_{q}}\right)^{q/p}\cdot \mathrm{sgn} \,f_{k}$$

Получается, что $(R_{p}^{n})^{*} = R_{q}^{n}$.

Неравенство Гёльдера для бесконечных последовательстей:

$$\begin{gather}
\sum_{k=1}^{\infty} |x_{k}|^{p} < \infty, \ \sum_{k=1}^{\infty} |y_{k}|^{q} < \infty
\end{gather}$$

$$\begin{gather}
\left| \sum_{k=1}^{n}x_{k}y_{k} \right|  \leq \left( \sum_{k=1}^{n} |x_{k}^{p}| \right)^{1/p}\left( \sum_{k=1}^{n} |y_{k}|^{q} \right) ^{1/q} \leq\\
\leq \left( \sum_{k=1}^{\infty} |x_{k}|^{p} \right)^{1/p} \left( \sum_{k=1}^{\infty} |y_{k}|^{q} \right)^{1/q}
\end{gather}$$

Устремляем в левой части $n\to \infty$ и переходим к пределу:

$$\begin{gather}
\left| \sum_{k=1}^{\infty} x_{k}y_{k} \right| \leq \left( \sum_{k=1}^{\infty} |x_{k}|^{q} \right)^{1/p} \left( \sum_{k=1}^{\infty} |y_{k}|^{q} \right)^{1/q}
\end{gather}$$

Заново рассмотрим $l_{p}$:

$$\begin{gather}
l_{p}, \ x = (x_{1}, x_{2}, \dots, x_{n}, \dots ) \\
x^{(N)} = (x_{1}, x_{2}, \dots, x_{N}, 0, \dots ) \\
\end{gather}$$

$$\begin{gather}
f(x^{(N)}) = \sum_{k=1}^{N} x_{k}f_{k} \\
|f(x^{(N)})| = \left| \sum_{k=1}^{N} x_{k}f_{k} \right|a \leq \left( \sum_{k=1}^{N} |x_{k}|^{p} \right)^{1/p}\left( \sum_{k=1}^{N} |f_{k}|^{q} \right)^{1/q} \leq ||x||_{p} ||f||_{q},
\end{gather}$$

если ряд сходится, функционал ограничен.

$$\begin{gather}
l_{p}^{*} = l_{q}, \ l_{p} - \text{рефлексивное}
\end{gather}$$

### Функциональные пространства

$$\begin{gather}
L_{2}[ a,b ] \\
x,y \in L_{2}, \ f_{y}(x) = \int_{a}^{b} x(t)y(t) \, dt
\end{gather}$$

Функционал ограничен, т.к.

$$\begin{gather}
\left| \int _{a}^{b} x(t)y(t) \, dt  \right| \leq \sqrt{ \int _{a}^{b}x^{2}(t) \, dt  }\sqrt{ \int _{a}^{b} y^{2}(t) \, dt } \\
||f_{y}|| = ||y||
\end{gather}$$

Общий вид функционала в пространстве $L_{p}$ задается элементом $L_{q}$, где $p,q$ - сопряженные показатели.

$$\begin{gather}
\left| \int _{a}^{b} x(t)y(t) \, dt  \right| \leq \left(\int _{a}^{b}|x(t)|^{p} \, dt \right)^{1/p}\left(\int _{a}^{b}|x(t)|^{q} \, dt \right)^{1/q}
\end{gather}$$
