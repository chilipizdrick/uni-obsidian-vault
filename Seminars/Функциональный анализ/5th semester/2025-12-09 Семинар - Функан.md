### Достаточные условия для нормы на пространстве

$$\begin{gather}
f(x) \geq 0 \\
f(x) = 0 \iff x = 0 \\
f(\alpha x) = |\alpha|f(x)
\end{gather}$$

Такому функционалу, чтобы быть не хватает неравества треугольника.

$$\begin{gather}
M = \{ u: f(u) \leq 1 \} - \text{выпукло} \implies ?
\end{gather}$$

$$\begin{gather}
\forall u,v \ | \ f(u) \leq 1, f(v) \leq 1 \implies f(\alpha u + \beta v) \leq 1, \ \alpha + \beta = 1, \ \alpha, \beta > 0
\end{gather}$$

$$\begin{gather}
x = f(x)u \\
y = f(y)v \\
f(x+y) = f(f(x)u + f(y)v) = \\
= [f(x) + f(y)]\underbrace{f\left( \frac{f(x)}{f(x) + f(y)}u + \frac{f(y)}{f(x)+f(y)}v \right)}_{\leq 1} \leq f(x) + f(y)
\end{gather}$$

### Аксиомы векторного пространства

$$\begin{gather}
\forall a,b, \ a + b = b + a \\
\forall a,b,c, \ (a+b)+c = a+(b+c) \\
\exists 0 \forall a: \ a + 0 = a \\
\forall a \exists (-a): a+(-a) = 0
\end{gather}$$

$$\begin{gather}
1\cdot a = a \\
(\alpha \beta)a = \alpha(\beta a) \\
(\alpha+\beta)a = \alpha a + \beta a \\
\alpha(a + b) = \alpha a + \alpha b
\end{gather}$$

$$\begin{gather}
a + b = a + b' = 0 \\
b = b' = 0
\end{gather}$$

$$\begin{gather}
a + x = b \\
(-a) + a + x = (-a) + b \\
x = b +(- a)
\end{gather}$$

$$\begin{gather}
a + x = a \implies x = 0
\end{gather}$$

$$\begin{gather}
\alpha\cdot 0 \overset{?}{=} 0 \\
0 \cdot a \overset{?}{=} 0
\end{gather}$$

$$\begin{gather}
(-1)\cdot a \overset{?}{=} -a \\
(-1)a + a = (-a)a + 1\cdot a = (-1+ 1)a = 0
\end{gather}$$

$$\begin{gather}
a = 1\cdot a = (\alpha^{-1}\alpha)a = \alpha^{-1}(\alpha a) = \alpha^{-1}\cdot 0 = 0
\end{gather}$$

$$\begin{gather}
\alpha a = \beta a \iff \begin{cases}
a = 0 \\
\alpha = \beta
\end{cases} \\
\alpha a = \alpha b \iff \begin{cases}
a = b \\
\alpha = 0
\end{cases}
\end{gather}$$

Интегральный оператор Фредгольма:

$$\begin{gather}
(Ax)(t) = \int_{a}^{b}K(t,s)x(s) \, ds
(Ax)(t) \leq ||K||(b-a)||x||
\end{gather}$$

Интегральное уравнение Фредгольма второго рода:

$$\begin{gather}
x(t) = \mu\int_{a}^{b} K(t,s)x(s) \, ds + f(t)
\end{gather}$$


Достаточное условие существования и единственности решения:

$$\begin{gather}
|\mu|||K||\underbrace{(b-a)}_{L} < 1
\end{gather}$$

Уравнение Вито Вальтерра:

$$\begin{gather}
x(t) = \mu \int_{a}^{t}K(t,s)x(s) \, ds  + f(t)
\end{gather}$$

$$\begin{gather}
t \leq a + L - \text{единственное решение}
\end{gather}$$

Уравнение имеет решение всегда, на всей числовой оси, так как следующую операцию можно провести сколь угодно много раз (разбиение интеграла):

$$\begin{gather}
\int_{a}^{a+L} + \int_{a+L}^{t} + \dots
\end{gather}$$

$$\begin{gather}
\mathbb{R}^{n}_{\mathrm{max}}, \ x = (x_{1},x_{2},\dots x_{n}) \\
f(x) = a_{1}x_{1} + \dots + a_{n}x_{n} \\
f(x) = f\left(\sum_{k=1}^{n} x_{k} e_{k} \right) = \sum x_{k}\underbrace{f(e_{k})}_{a_{k}} \\
\end{gather}$$

$$\begin{gather}
||f|| = \underset{||x||\leq 1}{\mathrm{max}} \ |f(x)| \\
|f(x)| \leq \left| \sum_{k=1}^{n} a_{k}x_{k} \right|  \leq \sum_{k=1}^{n}|a_{k}||x_{k}| \leq \sum_{k=1}^{n} |a_{k}| \ \mathbb{R}_{1}^{n}
\end{gather}$$

Получается, что $\left( \mathbb{R}_{\mathrm{max}}^{n} \right)^{*} = \mathbb{R}_{1}^{n}$ ($*$ - сопряженное).
