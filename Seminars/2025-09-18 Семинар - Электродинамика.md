# Электростатическое поле электрического заряда, распределенного в свободном пространстве с объемной плотностью $\rho(\vec{r})$.

## 1. Постановка задачи

Основная характеристика электростатического поля - напряженность электрического поля. Электрические заряды создают электростатическое поле.

$$\begin{gather}
\left( \vec{j} = 0, \ \frac{\partial }{\partial t} = 0 \right)
\end{gather}$$

Система уравнений электродинамики:

$$\begin{cases}
1. \ \mathrm{rot} \ \vec{E} = 0 \\
2. \ \mathrm{div} \ \vec{D} = \rho \\
3. \ \vec{D} = \epsilon_{a} \vec{E}
\end{cases}$$

$\vec{E}$ - напряженность электрического поля,
$\vec{D}$ - индукция электрического поля,
$\vec{H}$ - напряженность магнитного поля,
$\vec{B}$ - индукция магнитного поля,
$\epsilon_{a}$ - абсолютная диэлектрическая проницаемость среды,
$\epsilon = \frac{\epsilon_{a}}{\epsilon_{0}}$ - аналог в вакууме.

Граничное условие: 
$$\begin{gather}
\left.\vec{E}(\vec{r})\right|_{r \to \infty} \to 0
\end{gather}$$

В электростатике заряды зависят только от координат, не зависят от времени.

$$\begin{gather}
\rho(\vec{r}) = \begin{cases}
\rho(\vec{r}') \ \text{в некоторой области} \ V \\
0 \ \text{вне области} \ V
\end{cases}
\end{gather}$$

![[2025-09-18 Семинар - Электродинамика 2025-09-18 16.31.24.excalidraw]]

$$\begin{gather}
\vec{E}_{(\vec{r})} = -\nabla \phi(\vec{r})
\end{gather}$$

Выведем уравнение для потенциала:

$$\begin{gather}
\mathrm{div} \ \vec{E} = \frac{\rho}{\epsilon_{a}} \\
\mathrm{div} \nabla \phi(\vec{r}) = -\frac{\rho}{\epsilon_{a}} \\
\Delta \phi = -\frac{\rho}{\epsilon_{a}}, \ \left(\Delta - \text{оператор Лапласа}\right) - \text{уравнение Пуассона} \\
\left.\phi \right|_{r \to \infty} \to 0
\end{gather}$$

Задача - определить $\vec{E}$.
Решаем уравнение Пуассона в три этапа:
### 1 этап. Определение потенциала точечного заряда, находящегося в начале координат.

![[2025-09-18 Семинар - Электродинамика 2025-09-18 16.43.18.excalidraw]]

$$\vec{E} = \vec{r}^{0}\cdot \frac{q}{4\pi \epsilon_{a} r^{2}}$$

$$\phi(\vec{r}) = \phi(r)$$

$$\begin{gather}
Q = \int_{V} \rho(\vec{r}) \, dv
\end{gather}$$

Точечный заряд имеет плотность бесконечную в самой точке, и нулевую в остальных.

$$\begin{gather}
\rho = \begin{cases}
\infty, \ \vec{r} = 0 \\
0, \ \vec{r} \neq 0
\end{cases}
\end{gather}$$

Во всех точках, кроме начала координат, потенциал удовлетворяет нулю. $\vec{r} \neq 0 \implies \Delta\phi(r) = 0$ - уравнение Лапласа.

$$\begin{gather}
\Delta \phi(r)_{\text{в сфер.}} = \frac{1}{r^{2}} \frac{\partial }{\partial r}\left(  r^{2} \cdot \frac{\partial \phi}{\partial r} \right) = 0
\end{gather}$$

$$\begin{gather}
r^{2} \frac{\partial \phi}{\partial r} = C_{1} \\
\phi = -\frac{C_{1}}{r} + C_{2}
\end{gather}$$

$$\begin{gather}
\left.\phi \right|_{r \to \infty} \to 0 \implies C_{2} = 0
\end{gather}$$

$$\begin{gather}
\phi(r) = -\frac{C_{1}}{r} \\
\end{gather}$$

Для определения константы $C_{1}$ используем уравнение Пуассона.
Возьмем шар объема $r$, как объем интегрирования, тогда по теореме Остроградского-Гаусса:

$$\begin{gather}
\underbrace{\int_{V_{r}} \Delta \phi(r) \, dv}_{(1)} = -\int_{V_{r}} \frac{\rho(\vec{r})}{\epsilon_{a}} \, dv = -\frac{1}{\epsilon_{a}}q \\
(1): \int_{V_{r}} \mathrm{div} \ \mathrm{grad} \ \phi \, dv = \oint_{S_{r}} \mathrm{grad} \phi \, \vec{ds} = \oint_{S_{r}}\vec{r}^{0} \cdot \frac{d\phi}{dr} \vec{r}^{0} ds = \\
= \oint_{S_{r}} \frac{d}{dr}\left( -\frac{C_{1}}{r} \right)  ds = \oint_{S_{r}} \frac{C_{1}}{r^{2}} ds = \frac{C_{1}}{r^{2}} \oint_{S_{r}} ds = \frac{C_{1}}{r^{2}}\cdot S_{r} = \\
= \frac{4\pi r^{2}}{r^{2}} C_{1} = 4\pi C_{1} \\
4\pi C_{1} = -\frac{q}{\epsilon_{a}} \implies C_{1} = -\frac{q}{4\pi\epsilon_{a}}
\end{gather}$$

$$\begin{gather}
\phi(r) = \frac{q}{4\pi\epsilon_{a}r} \\
\vec{E} = \vec{r}^{0} \frac{q}{4\pi\epsilon_{a}r^{2}}
\end{gather}$$

$$\begin{gather}
\rho(\vec{r}) = q\delta(\vec{r}) , \ \delta(\vec{r}) = \begin{cases}
\infty, \ \vec{r} = 0 \\
0, \ \vec{r} \neq 0
\end{cases} \\
\end{gather}$$

$$\begin{gather}
q = \int_{V} \rho(\vec{r}) \, dv = \int_{V} q\delta(\vec{r}) \, dv \\
\implies \int_{V} \delta(\vec{r}) \, dv = 1
\end{gather}$$

### 2 этап. Определение потенциала точечного заряда, расположенного в произвольной точке (в т. $\vec{r}^{0}$)

![[2025-09-18 Семинар - Электродинамика 2025-09-18 17.30.28.excalidraw]]

$$\begin{gather}
\phi(\vec{r}) = \frac{q}{4\pi\epsilon_{a} \left| \vec{r} - \vec{r}_{0} \right| }
\end{gather}$$

### 3 этап. Записать решение уравнения Пуассона при заданной функции $\rho(\vec{r})$.

Рассмотрим заряд $q$ в маленьком шаре. Тогда:

$$\begin{gather}
\rho(\vec{r}') dv' \\
d\phi = \frac{\rho(\vec{r}')dv'}{4\pi\epsilon_{a}\left| \vec{r} - \vec{r}' \right| }
\end{gather}$$
