# Электростатическое поле электрического заряда, распределенного в свободном пространстве с объемной плотностью $\rho(\vec{r})$.

## 1. Постановка задачи

Основная характеристика электростатического поля - напряженность электрического поля. Электрические заряды создают электростатическое поле.

$$\begin{gather}
\left( \vec{j} = 0, \ \frac{\partial }{\partial t} = 0 \right)
\end{gather}$$

Система уравнений электродинамики:

$$\begin{cases}
1. \ \mathrm{rot} \ \vec{E} = 0 \\
2. \ \mathrm{div} \ \vec{D} = \rho \\
3. \ \vec{D} = \epsilon_{a} \vec{E}
\end{cases}$$

$\epsilon_{a}$ - абсолютная диэлектрическая проницаемость среды
