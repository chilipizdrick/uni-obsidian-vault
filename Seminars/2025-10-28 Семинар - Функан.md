> [!definition] Функционал
> Линей

$$\begin{gather}
C[-1,1], \ f(x) = x(0)
\end{gather}$$

> [!definition] Дельта функционал
> Дельта функционал сопоставляет в каждой точке функции ее значение.

$$\begin{gather}
f(\alpha x' + \beta x'') = \alpha f(x') +\beta f(x'')
\end{gather}$$

$$\begin{gather}
||x|| \leq M
\end{gather}$$

$$\begin{gather}
\forall \epsilon \exists \delta > 0 : \ ||x'-x''|| < \delta \implies |f(x') - f(x'')| < \epsilon
\end{gather}$$

> [!important] Теорема
> Для линейных функционалов ограниченность и непрерывность связанны.

$$\begin{gather}
f(x) = \underset{t \in[-1;1]}{\mathrm{max}} |x(t)|
\end{gather}$$

$$\begin{gather}
f(x) = \begin{cases}
1, \ x(t) \geq 0 \forall t, \ x(t) \not\equiv 0 \\
0, \ x \equiv 0 \\
-1, \ \exists t \ | \ x(t) < 0 \\
\end{cases}
\end{gather}$$

> [!important] Теорема
> Если функционал ограничен на $CL_{1}[a,b]$, то он ограничен в $C[a,b]$. Аналогично и для непрерывности.
