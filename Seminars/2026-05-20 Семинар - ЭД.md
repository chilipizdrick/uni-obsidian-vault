## Пр. №15 Возбуждение основной волны пряугольного волновода, ограниченного на одном конце идеально проводящей плоскостью, ЭМИ.

![[2026-05-20 Семинар - ЭД 2026-05-20 13.03.53.excalidraw]]

$$\begin{gather}
0 < z < \infty \\
\left.\dot{\vec{E}}_{m\tau} \right|_{z=0} = 0
\end{gather}$$

$$\begin{gather}
\dot{\vec{E}}_{m}(\vec{r}) = \begin{cases}
C_{o}^{(-)} \dot{\vec{E}}_{mo}^{(-)}(\vec{r}), \ z < z_{0} \\
C_{o}^{(+)} \dot{\vec{E}}_{mo}^{(+)}(\vec{r}), \ z < z_{0} \\
\end{cases}
\end{gather}$$

$$\begin{gather}
C_{o}^{(\pm)} = \frac{1}{N_{0}}\dot{I}_{m}^{ст} (\vec{l}^{м}, \dot{\bar{H}}_{mo}(\vec{r})), N_{o} = -\frac{E_{o}^{2}ab}{W_{o}}
\end{gather}$$

$$\begin{gather}
\dot{\vec{E}}_{mo}^{(\pm)} = \vec{y}^{0} \dot{E}_{o} \sin\left( \frac{\pi}{a} x \right)e^{\mp i\Gamma_{o}z}, \\
\dot{\vec{H}}_{mo}^{(\pm)} = \frac{E_{o}}{W_{o}}\left( \mp \vec{x}^{0} \sin\left( \frac{\pi}{a} x \right) + \vec{z}^{0} i \frac{\pi}{\Gamma_{o}a} \cos\left( \frac{\pi}{a} x \right) \right)e^{\mp i\Gamma_{o}z} \\
\end{gather}$$

$$\begin{gather}
\dot{\vec{E}}_{m}(\vec{r}) = \\
= \vec{y}^{0} \frac{\dot{I}_{m}^{м.ст}}{ab} \left(\vec{l}^{м}, \left( \mp \vec{x}^{0} \sin\left( \frac{\pi}{a} x \right) + \vec{z}^{0} i \frac{\pi}{\Gamma_{o}a} \cos\left( \frac{\pi}{a} x \right) \right)\right)\sin\left( \frac{\pi}{a}x \right)e^{\mp i\Gamma_{o}|z-z_{0}|}
\end{gather}$$

$-$ - при $z < z_{0}$, $+$ - при $z > z_{0}$

Амплитута будет максимальна тогда, когда момент направлен либо по оси $\vec{x}^{0}$, либо по оси $\vec{z}^{0}$.

### 1. $\vec{l}^{м} = \vec{x}^{0}l^{м}$

Используем метод зеркальных отображений чтобы решить задачу для магнитного излучателя:

$$\begin{gather}
\dot{\vec{E}}_{m}(\vec{r}) = \dot{\vec{E}}_{m}(\vec{r}, \vec{r}_{0}) + \dot{\vec{E}}_{m}(\vec{r}, -\vec{r}_{0})
\end{gather}$$

$$\begin{gather}
\dot{\vec{E}}_{m}(\vec{r}) = \frac{\vec{y}^{0}\dot{I}_{m}^{м.ст}l^{м}}{ab} \sin\left( \frac{\pi}{a} x_{0} \right)\sin\left( \frac{\pi}{a}x \right) \left(
\mp e^{-i\Gamma_{o}|z - z_{0}|} + e^{-i\Gamma_{o}(z + z_{0})}\right) = \\
= \frac{\vec{y}^{0}\dot{I}_{m}^{м.ст}l^{м}}{ab} \sin\left( \frac{\pi}{a} x_{0} \right)\sin\left( \frac{\pi}{a}x \right) \begin{cases}
e^{-i\Gamma_{o}z_{0}}(-2i)\sin(\Gamma_{o}z), \ z < z_{0} \\
2 \cos(\Gamma_{o}z_{0})e^{-i\Gamma_{o}z}, \ z > z_{0}
\end{cases}
\end{gather}$$

### 2. $\vec{l}^{м} = \vec{z}^{0}l^{м}$

$$\begin{gather}
\dot{E}_{m}(\vec{r}) = \\
= \vec{y}^{0} \frac{\dot{I}_{m}^{м.ст}l^{м}}{ab} i \frac{\pi}{\Gamma_{o}a}\cos\left( \frac{\pi}{a}x_{0} \right)\sin\left( \frac{\pi}{a}x \right) \begin{cases}
e^{-i\Gamma_{o}z_{0}}e^{i\Gamma_{o}z} - e^{-i\Gamma_{o}z_{0}} e^{-i\Gamma_{o}z}, \ z < z_{0} \\
e^{i\Gamma_{o}z_{0}}e^{-i\Gamma_{o}z} - e^{-i\Gamma_{o}z_{0}} e^{-i\Gamma_{o}z}, z > z_{0} \\
\end{cases} = \\
= \vec{y}^{0} \frac{\dot{I}_{m}^{м.ст}l^{м}}{ab} i \frac{\pi}{\Gamma_{o}a}\cos\left( \frac{\pi}{a}x_{0} \right)\sin\left( \frac{\pi}{a}x \right) \begin{cases}
e^{-i\Gamma_{o}z_{0}} \cdot 2i\sin(\Gamma_{o}z), z < z_{0}  \\
2i\sin(\Gamma_{o}z_{0})e^{-i\Gamma_{o}z}, z > z_{0}
\end{cases}
\end{gather}$$
