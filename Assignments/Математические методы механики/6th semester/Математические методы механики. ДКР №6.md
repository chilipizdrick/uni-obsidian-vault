### 1.

В состоянии равновесия: 

$$\sum \vec{F}_{k} = 0 \implies \vec{P} + \vec{F}_{упр} = 0$$

Откуда

$$\begin{gather}
mg = c\delta_{ст} \implies \delta_{ст} = \frac{mg}{c} = \frac{15\cdot 9.8}{1000} = 0.147 \ м = 14.7 \ см
\end{gather}$$

$$\begin{gather}
l_{st} = l_{0} + \delta_{ст} = 0.3 + 0.147 = 0.447 \ м
\end{gather}$$

$$\begin{gather}
x_{0} = l - l_{ст} = 0.28 - 0.447 = -0.167 \ м \\
v_{0} = 0.6 \ \frac{м}{с} - \text{по условию}
\end{gather}$$

$$\begin{gather}
k = \sqrt{ \frac{c}{m} } = \sqrt{ \frac{1000}{15} } = \frac{10\sqrt{ 6 }}{3} \approx 8.16 \ \frac{рад}{с}
\end{gather}$$

$$\begin{gather}
\ddot{x} + k^{2}x = 0 \\
x(t) = A\cos kt + B \sin kt
\end{gather}$$

$$\begin{gather}
x(0) = A = x_{0} = -0.167 \ м \\
\dot{x}(0) = B\cdot k = v_{0} \implies \\
\implies B = \frac{v_{0}}{k} = \frac{0.6\cdot 3}{10 \sqrt{ 6 }} = \frac{3\sqrt{ 6 }}{100} \approx 0.0735 \ м
\end{gather}$$

$$\begin{gather}
x(t) = -0.167\cos(8.16 \cdot t) + 0.0735\sin(8.16 \cdot t), \ м
\end{gather}$$

### 2.

$$\begin{gather}
m \vec{a} = \vec{P} + \vec{F}_{упр} + \vec{S}
\end{gather}$$

Спроецируем силы на ось $x$ с учетом возмущающей силы, тогда

$$\begin{gather}
m \ddot{x} = mg - c(x + \delta_{ст}) + S_{0}\sin pt
\end{gather}$$

Так как $mg - c\delta_{ст} = 0$, уравнение принимает вид:

$$\begin{gather}
m \ddot{x} + cx = S_{0}\sin pt
\end{gather}$$

Для поиска вынужденных колебаний груза при действии на него силы $\vec{S}$ найдем частное решение полученного уравнения. Будем искать решение в виде:

$$\begin{gather}
x^{чн}(t) = X \sin pt \\
\end{gather}$$

Подставив в уравнение, получим:

$$\begin{gather}
-m\cdot X\cdot p^{2} \sin pt + c \cdot X \sin pt = S_{0} \sin pt \\
-mXp^{2} + cX = S_{0}  \\
X(c - mp^{2}) = S_{0} \implies X = \frac{S_{0}}{c-mp^{2}}
\end{gather}$$

$$\begin{gather}
X = \frac{15}{1000 - 15 \cdot 3^{2}} = \frac{3}{173} \approx 0.0173 \ м
\end{gather}$$

Уравнение вынужденных полебаний груза:

$$\begin{gather}
x^{чн}(t) = \frac{3}{173}\sin 3t \approx 0.0173 \cdot \sin 3t, \ м
\end{gather}$$
