### $T = T_{1} + T_{2} + T_{3}$

При решении задачи 7 было выяснено, что

$$\begin{gather}
T = \left( 2m_{1}R^{2} + m_{2}R^{2} + \frac{1}{2}m_{3}(R^{2} + r^{2}) \right) \omega_{3}^{2}
\end{gather}$$

Зная, что $\omega_{3} = \frac{v_{1}}{2R} = \frac{\dot{x}_{1}}{2R}$, получим:

$$\begin{gather}
T = \left( 2m_{1}R^{2} + m_{2}R^{2} + \frac{1}{2}m_{3}(R^{2} + r^{2}) \right) \frac{\dot{x}_{1}^{2}}{4R^{2}} \\
T = \left( \frac{m_{1}}{2} + \frac{m_{2}}{4} + \frac{m_{3}(R^{2} + r^{2})}{8R^{2}} \right) \dot{x}_{1}^{2}
\end{gather}$$

$$\begin{gather}
\frac{ \partial T }{ \partial \dot{x} } = 2\left( \frac{m_{1}}{2} + \frac{m_{2}}{4} + \frac{m_{3}(R^{2} + r^{2})}{8R^{2}} \right) \dot{x}_{1} \\
\frac{d}{dt}\frac{ \partial T }{ \partial \dot{x} } = 2\left( \frac{m_{1}}{2} + \frac{m_{2}}{4} + \frac{m_{3}(R^{2} + r^{2})}{8R^{2}} \right) \ddot{x}_{1}
\end{gather}$$

$$\begin{gather}
\frac{ \partial T }{ \partial x } = 0
\end{gather}$$

### $\sum \delta A_{k}$

Также при решении задачи 7 было выяснено, что представленная сисетма система с идеальными связями, и

$$\sum \delta A_{k} = \left( FR + m_{3}gR\sin\alpha - 2m_{1}gR - M\frac{2R}{r} \right) \delta\phi_{3}$$

Зная, что $\phi_{3} = \frac{x_{1}}{2R}$, получим:

$$\begin{gather}
\sum \delta A_{k} = \left( FR + m_{3}gR\sin\alpha - 2m_{1}gR - M\frac{2R}{r} \right) \frac{1}{2R}\delta x_{1} = \\
= \underbrace{\left( \frac{F}{2} + \frac{m_{3}g\sin\alpha}{2} - m_{1}g - \frac{M}{r} \right)}_{Q_{1}} \delta x_{1}
\end{gather}$$

Наконец, получаем уравнение Лагранжа движения системы:

$$\begin{gather}
\left[ m_{1} + \frac{m_{2}}{2} + \frac{m_{3}(R^{2} + r^{2})}{4R^{2}} \right] \ddot{x}_{1} = \frac{F}{2} + \frac{m_{3}g\sin\alpha}{2} - m_{1}g - \frac{M}{r}
\end{gather}$$
