## Математические методы механики. ДКР №5

### Ершов Алексей Геннадьевич КМБО-03-23

### Вариант 5

$$\begin{align}
& m = 0.5 \ кг \\
& F_{1x} = 3 \sin \pi t, Н; F_{1y} = 0, H \\
& F_{2x} = -10 \ Н; F_{2y} = 3\cos \pi t, Н \\
& x_{0} = 0 \ м, \ y_{0} = -1 \ м \\
& v_{0x} = 0.03 \ \frac{м}{с}; v_{0y} = 0 \ \frac{м}{с} \\
& \hline x(t) - ? , \ y(t) - ?
\end{align}$$

![[Механика КР 5 2026-03-09 11.24.13.excalidraw]]

$$\begin{gather}
F_{x} = 3\sin \pi t - 10, \ Н \\
F_{y} = 3\cos \pi t, Н \\
\end{gather}$$

$$\begin{gather}
a_{x}(t) = \frac{F_{x}(t)}{m} = 6\sin \pi t - 20, \frac{м}{c^{2}} \\
a_{y}(t) = \frac{F_{y}(t)}{m} = 6\cos \pi t, \frac{м}{c^{2}} \\
\end{gather}$$

$$\begin{gather}
v_{x}(t) = \int a_{x}(t) \, dt \\
v_{x}(t) = \int (6\sin \pi t - 20) \, dt = -\frac{6}{\pi}\cos \pi t - 20t + C \\
\end{gather}$$

$$\begin{gather}
v_{x}(0) = -\frac{6}{\pi}\cdot 1 + C = 0.03 \implies C = \frac{6}{\pi} + 0.03 \\
v_{x}(t) = -\frac{6}{\pi}\cos \pi t - 20t + \frac{6}{\pi} + 0.03, \frac{м}{с}
\end{gather}$$

$$\begin{gather}
v_{y}(t) = \int a_{y}(t) \, dt \\
v_{y}(t) = \int (6\cos \pi t) \, dt = \frac{6}{\pi}\sin \pi t + C \\
\end{gather}$$

$$\begin{gather}
v_{y}(0) = C = 0 \implies C = 0 \\
v_{y}(t) = \frac{6}{\pi}\sin \pi t, \frac{м}{c}
\end{gather}$$

$$\begin{gather}
x(t) = \int v_{x}(t) \, dt \\
x(t) = \int \left(-\frac{6}{\pi}\cos \pi t - 20t + \frac{6}{\pi} + 0.03\right) \, dt = \\
= -\frac{6}{\pi^{2}}\sin \pi t - 10t^{2} + \left(\frac{6}{\pi} + 0.03 \right)t + C \\
\end{gather}$$

$$\begin{gather}
x(0) = C = 0 \implies C = 0 \\
x(t) = -\frac{6}{\pi^{2}}\sin \pi t - 10t^{2} + \left(\frac{6}{\pi} + 0.03 \right)t, \ м
\end{gather}$$

$$\begin{gather}
y(t) = \int v_{y}(t) \, dt \\
y(t) = \int \frac{6}{\pi}\sin \pi t  \, dt = -\frac{6}{\pi^{2}}\cos \pi t + C \\
\end{gather}$$

$$\begin{gather}
y(0) = -\frac{6}{\pi^{2}} + C = -1 \implies C = \frac{6}{\pi^{2}} - 1 \\
y(t) = -\frac{6}{\pi^{2}}\cos \pi t + \frac{6}{\pi^{2}} - 1, \ м
\end{gather}$$

Ответ:

$$\begin{cases}
x(t) = -\frac{6}{\pi^{2}}\sin \pi t - 10t^{2} + \left(\frac{6}{\pi} + 0.03 \right)t \\
y(t) = -\frac{6}{\pi^{2}}\cos \pi t + \frac{6}{\pi^{2}} - 1
\end{cases}$$
