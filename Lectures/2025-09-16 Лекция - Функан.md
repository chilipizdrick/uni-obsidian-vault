### Евклидово пространство

$$\begin{gather}
E^{n}, \ ||x||_{2} = \sqrt{ \sum_{k=1}^{n} |x_{k}|^{2}  }, \ \rho_{2}(x,y) = \sqrt{ \sum_{k=1}^{n} |x_{k} - y_{k}|^{2} }
\end{gather}$$


$$\begin{gather}
\sum_{k=1}^{n} x_{k}y_{k} \leq \sqrt{ \sum_{k=1}^{n} x_{k}^{2} } \sqrt{ \sum_{k=1}^{n} y_{k}^{2} }
\end{gather}$$

### Доказательство

$$\begin{gather}
\Phi(\lambda) = \sum_{k=1}^{n} (x_{k} + \lambda y_{k})^{2} = \sum_{k=1}^{n} x_{k}^{2} + 2
\end{gather}$$
