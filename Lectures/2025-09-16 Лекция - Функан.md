### Евклидово пространство

$$\begin{gather}
E^{n}, \ ||x||_{2} = \sqrt{ \sum_{k=1}^{n} |x_{k}|^{2}  }, \ \rho_{2}(x,y) = \sqrt{ \sum_{k=1}^{n} |x_{k} - y_{k}|^{2} }
\end{gather}$$


$$\begin{gather}
\sum_{k=1}^{n} x_{k}y_{k} \leq \sqrt{ \sum_{k=1}^{n} x_{k}^{2} } \sqrt{ \sum_{k=1}^{n} y_{k}^{2} }
\end{gather}$$

### Доказательство

$$\begin{gather}
\Phi(\lambda) = \sum_{k=1}^{n} (x_{k} + \lambda y_{k})^{2} = \sum_{k=1}^{n} x_{k}^{2} + 2\lambda \sum_{k=1}^{n} x_{k}y_{k} + \lambda^{2} \sum_{k=1}^{n} y_{k}^{2} \geq 0 \\
\frac{D}{4} = \left(\sum_{k=1}^{n} x_{k}y_{k}\right)^{2} - \sum_{k=1}^{n} x_{k}^{2} \sum_{k=1}^{n} y_{k}^{2} \leq 0 \ \blacksquare
\end{gather}$$

$$\begin{gather}
||x+y||^{2} = \sum_{k=1}^{n} (x_{k} + y_{k})^{2} = \sum_{k=1}^{n} x_{k}^{2} + 2\sum_{k=1}^{n} x_{k}y_{k} + \sum_{k=1}^{n} y_{k}^{2} \leq \\
\leq \sum_{k=1}^{n} x_{k}^{2} + 2\sqrt{ \sum_{k=1}^{n} x_{k}^{2} }\sqrt{ \sum_{k=1}^{n} y_{k}^{2} } + \sum_{k=1}^{n} y_{k}^{2} = \\
= \left( \sqrt{ \sum_{k=1}^{n} x_{k}^{2}  } + \sqrt{ \sum_{k=1}^{n} y_{k}^{2}  } \right) = \left( ||x|| + ||y|| \right)^{2}
\end{gather}$$

Неравенство треугольника выполняется.

> [!definition] Изометричное пространство
> Метрическое пространство $X$ изометрично пространству $Y$, если существует такое $\tau: X \to Y$, что $\rho_{2}(\tau(x_{1}), \tau(x_{2})) = \rho_{1}(x_{1}, x_{2}) \forall x_{1},x_{2} \in X$.

Открытый шар с центром в точке $a$ - $S_{r}(a) = \{ x: \rho(x,a) < r \}$ - $r$-окрестность точки $a$.
Закрытый шар с чентром в точке $a$ - $\overline{S}_{r}(a) = \{ x: \rho(x,a) \leq r \}$.
Сфера с центром в точке $a$ - $\sigma_{r}(a) = \{ x: \rho(x,a) = r \}$

$\sup_{x,y \in A} \rho(x,y)$ - диаметр пространства.

Множество ограниченное, если $A \subset S_{r}(a)$.
Множество вполне ограниченное, если $\forall \epsilon \exists \{ a_{1}, a_{2}, \dots, a_{n} \} \ A \sum\{ \bigcup_{k=1}^{N} S(\epsilon)(a_{k}) \}$.
