### 1. Лемма Лоренца

$$\begin{gather}
\oint_{S} \left\{ \left[ \dot{\vec{E}_{m 1}}, \dot{\vec{H}}_{m 2} \right] - \left[ \dot{\vec{E}_{m 2}}, \dot{\vec{H}}_{m 1} \right]  \right\} \vec{\nu}^{0} ds = \\
= \int_{V} \left( \dot{\vec{j}}^{ст}_{m 1} \dot{\vec{E}}_{m 2} - \dot{\vec{j}}_{m 1}^{м.ст}\dot{\vec{H}}_{m 2} - \dot{\vec{j}}_{m 2}^{ст} \dot{\vec{E}}_{m 1} +  \dot{\vec{j}}_{m 2} ^{м.ст} \dot{\vec{H}}_{m 1} \right)  \, dv = Q_{k}^{(+)}
\end{gather}$$

1. $\dot{\vec{E}}_{m 2} = \dot{\vec{E}}^{(+)}_{mk}, \ \dot{\vec{H}}_{m 2} = \dot{\vec{H}}^{(+)}_{mk}$

2. $\dot{\vec{E}}_{m 2} = \dot{\vec{E}}^{(-)}_{mk}, \ \dot{\vec{H}}_{m 2} = \dot{\vec{H}}^{(-)}_{mk}$ 

$$\begin{gather}
\int_{S_{1}} \left\{ \left[ \dot{\vec{E}}_{m}, \dot{\vec{H}}_{mk}^{(+)} \right] - \left[ \dot{\vec{E}}_{mk}^{(+)}, \dot{\vec{H}}_{m} \right]   \right\} (-\vec{z}^{0})  \, ds + \int_{S_{2}} \left\{ \left[ \dot{\vec{E}}_{m}, \dot{\vec{H}}_{mk}^{(+)} \right] - \left[ \dot{\vec{E}}_{mk}^{(+)}, \dot{\vec{H}}_{m} \right]   \right\} \vec{z}^{0}  \, ds = Q_{k}^{(+)}
\end{gather}$$

$$\begin{gather}

\end{gather}$$

$$\begin{gather}
N_{k} = \int_{S_{1}} \left\{ \left[ \dot{\vec{E}}^{(+)}_{mk}, \dot{\vec{H}}_{mk}^{(-)} \right] - \left[ \dot{\vec{E}}^{(-)}_{mk}, \dot{\vec{H}}_{mk}^{(+)} \right] \right\} \vec{z}^{0} \, ds
\end{gather}$$

При $z < z_{1}$: 

$$\begin{gather}
\dot{\vec{H}}_{m} = \sum_{l=1}^{+\infty} C_{l}^{(-)} \dot{\vec{H}}_{ml}^{(-)}, \ \dot{\vec{H}}_{m} = \sum_{l=1}^{+\infty} C_{l}^{(-)} \dot{\vec{H}}_{ml}^{(-)}
\end{gather}$$

При $z > z_{2}$: 

$$\begin{gather}
\dot{\vec{H}}_{m} = \sum_{l=1}^{+\infty} C_{l}^{(+)} \dot{\vec{H}}_{ml}^{(+)}, \ \dot{\vec{H}}_{m} = \sum_{l=1}^{+\infty} C_{l}^{(+)} \dot{\vec{H}}_{ml}^{(+)}
\end{gather}$$

Воспользовавшись леммой, получим:

$$\begin{gather}
C_{k}^{(-)} = \frac{1}{N_{k}}Q_{k}^{(+)}
\end{gather}$$
