## Л. № 4. Тема 5. Дифракция электромагнитных волн
### 5.1. Постановка задачи диффракции

Постановка задачи: рассмотрим падение некоторой электромангитной волны на тело, расположенное в линейной изотропной однородной среде, характеризующейся параметрами $\epsilon_{a}, \mu_{a}, \sigma$.

$$\begin{gather}
k_{1} = k = \omega \sqrt{ \epsilon_{a}\mu_{a} } \\
W_{1} = W = \sqrt{ \frac{\mu_{a}}{\epsilon_{a}} }
\end{gather}$$

![[2026-04-01 Лекция - ЭД 2026-04-01 11.08.17.excalidraw]]

$$\begin{gather}
\dot{\vec{E}}_{m}(\vec{r}) = \dot{\vec{E}}_{m}^{(0)}(\vec{r}) + \dot{\vec{E}}_{m}^{вт}(\vec{r})
\end{gather}$$

Первичное поле удовлетворяет неоднородной системе уравнений электродинамики, а вторичное - однородной, так как внутри области $S$ - источников нет.

Для реальных тел граничные условия ЭД записываются в виде:

$$\begin{gather}
\begin{cases}
\left.\dot{\vec{E}}_{m\tau}^{(1)}\right|_{S} = \left.\dot{\vec{E}}_{m\tau}^{(2)}\right|_{S}, \\
\left.\dot{\vec{H}}_{m\tau}^{(1)}\right|_{S} = \left.\dot{\vec{H}}_{m\tau}^{(2)}\right|_{S}. \\
\end{cases} \ (**)
\end{gather}$$

При $\sigma_{2} = \infty$:

$$\begin{gather}
\dot{\vec{E}}_{m}^{(2)}(\vec{r}) = 0 \\
\dot{\vec{H}}_{m}^{(2)}(\vec{r}) = 0 \\
\left.\vec{E}_{m\tau}\right|_{S} = 0 \ (*)
\end{gather}$$

$$\begin{gather}
\begin{cases}
\mathrm{rot} \ \dot{\vec{H}}_{m}^{вт} = i\omega  \dot{\epsilon}_{a} \dot{\vec{E}}_{m}^{вт} \\
\mathrm{rot} \ \dot{\vec{E}}_{m}^{вт} = -i\omega  \mu_{a} \dot{\vec{H}}_{m}^{вт}
\end{cases}
\end{gather}$$

Вторичное электромагнитное поле должно удовлетворять условию на бесконечности.

Иными словами диффракция - огибание электромагнитной волной встречных препятствий.

Строгий метод решения задач диффракции - один, надо чтобы огибаемое тело можно было представить в виде одной из координатных плоскостей, тогда в такой системе можно будет решить диф. уравнение методом разделения переменных.

### 5.3. Диффракция плоской однородной волны на бесконечном идеально проводящем цилиндре.

![[2026-04-01 Лекция - ЭД 2026-04-01 10.48.04.excalidraw]]

Цилиндр бесконечный по оси $z$, остальные характеристики и волны можно увидеть на рисунке. Дано: начальное поле $(1)$ и условие $(*)$ а также условие на бесконечности.

$$\begin{gather}
\left.\dot{\vec{E}}_{m\tau}\right|_{r = a} = 0 \ (*) \\
\dot{\vec{E}}_{m}^{(0)} = \vec{z}^{0} \dot{E}_{0} e^{ikx} = \vec{z}^{0} \dot{E}_{0} e^{ikz\cos\alpha} \ (1) \\
\end{gather}$$

К этой задаче можно применить метод разделения переменных, для эгоно необходимо использовать циллиндрическую систему координат. Это упрощает решение задачи, т.к. теперь первичное и вторичное поля имеют только одну составляющую по $z$. Тогда задача из векторной практически вырождается в скалярную. Осталось разделить дифференциальное уравнение по $\alpha$ и $z$ и найти решение.

$$\begin{gather}
\dot{\vec{E}}_{m} (\vec{r}) = \dot{\vec{E}}_{m}^{(0)} + \dot{\vec{E}}_{m}^{вт} \\
\dot{\vec{E}}_{m}^{вт} = \vec{z}^{0} \dot{E}_{m}^{вт} (z, \alpha) \\
\end{gather}$$

$$\begin{gather}
\dot{\Delta}E_{m}^{вт} = k^{2} \dot{E}_{m}^{вт} = 0 \\
\frac{1}{r}\cdot \frac{ \partial  }{ \partial r } \left( r \cdot \frac{\partial  \dot{E}_{m}^{вт}}{\partial r} \right) + \frac{1}{r^{2}} \frac{ \partial^{2} }{ \partial \alpha^{2} } \dot{E}_{m}^{вт} + k^{2} \dot{E}_{m}^{вт} = 0
\end{gather}$$

$$\begin{gather}
\dot{E}_{m}^{вт} = \sum_{n=0}^{\infty} a_{n}R(r) \cos n\alpha \\
\dot{E}_{m}^{(0)} = E_{0}\left(J_{0}( kz) + 2\sum_{n=1}^{\infty} i^{n} J_{n}(kz) \cos(n\alpha) \right)
\end{gather}$$

$$\begin{gather}
F(r,\alpha) = R(r)A(\alpha) \\
\frac{d^{2}A}{d\alpha^{2}} +   n^{2} A = 0 \\
\cos (n\alpha), \ \sin(n\alpha) \\
n = 0,1,2,\dots
\end{gather}$$

Также знаем, что $A(\alpha + 2\pi) = A(\alpha)$.
