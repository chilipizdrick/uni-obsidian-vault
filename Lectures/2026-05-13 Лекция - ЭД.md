## Л. №7. 6.7. Собственные (свободные) поля для волноводного резонатора.

### 1. Постановка задачи

![[2026-05-13 Лекция - ЭД 2026-05-13 10.52.01.excalidraw]]

Волноводный резонатор - частный случай объемного резонатора.

Объемный резонатор - объем $V$, ограниченный неторогой металической оболочкой, предназначенный для возбуждения и накопления электромагнитной энергии на определенных резонансных частотах.

Отрезок волновода, ограниченный с обоих концов идеально проводящими стенками.

$$\begin{gather}
\begin{cases}
\mathrm{rot} \, \dot{\vec{H}}_{m} = i\omega\epsilon_{a} \dot{\vec{E}}_{m} \\
\mathrm{rot} \, \dot{\vec{E}}_{m} = -i\omega \mu_{a} \dot{\vec{H}}_{m} \\
\end{cases}, \\
\left.\dot{\vec{E}}_{m\tau}\right|_{S} = 0, \ S = S_{0} + S_{1} + S_{2}
\end{gather}$$

$$\begin{gather}
\frac{d^{2}Z^{э}}{dz^{2}} + (\Gamma^{э})^{2} Z^{Э} = 0 \\
\left.\frac{dZ^{э}}{dz}\right|_{z=0} = 0, \ \left.\frac{dZ^{э}}{dz} \right|_{z=L} = 0
\end{gather}$$

1. $E$-поля ($E_{z} \neq 0, \ H_{z} = 0$):

$$\begin{gather}
\dot{\vec{E}}_{m}^{э} = \frac{1}{i\omega\epsilon_{a}} \left( \frac{dZ^{Э}}{dz} \mathrm{grad}_{\perp} \, T^{э} + \vec{z}^{0} (\varkappa^{э})^{2} T^{э} Z^{э} \right) , \ \dot{\vec{H}}_{m}^{э} = \left[ \mathrm{grad}_{\perp} \, T^{э}, \vec{z}^{0} \right]Z^{э}.
\end{gather}$$

$$\begin{gather}
\frac{d^{2}Z^{э}}{dz^{2}} + (\Gamma^{э})^{2} Z^{э} = 0 \to e^{-i\Gamma z}, \ e^{i\Gamma z} \\
T^{э} = T^{э}_{l}, \ \varkappa^{э} = \varkappa_{l}^{э}, \ l = 1,2,\dots \\
\Gamma = \Gamma_{l} = \sqrt{ k^{2} - \varkappa^{2} } \\
k = \omega \sqrt{ \epsilon_{a}\mu_{a} }
\end{gather}$$

$$\begin{gather}
\frac{d^{2}Z^{э}}{dz^{2}} + (\Gamma^{э})^{2} Z^{Э} = 0 \\
\left.\frac{dZ^{э}}{dz}\right|_{z=0} = 0, \ \left.\frac{dZ^{э}}{dz} \right|_{z=L} = 0
\end{gather}$$

Краевые условия эквивалентны $\left.\dot{\vec{E}}_{m\tau} \right|_{z=0} = 0, \ \left.\dot{\vec{E}}_{m\tau}\right|_{z=L} = 0$, что очевидно следует из вида $\dot{\vec{E}}_{m}^{э}$.

Здесь решение очевидно:

$$\begin{gather}
Z^{Э} = \cos\left( \frac{\pi}{L}p z \right), p = 0,1,2\dots
\end{gather}$$

Теперь найдем $\omega_{lp}^{э}$:

$$\begin{gather}
k^{2} = \varkappa_{l}^{2} + (\Gamma^{э}_{l})^{2} \\
(\omega^{2})^{2}\epsilon_{a}\mu_{a} = \varkappa_{l}^{2} + \frac{\pi^{2}p^{2}}{L^{2}} \\
\omega_{lp}^{э} = \frac{1}{\sqrt{ \epsilon_{a} \mu_{a} }}\sqrt{ \varkappa_{l}^{2} + \frac{\pi^{2}p^{2}}{L^{2}} }
\end{gather}$$

\dot{\vec{H}}_{m} = \frac{1}{i\omega \mu_{a}}\left( dZ^{м} \right) 
\end{gather}$$
