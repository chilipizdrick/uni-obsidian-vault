## Л. №7. 6.7. Собственные (свободные) поля для волноводного резонатора.

### 1. Постановка задачи

![[2026-05-13 Лекция - ЭД 2026-05-13 10.52.01.excalidraw]]

Волноводный резонатор - частный случай объемного резонатора.

Объемный резонатор - объем $V$, ограниченный некоторой металической оболочкой, предназначенный для возбуждения и накопления электромагнитной энергии на определенных резонансных частотах.

Волноводный резонатор - это отрезок волновода, ограниченный с обоих концов идеально проводящими стенками.

$$\begin{gather}
\begin{cases}
\mathrm{rot} \, \dot{\vec{H}}_{m} = i\omega\epsilon_{a} \dot{\vec{E}}_{m} \\
\mathrm{rot} \, \dot{\vec{E}}_{m} = -i\omega \mu_{a} \dot{\vec{H}}_{m} \\
\end{cases}, \\
\left.\dot{\vec{E}}_{m\tau}\right|_{S} = 0, \ S = S_{0} + S_{1} + S_{2}
\end{gather}$$

$$\begin{gather}
\frac{d^{2}Z^{э}}{dz^{2}} + (\Gamma^{э})^{2} Z^{Э} = 0 \\
\left.\frac{dZ^{э}}{dz}\right|_{z=0} = 0, \ \left.\frac{dZ^{э}}{dz} \right|_{z=L} = 0
\end{gather}$$

1. $E$-поля ($E_{z} \neq 0, \ H_{z} = 0$):

$$\begin{gather}
\dot{\vec{E}}_{m}^{э} = \frac{1}{i\omega\epsilon_{a}} \left( \frac{dZ^{Э}}{dz} \mathrm{grad}_{\perp} \, T^{э} + \vec{z}^{0} (\varkappa^{э})^{2} T^{э} Z^{э} \right) , \ \dot{\vec{H}}_{m}^{э} = \left[ \mathrm{grad}_{\perp} \, T^{э}, \vec{z}^{0} \right]Z^{э}.
\end{gather}$$

$$\begin{gather}
\frac{d^{2}Z^{э}}{dz^{2}} + (\Gamma^{э})^{2} Z^{э} = 0 \to e^{-i\Gamma z}, \ e^{i\Gamma z} \\
T^{э} = T^{э}_{l}, \ \varkappa^{э} = \varkappa_{l}^{э}, \ l = 1,2,\dots \\
\Gamma = \Gamma_{l} = \sqrt{ k^{2} - \varkappa^{2} } \\
k = \omega \sqrt{ \epsilon_{a}\mu_{a} }
\end{gather}$$

$$\begin{gather}
\frac{d^{2}Z^{э}}{dz^{2}} + (\Gamma^{э})^{2} Z^{Э} = 0 \\
\left.\frac{dZ^{э}}{dz}\right|_{z=0} = 0, \ \left.\frac{dZ^{э}}{dz} \right|_{z=L} = 0
\end{gather}$$

Краевые условия эквивалентны $\left.\dot{\vec{E}}_{m\tau} \right|_{z=0} = 0, \ \left.\dot{\vec{E}}_{m\tau}\right|_{z=L} = 0$, что очевидно следует из вида $\dot{\vec{E}}_{m}^{э}$.

Здесь решение очевидно:

$$\begin{gather}
Z^{Э} = \cos\left( \frac{\pi}{L}p z \right), p = 0,1,2\dots
\end{gather}$$

Теперь найдем $\omega_{lp}^{э}$ - собственные частоты резонатора:

$$\begin{gather}
k^{2} = \varkappa_{l}^{2} + (\Gamma^{э}_{l})^{2} \\
(\omega^{2})^{2}\epsilon_{a}\mu_{a} = \varkappa_{l}^{2} + \frac{\pi^{2}p^{2}}{L^{2}} \\
\omega_{lp}^{э} = \frac{1}{\sqrt{ \epsilon_{a} \mu_{a} }}\sqrt{ \varkappa_{l}^{2} + \frac{\pi^{2}p^{2}}{L^{2}} }
\end{gather}$$

2. $H$-поля ($H_{z} \neq 0, \ E_{z} = 0$):

$$\begin{gather}
\dot{\vec{H}}_{m} = \frac{1}{i\omega \mu_{a}}\left( \frac{dZ^{м}}{dz} \mathrm{grad}_{\perp} \, T^{м} + \vec{z}^{0} (\varkappa^{м})^{2} T^{м}Z^{м} \right), \\
\dot{\vec{E}}_{m}^{м} = - \left[ \mathrm{grad}_{\perp} \, T^{м}, \ \vec{z}^{0} \right] Z^{м}
\end{gather}$$

Аналогично находим решения:

$$\begin{gather}
Z^{м} = \sin\left( \frac{\pi}{L}pz \right), \ z = 1,2\dots
\end{gather}$$

А также собственные волны резонатора:
$$\begin{gather}
\omega_{lp}^{м} = \frac{1}{\sqrt{ \epsilon_{a}\mu_{a} }} \sqrt{ (\varkappa^{м})^{2} + \left( \frac{\pi}{L}p \right)^{2} }
\end{gather}$$

Т.е. в резонаторе существуют только его собственные волны, в отличие от волновода, где может распространяться бесконечное число несобственных волн.

### Общие свойства собственных полей в резонаторе

1. Существует бесконечное множество собственных полей электрического и магнитного типа.
2. Собственные поля могут существовать только на определенных частотах - собственных частотах.
3. Собственные поля можно пронумеровать в порядке возрастания собственной частоты.
4. Поле с наименьшей собственной частотой называют основным, остальные поля называют высшими полями.
5. Зависимость собственных полей от поперечных координат определятся функцией $T$, такой же как и для собственных полей волновода.
6. Зависимость составляющих поля от продольной координаты $z$ определяется триг. функциями - синусом или косинусом.
7. Поперечные составляющие вектора $\dot{\vec{E}}_{m}$ и продольные составляющие вектора $\dot{\vec{H}}_{m}$ изменяются по синусоидальному закону, остальные составляющие - по косинусоидальному.

### 6.8 Собственные поля прямоугольного волновода

1. $E$-поля: обозначаются $E_{mnp}$
$$\begin{gather}
T_{mn}^{э}(x,y) = C_{mn}^{э} \sin \left( \frac{\pi}{a} mx \right)\cos\left( \frac{\pi}{a}ny \right) \\
(\varkappa^{э}_{m})^{2} = \left( \frac{\pi}{a}m \right)^{2} + \left( \frac{\pi}{b}m \right)^{2}, m,n = 1,2,\dots
\end{gather}$$

2. $H$-поля: обозначаются $H_{mnp}$

$$\begin{gather}
T_{mn}^{м}(x,y) = C_{mn}^{м} \sin \left( \frac{\pi}{a} mx \right)\cos\left( \frac{\pi}{a}ny \right) \\
(\varkappa^{м}_{m})^{2} = \left( \frac{\pi}{a}m \right)^{2} + \left( \frac{\pi}{b}m \right)^{2}, m,n = (0),1,2,\dots
\end{gather}$$

$$\begin{gather}
\omega_{mnp}^{э,м} = \frac{1}{\sqrt{ \epsilon_{a}\mu_{a} }}\sqrt{ \left( \frac{\pi}{a}m \right)^{2} + \left( \frac{\pi}{b}n \right)^{2} + \left( \frac{\pi}{L}p \right)^{2} } \\
\end{gather}$$

$$\begin{gather}
E: \ p = 0,1,2,\dots \\
H: \ p = 1,2,\dots
\end{gather}$$
