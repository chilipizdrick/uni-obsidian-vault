## Элиптические уравнения (примеры). Метод разделения переменных

$$\begin{gather}
u = u(x,y) \\
\Omega = (0,a) \times (0,b) \\
\end{gather}$$

### Задача Дирихле

$$\begin{gather}
u_{xx} + u_{yy} = 0 \\
u(0,y) = 0 \\
u(a,y) = 0 \\
u(x,0) = \phi(x) \\
u(x,b) = \psi(x)
\end{gather}$$

$$\begin{gather}
u(x,y) = X(x)Y(y) \\
u(x,y) = X(x)Y(y) \to u_{xx} + u_{yy} = 0 \\
(X(x)Y(y))_{xx} + (X(x)Y(y))_{yy} = 0 \\
\left.X''Y + XY'' = 0 \right| : XY \\
\frac{X''}{X} + \frac{Y''}{Y} = 0 \\
\frac{X''}{X} = -\frac{Y''}{Y} = \lambda = \mathrm{const}
\end{gather}$$

$$\begin{gather}
\begin{cases}
\frac{X''}{X} = \lambda \\
\frac{Y''}{Y} = -\lambda
\end{cases} \\
\lambda = -\mu^{2} \\
\begin{cases}
X'' + \mu^{2}X = 0 \\
Y'' - \mu^{2}Y = 0
\end{cases}
\end{gather}$$

$$\begin{gather}
X'' + \mu^{2}X = 0 \implies X(x) = C_{1}\cos(\mu x) + C_{2}\sin(\mu x) \\
u(0,y) = X(0)Y(y) = 0 \implies X(0) = 0 \\
u(a,y) = X(a)Y(y) = 0 \implies X(a) = 0 \\
\end{gather}$$

$$\begin{gather}
X(0) = C_{1} = 0 \\
X(a) = C_{2}\sin(\mu a) = 0 \implies \left[\begin{array}{l}
C_{2} = 0 \\
\sin(\mu a) = 0
\end{array}\right.
\end{gather}$$

$$\begin{gather}
\sin(\mu a) = 0 \implies \mu_{n} = \frac{\pi n}{a}, \ n \in \mathbb{Z} \\
\mu\neq 0 \implies n\neq 0 \\
X_{n}(x) = C_{2}\sin\left( \frac{\pi nx}{a} \right), \ n \in \mathbb{Z} \setminus \{ 0 \}
\end{gather}$$


$$\begin{gather}
\text{Пусть} \ \mu = 0: \ 
X'' = 0 \implies C_{1}x + C_{2} \\
X(0) = C_{2} = 0 \\
X(a) = C_{1}a = 0 \implies C_{1} = 0 \\
\mu = 0 \ \text{ведет к тривиальному решению}
\end{gather}$$

$$\begin{gather}
Y''_{n} - \mu_{n}^{2}Y_{n} = 0 \implies Y_{n}(y) = A_{n}e^{\mu_{n}y} + B_{n}e^{-\mu_{n}y} \\
\end{gather}$$

Тогда

$$\begin{gather}
u_{n}(x,y) = X_{n}(x)Y_{n}(y) = \\
= (A_{n}e^{\mu_{n}y}+B_{n}e^{-\mu_{n}y})\sin\left( \frac{\pi nx}{a} \right), \ n = 1,2,3,\dots
\end{gather}$$

Осталось рассмотреть условия 

$$\begin{gather}
u(x,0) = \phi(x) \\
u(x,b) = \psi(x)
\end{gather}$$

$$\begin{gather}
u_{n}(x,0) = (A_{n}+B_{n})\sin\left( \frac{\pi nx}{a} \right) = \phi(x) \implies \\
\end{gather}$$
$\implies$ Ни одно из полученных решений может не удовлетворять граничным условиям.

Линейная комбинация $u_{n}(x,y)$:

$$\begin{gather}
u(x,y) = \sum_{n=1}^{\infty} u_{n}(x,y) \\
\end{gather}$$

Уравнение $u_{xx} + u_{yy} = 0$ - линейное и однородное, а потому сумма решений тоже является решением.

$$\begin{gather}
u(0,y) = \sum_{n=1}^{\infty} u_{n}(0,y) = 0 \\
u(a,y) = \sum_{n=1}^{\infty} u_{n}(a,y) = 0
\end{gather}$$

Однородные граничные условия по переменной $x$ не нарушаются.

$$\begin{gather}
u(x,0) = \sum_{i=1}^{n} (A_{n} + B_{n})sin\left( \frac{\pi nx}{a} \right) = \phi(x) \\
u(x,b) = \sum_{i=1}^{n} (A_{n}e^{\mu_{n}b} + B_{n}e^{-\mu_{n}b}) \sin\left( \frac{\pi nx}{a} \right) = \psi(x)
\end{gather}$$

Вывод: Учет граничных условий по переменной $y$ сводится к разложению в ряд Фурье.

Случай для не непрерывнодифференциируемых $\phi(x), \psi(x)$ рассмотрим позже.

### Схема решения

1. Ищем решения в виде произведения $$u(x,y) = X(x)Y(y)$$
2. Разделяем переменные и находм компоненты $$X_{n}(x) = \sin\left( \frac{\pi nx}{a} \right), \ Y_{n}(y) = A_{n}e^{\mu_{n}u} + B_{n}e^{-\mu_{n}y}$$
3. Берем линейную комбинацию базисных функций $$u(x,y) = \sum_{n=1}^{\infty} u_{n}(x,y)$$

### Задача Неймана

$$\begin{gather}
u_{x}(0,y) = 0 \\
u_{x}(a,y) = 0
\end{gather}$$

$$\begin{gather}
\left[\begin{array}{l}
X_{0}(x)= 1, \\
X_{n}(x) = \cos\left( \frac{\pi nx}{a} \right), \ n = 1,2,3,\dots
\end{array}\right.
\end{gather}$$

### 3-ий случай (смешанные краевые условия)
### ДОКАЗАТЬ!

$$\begin{gather}
u(0,y) = 0 \\
u_{x}(a,y) = 0 \\
X_{n}(x) = \sin\left( \frac{\pi}{a}\left( n+\frac{1}{2} \right)x \right), \ n = 0,1,2,\dots
\end{gather}$$

### 4-ый случай

$$\begin{gather}
u_{x}(0,y) = 0 \\
u(a,y) = 0 \\
X_{n}(x) = \cos\left( \frac{\pi}{a}\left( n+\frac{1}{2} \right)x \right), \ n = 0,1,2,\dots
\end{gather}$$

### 5-ый случай

$$\begin{gather}
\alpha_{1}u(0,y) + \beta_{1}u_{x}(0,y) = 0, \\
\alpha_{2}u(a,y) + \beta_{2}u_{x}(a,y) = 0, \\
\end{gather}$$

где $\alpha_{1,2}, \beta_{1,2} = \mathrm{const}$.
Для нахождения $X_{n}(x)$ могут потребоваться компьютерные расчеты.

## Решение уравнений с неоднородными граничными условиями

Замена:

$$u = v + H$$

$$\begin{gather}
H(0,y) = f(y) \\
H(a,y) = g(y) \\
v = u - H \\
\end{gather}$$

$$\begin{gather}
H(x,y) = C(y) + xd(y) \\
H(0,y) = C(y) = f(y) \\
H(a,y) = C(y) + a\,d(y) = g(y) \\
d(y) = \frac{g(y) - f(y)}{a} \\
H(x,y) = f(y) + \frac{x}{a}(g(y) - f(y))
\end{gather}$$

Уравнение принимает вид:

$$\begin{gather}
u_{xx} + u_{yy} = 0 \\
(v+H)_{xx} + (v+H)_{yy} = 0 \\
v_{xx} + v_{yy} + H_{yy} = 0 \\
v_{xx} + v_{yy} + \frac{x}{a}(g''(y) -f''(y)) = 0 - \text{неоднородное}
\end{gather}$$

$$\begin{gather}
v(0,y) = 0, \ v(a,y) = 0 \\
u(x,0) = \phi(x) \\
v(x,0) + H(x,0) = \phi(x) \\
v(x,0) = \phi(x) - H(x,0) \\
\text{аналогично} \\
v(x,a) = \psi(x) - H(x,a) \\
\end{gather}$$

Если граничные условия неоднородны, делаем замену:

$$\begin{gather}
u(x,y) = v(x,y) + H(x,y)  \\
\left[ \begin{array}{l}
H(x,y) = c(y) + x\cdot d(y) \\
H(x,y) c(y)x + x^{2} \cdot d(y)
\end{array} \right.
\end{gather}$$

1. НЕ ЗАБЫТЬ ПЕРЕСЧИТАТЬ УРАВНЕНИЕ, ПОДСТАВИВ ГРАНИЧНЫЕ УСЛОВИЯ.
2. Однородное уравнение может стать неоднородным.

### Пример

$$\begin{gather}
u_{xx} + u_{yy} = 0 \\
u(0,y) = 12 \\
u_{x}(1,y) = 3y - 1 \\
u(x,0) = x^{2} \\
u_{y}(x,2) = \sin x
\end{gather}$$

$$\begin{gather}
H(x,y) = c(y) + x\cdot d(y) \\
H(0,y) = 12 \\
H_{x}(1,y) = 3y-1 \\
H(0,y) = c(y) = 12 \\
H_{x}(1,y) = d(y) = 3y-1  \\
\implies H(x,y) = 12+ x(3y-1)
\end{gather}$$

Повезло, $H_{yy} = 0$

$$\begin{gather}
v_{xx} + v_{yy} = 0 \\
v(0,y) = 0 \\
v_{x}(1,y) = 0 \\
v(x,0) = x^{2} + x - 12 \\
v_{y}(x, 2) = \sin x - 3x
\end{gather}$$
