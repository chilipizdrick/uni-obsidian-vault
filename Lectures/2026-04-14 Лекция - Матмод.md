$$\begin{gather}
S = \int_{t_{1}}^{t_{2}} L(t,g,\dot{g}) \, dt \\
\frac{ \partial L }{ \partial t } -\frac{d}{dt} \frac{ \partial L }{ \partial \dot{g} } = 0
\end{gather}$$

Если функций $L$ - много, то получается система уравнений:

$$\begin{gather}
\frac{ \partial L }{ \partial g_{\alpha} } - \frac{d}{dt} \frac{ \partial L }{ \partial \dot{g}_{\alpha} } = 0
\end{gather}$$

Для материальной точки (вывод 2-го закона Ньютона):

$$\begin{gather}
L = \frac{m}{2}(\dot{x}^{2} + \dot{y}^{2} + \dot{z}^{2}) - U(x,y,z)
\end{gather}$$

$$\begin{gather}
\begin{cases}
-\frac{ \partial U }{ \partial x }  - \frac{d}{dt} (m\dot{x}) = 0 \\
-\frac{ \partial U }{ \partial y }  - \frac{d}{dt} (m\dot{y}) = 0 \\
-\frac{ \partial U }{ \partial z }  - \frac{d}{dt} (m\dot{z}) = 0 \\
\end{cases}
\end{gather}$$

$$\begin{gather}
\begin{cases}
m \ddot{x} = -\frac{ \partial U }{ \partial x } \\
m \ddot{y} = -\frac{ \partial U }{ \partial y } \\
m \ddot{z} = -\frac{ \partial U }{ \partial z } 
\end{cases}
\end{gather}$$

Для системы частиц - все то же самое.

От сюда же следуют законы сохранения энергии, импульса, углового момента.

### Задача - описать систему с двойным маятником

Введем обобщенные координаты - $\phi_{1}, \phi_{2}$ю

$$\begin{gather}
L = T - U \\
T = \frac{m_{1}}{2}\left( \dot{x}_{1}^{2} + \dot{y}_{1}^{2} \right) + \frac{m_{2}}{2}(\dot{x}_{2}^{2} + \dot{y}_{2}^{2}) \\
U = m_{1}gy_{1} - m_{2}gy_{2} \\
\end{gather}$$

$$\begin{gather}
x_{1} = l_{1} \sin \phi_{1} \\
y_{1} = l_{1} \cos \phi_{1} \\
x_{2} = l_{1} + \sin \phi_{1} + l_{2}\sin \phi_{2} \\
y_{2} = l_{1}\cos \phi_{1} + l_{2} \cos \phi_{2}
\end{gather}$$

$$\begin{gather}
\dot{x}_{1} = l_{1}\cos \phi_{1} \cdot \dot{\phi}_{1} \\
\dot{y}_{1} = -l_{1} \sin \phi_{1} \cdot \dot{\phi}_{1} \\
\dot{x}_{2} = l_{1} \cos \phi_{1} \cdot  \dot{\phi}_{1} + l_{2} \cos \phi_{2}  \cdot  \dot{\phi}_{2} \\
\dot{y}_{2} = -l_{1} \sin \phi_{1} \cdot  \dot{\phi}_{1} - l_{2} \sin \phi_{2}  \cdot  \dot{\phi}_{2} \\
\end{gather}$$

Далее собираем лагранжиан и получаем систему уравнений:

$$\begin{gather}
\frac{ \partial L }{ \partial \phi_{1} } - \frac{d}{dt} \frac{ \partial L }{ \partial \dot{\phi}_{1} }  = 0 \\
\frac{ \partial L }{ \partial \phi_{2} } - \frac{d}{dt} \frac{ \partial L }{ \partial \dot{\phi}_{2} }  = 0
\end{gather}$$

В механике сплошных сред энергия вводится следующим образом:

$$\begin{gather}
E = \frac{\rho v^{2}}{2}
\end{gather}$$
