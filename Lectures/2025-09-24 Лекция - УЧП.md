# Элипрические уравнения (примеры)

## Метод разделения переменных

$$\begin{gather}
u = u(x,y) \\
\Omega = (0,a) \times (0,b) \\
\end{gather}$$

### Задача Дирихле

$$\begin{gather}
u_{xx} + u_{yy} = 0 \\
u(0,y) = 0 \\
u(a,y) = 0 \\
u(x,0) = \phi(x) \\
u(x,b) = \psi(x)
\end{gather}$$

$$\begin{gather}
u(x,y) = X(x)Y(y) \\
u(x,y) = X(x)Y(y) \to u_{xx} + u_{yy} = 0 \\
(X(x)Y(y))_{xx} + (X(x)Y(y))_{yy} = 0 \\
\left.X''Y + XY'' = 0 \right| : XY \\
\frac{X''}{X} + \frac{Y''}{Y} = 0 \\
\frac{X''}{X} = -\frac{Y''}{Y} = \lambda = \mathrm{const}
\end{gather}$$

$$\begin{gather}
\begin{cases}
\frac{X''}{X} = \lambda \\
\frac{Y''}{Y} = -\lambda
\end{cases} \\
\lambda = -\mu^{2} \\
\begin{cases}
X'' + \mu^{2}X = 0 \\
Y'' - \mu^{2}Y = 0
\end{cases}
\end{gather}$$

$$\begin{gather}
X'' + \mu^{2}X = 0 \implies X(x) = C_{1}\cos(\mu x) + C_{2}\sin(\mu x) \\
u(0,y) = X(0)Y(y) = 0 \implies X(0) = 0 \\
u(a,y) = X(a)Y(y) = 0 \implies X(a) = 0 \\
\end{gather}$$

$$\begin{gather}
X(0) = C_{1} = 0 \\
X(a) = C_{2}\sin(\mu a) = 0 \implies \left[\begin{array}{l}
C_{2} = 0 \\
\sin(\mu a) = 0
\end{array}\right.
\end{gather}$$

$$\begin{gather}
\sin(\mu a) = 0 \implies \mu_{n} = \frac{\pi n}{a}, \ n \in \mathbb{Z} \\
\mu\neq 0 \implies n\neq 0 \\
X_{n}(x) = C_{2}\sin\left( \frac{\pi nx}{a} \right), \ n \in \mathbb{Z} \setminus \{ 0 \}
\end{gather}$$


$$\begin{gather}
\text{Пусть} \ \mu = 0: \ 
X'' = 0 \implies C_{1}x + C_{2} \\
X(0) = C_{2} = 0 \\
X(a) = C_{1}a = 0 \implies C_{1} = 0 \\
\mu = 0 \ \text{ведет к тривиальному решению}
\end{gather}$$

$$\begin{gather}
Y''_{n} - \mu_{n}^{2}Y_{n} = 0 \implies Y_{n}(y) = A_{n}e^{\mu_{n}y} + B_{n}e^{-\mu_{n}y} \\
\end{gather}$$

Тогда

$$\begin{gather}
u_{n}(x,y) = X_{n}(x)Y_{n}(y) = \\
= (A_{n}e^{\mu_{n}y}+B_{n}e^{-\mu_{n}y})\sin\left( \frac{\pi nx}{a} \right), \ n = 1,2,3,\dots
\end{gather}$$

Осталось рассмотреть условия 

$$\begin{gather}
u(x,0) = \phi(x) \\
u(x,b) = \psi(x)
\end{gather}$$

$$\begin{gather}
u_{n}(x,0) = (A_{n}+B_{n})\sin\left( \frac{\pi nx}{a} \right) = \phi(x) \implies \\
\implies \text{ни одно из полученных решений может не удовлетворять граничным условиям}
\end{gather}$$

Линейная комбинация $u_{n}(x,y)$:

$$\begin{gather}
u(x,y) = \sum_{n=1}^{\infty} u_{n}(x,y) \\
\end{gather}$$

Уравнение $u_{xx} + u_{yy} = 0$ - линейное и однородное, а потому сумма решений тоже является решением.

$$\begin{gather}
u(0,y) = \sum_{n=1}^{\infty} u_{n}(0,y) = 0 \\
u(a,y) = \sum_{n=1}^{\infty} u_{n}(a,y) = 0
\end{gather}$$

Однородные граничные условия по переменной $x$ не нарушаются.

$$\begin{gather}
u(x,0) = \sum_{i=1}^{n} (A_{n} + B_{n})sin\left( \frac{\pi nx}{a} \right) = \phi(x) \\
u(x,b) = \sum_{i=1}^{n} (A_{n}e^{\mu_{n}b} + B_{n}e^{-\mu_{n}b}) \sin\left( \frac{\pi nx}{a} \right) = \psi(x)
\end{gather}$$

Вывод: Учет граничных условий по переменной $y$ сводится к разложению в ряд Фурье.

Случай для не непрерывнодифференциируемых $\phi(x), \psi(x)$ рассмотрим позже.

### Схема решения

1. Ищем решения в виде произведения $$u(x,y) = X(x)Y(y)$$
2. Разделяем переменные и находм компоненты $$X_{n}(x) = \sin\left( \frac{\pi nx}{a} \right), \ Y_{n}(y) = A_{n}e^{\mu_{n}u} + B_{n}e^{-\mu_{n}y}$$
3. Берем линейную комбинацию базисных функций $$u(x,y) = \sum_{n=1}^{\infty} u_{n}(x,y)$$

$$\begin{gather}
u_{x}(0,y) = 0 \\

\end{gather}$$

### 5-ый случай

$$\begin{gather}
\alpha_{1}u(0,y) + \beta_{1}u_{x}(0,y) = 0, \\
\alpha_{2}u(a,y) + \beta_{2}u_{x}(a,y) = 0, \\
\end{gather}$$

где $\alpha_{1,2}, \beta_{1,2} = \mathrm{const}$.
