## Элипрические уравнения (примеры)

### Метод разделения переменных

$$\begin{gather}
u = u(x,y) \\
\Omega = (0,a) \times (0,b) \\
\end{gather}$$

Задача Дирихле:

$$\begin{gather}
u_{xx} + u_{yy} = 0 \\
u(0,y) = 0 \\
u(a,y) = 0 \\
u(x,0) = \phi(x) \\
u(x,b) = \psi(x)
\end{gather}$$

$$\begin{gather}
u(x,y) = X(x)Y(y) \\
u(x,y) = X(x)Y(y) \to u_{xx} + u_{yy} = 0 \\
(X(x)Y(y))_{xx} + (X(x)Y(y))_{yy} = 0 \\
\left.X''Y + XY'' = 0 \right| : XY \\
\frac{X''}{X} + \frac{Y''}{Y} = 0 \\
\frac{X''}{X} = -\frac{Y''}{Y} = \lambda = \mathrm{const}
\end{gather}$$

$$\begin{gather}
\begin{cases}
\frac{X''}{X} = \lambda \\
\frac{Y''}{Y} = -\lambda
\end{cases} \\
\lambda = -\mu^{2} \\
\begin{cases}
X'' + \mu^{2}X = 0 \\
Y'' - \mu^{2}Y = 0
\end{cases}
\end{gather}$$

$$\begin{gather}
X'' + \mu^{2}X = 0 \implies X(x) = C_{1}\cos(\mu x) + C_{2}\sin(\mu x) \\
u(0,y) = X(0)Y(y) = 0 \implies X(0) = 0 \\
u(a,y) = X(a)Y(y) = 0 \implies X(a) = 0 \\
\end{gather}$$

$$\begin{gather}
X(0) = C_{1} = 0 \\
X(a) = C_{2}\sin(\mu a) = 0 \implies \left[\begin{array}{l}
C_{2} = 0 \\
\sin(\mu a) = 0
\end{array}\right.
\end{gather}$$

$$\begin{gather}
\sin(\mu a) = 0 \implies \mu_{n} = \frac{\pi n}{a}, \ n \in \mathbb{Z} \\
\mu\neq 0 \implies n\neq 0 \\
X_{n}(x) = C_{2}\sin\left( \frac{\pi nx}{a} \right), \ n \in \mathbb{Z} \setminus \{ 0 \}
\end{gather}$$
