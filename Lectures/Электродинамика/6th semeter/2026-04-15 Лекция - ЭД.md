## Л. №5. Возбуждение электромагнитных волн в полых волноводах.

### 6.1. Введение 

Полый волновод представляет собой полю металическую трубу, предназначенную для передачи сверхвысокочастотных волн.

Регулярный волновод - бесконечный волновод с неизменной формой поперечного счения.

Собственные волны (собственные фукнции системы) - решение систем однородных уравнений (токи отбрасывается), удовлетворяющие условиям на границе волновода.

![[2026-04-15 Семинар - ЭД 2026-04-15 11.11.20.excalidraw]]

$$\begin{gather}
\mathrm{rot} \, \dot{\vec{H}}_{m} = i\omega\epsilon_{a} \dot{\vec{E}}_{m} + \dot{\vec{j}}_{m}^{ст} \\
\mathrm{rot} \, \dot{\vec{E}}_{m} = -i\omega \mu_{a} \dot{\vec{H}}_{m} - \dot{\vec{j}}_{m}^{ст}
\end{gather}$$

$$\begin{gather}
\left.\dot{\vec{E}}_{m\tau}\right|_{S} = 0 \to \left.\dot{\vec{H}}_{m\nu}\right|_{S} = 0
\end{gather}$$

+ также не забываем условия при $z \to \pm \infty$

### 6.2. Собственные волны идеального волновода

$$\begin{gather}
\begin{cases}
\mathrm{rot} \, \dot{\vec{H}}_{m} = i\omega\epsilon_{a} \dot{\vec{E}}_{m} \\
\mathrm{rot} \, \dot{\vec{E}}_{m} = -i\omega \mu_{a} \dot{\vec{H}}_{m}
\end{cases}
\end{gather}$$

Данная система имеет решение двух типов - электрического и волнового, но одно из другого тривиально получается из принципа двойственности.

Решение элетрического типа - продольная составляющая электрического поля отлична от нуля, а продольная составляющая магнитного поля равна нулю. 

$$\begin{gather}
E - \text{волны}, \ E_{z} \neq 0, \ H_{z} = 0
\end{gather}$$

$$\begin{gather}
\dot{\vec{E}}_{m}^{э} = \frac{1}{i\omega \epsilon_{a}} (\mathrm{grad} \, \mathrm{div} \, \dot{\vec{A}}_{m} + k^{2} \dot{\vec{A}}_{m}^{э}) \\
\dot{\vec{H}}_{m}^{э} = \mathrm{rot} \, \dot{\vec{A}}_{m}^{э} \\
\Delta \dot{\vec{A}}_{m}^{э} + k^{2} + \dot{\vec{A}}_{m}^{э} = - \dot{\vec{j}}_{m}^{ст} = 0
\end{gather}$$

Тогда решение можно представить в виде одной продольной составляющей векторного потенциала.

$$\begin{gather}
\dot{\vec{A}}_{m}^{э} = \vec{z}^{0} \dot{U}_{m}^{э}, \ \Delta \ \dot{U}_{m}^{э} + k^{2} \dot{U}_{m}^{э} = 0
\end{gather}$$

Решение волнового уравнения: ($\Delta_{\perp}$ - двумерный оператор лапласа)

$$\begin{gather}
\Delta_{\perp} \dot{U}_{m}^{э} + \frac{ \partial^{2} \dot{U}_{m}^{э} }{ \partial^{2} z^{2} } + k^{2} \dot{U}_{m} = 0 \\
\end{gather}$$

$$\begin{gather}
\dot{U}_{m}^{э} = T^{э}(x,y) Z^{э}(z), \ \underbrace{\frac{1}{T^{э}} \Delta_{\perp} T^{э}}_{-(\varkappa^{э})^{2}} + \underbrace{\frac{1}{Z^{э}} \frac{d^{2} Z^{э}}{dz^{2}}}_{-(\Gamma^{э})^{2}} + k^{2} = 0 \to \\
\to k^{2} = (\varkappa^{э})^{2} + (\Gamma^{э})^{2}
\end{gather}$$


$$\begin{gather}
\to \Delta_{\perp} T^{э} + (\varkappa^{э})^{2} T^{э} = 0, \ 
\frac{d^{2}Z^{э}}{dz^{2}} + (\Gamma^{э})^{2} Z^{э} = 0 \to \\
\to Z_{1}^{э} = e^{-i\Gamma^{э}z}, \ Z^{э}_{2} = e^{i\Gamma^{э}z}
\end{gather}$$

$$\begin{gather}
\dot{\vec{E}}_{m}^{э} = \frac{1}{i\omega\epsilon_{a}} \left( \frac{dZ^{э}}{dz} \cdot \mathrm{grad}_{\perp} \, T^{э} + \vec{z}^{0} (\varkappa^{э})^{2} T^{э} Z^{э}\right) \\
\dot{\vec{H}}_{m}^{э} = \mathrm{rot} \, (\vec{z}^{0} U_{m}^{э}) = \left[ \mathrm{grad}_{\perp} \, T^{э}, \vec{z}^{0} \right] Z^{э}
\end{gather}$$
